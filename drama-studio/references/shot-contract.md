# 镜头契约（景川·每镜开工前执行，按需加载）

> 解决：提示词没想清楚就投喂 → 一遍遍出废片烧积分。机制：**先诊断、再冻结、后生成**。

## 1. Director's Read 轻量六问（每镜开工前判读）

| 问 | 写什么 |
|---|---|
| ① 戏剧功能 | 本镜在叙事里干什么：介绍/深化/转折/考验/揭示/决定/兑现（七选一） |
| ② 转折 | 本镜承担翻转时，写拍内可见的单一前后价值变化（由疑到信/由强到弱/由聚到散）；建立、停留或余波镜写「本镜不承担」，并说明继承或稳定什么 |
| ③ POV | 谁的视角看这场戏 |
| ④ 权力变化 | 本镜承担关系变化时，写开场谁控制、结尾谁控制及改变平衡的动作；不承担时写本镜维持的关系状态，不硬造压制 |
| ⑤ 隐藏欲求-障碍 | 角色真正要什么（潜文本）+ 什么在挡路 |
| ⑥ 一个不可转移细节 | 只属于你的戏、别的剧抄不走的细节（标出处：素材绑定/原创选择） |

**按职责选择可拍证据**：最终提示词须让本镜的叙事目的有可观察依据。转折镜保留前后变化，权力变化镜保留控制关系与可见反应，建立镜可用空间基线与方向，停留/余波镜可用持续状态、细微行为或声音，不可转移细节在它能加强本镜时使用。静态建立、停留或只继承前镜结果的镜头，不为齐项硬造转折、被压制行为或环境破坏；证据与本镜职责对不上才退回重判。

**动作承载与过渡**：先核人物实际注意对象与关系/处境是否相称，听到或看到的刺激是否先于选择；故事依据缺失退回编剧，不用运镜补造角色知情。先删无叙事或观看作用、且不改变因果与结果的琐碎动作，不为证明连续性增造操作或道具再安排后续处理；删上游多余动作时同步清掉仅由它产生的后续依赖，涉及已锁故事事实回创作侧处理。真正改变危险状态、人物选择、道具归属、关键承重结果，或承担情绪、关系与空间理解的动作仍须保留。看同一时刻实际可用的手、支撑点、负荷、通路与伤势；互斥动作不能同时完成。抱举须使取得支撑、抬离、承载移动的因果可读，姿态变化须有可理解的空间与时间依据；只保留证明关键结果所需的过程，普通自然连接可合写或合理剪省，不要求逐手逐脚展示，不把省略拍成瞬移或跳过关键承重结果。动作与问答按可同步、必须听完才发生、互斥顺序区分；改短片长时先去冗余，再重排完整听答和必要动作，容量不足按现有授权调整分组，不能加速吞掉关键过程或擅改台词。先判断一镜到底、多镜覆盖或混合，再用景别、机位、运动与真实切点交付这些可读证据。

## 2. 镜头卡冻结（投喂/付费前锁死）

十要素逐项写定；**冻结时机在进入付费生成或正式拍摄前**——`planning_only` 阶段改分镜直接更新分镜总表即可。进入生成/拍摄后的修改先判断镜头叙事身份：

- 同一叙事职责、同一认领范围内，只调整构图、调度、表演强度、提示词措辞或生成参数时，**保留 Shot ID，提升修订号**，并让旧 take 退出当前候选；
- 拆分、合并、改变剧本节拍认领范围或让镜头承担不同叙事职责时，创建**新 Shot ID**，原**旧 ID 停用**并在分镜总表中保留去向说明；
- 是否重生成只按受影响范围决定，不因一次局部修订让无关兄弟镜头失效。修订血缘留在现有分镜总表与 `storyboard_rev` 中，不另建报告或确认关。 修订前按下文当前状态规则查看实际选片的前后相邻片段，不只改文字。

镜头十要素：

```
人物特征 / 服装 / 场景 / 动作 / 情绪 / 镜头语言（景别+运镜）/ 走位 / 构图 / 可见结果 / 画幅时长
```

**串行规则**：**只有真正依赖前镜结果的镜头才串行**——首尾帧承接、动作接切、伤口/道具状态依赖前镜成片时，由实际执行者先对前镜成片做**身份正确 / 动作结果成立 / 关键状态可继承**的最小语义核对；通过后才生成依赖它的下一镜，不盲续。该核对内联完成，**不新增报告、关卡或用户确认**；严恪启用时，其批次语义 QC 结论覆盖此前内联接受状态。失败、未核对或状态未知的输出不得作为下一镜依据。资产独立、空间状态已锁定的镜头可批量处理，不整剧串行。

**【接续状态】字段**（吸收 manju-laoli，替代首尾帧拉伸粘连）：每组镜头自带接续状态块——角色动作/位置/情绪/道具状态从上一组继承什么，逐字段写清。下一镜以此为准入画，不靠模型自己猜。

**当前状态必须可继承、可看见**：局部修订先看实际选片及其前后相邻承接段，核身份状态、妆容、衣装、情绪、台词、调度、道具与出口方向；只重做真实受影响的依赖，未受影响的已认可素材继续保留。同场跨 Clip 从选用前片实际剪辑出点附近的连续画面核对人物伤势/血污的位置与程度、衣物破损、沾染的手及接触物、姿态/呼吸、持物，还有环境烟火的来源/范围/可见度及其光影；只取真实影响本段的项，不把身份图或场景布局一致当状态一致。已发生且未解除的状态进入本段入态，在承担发现、判断或行动因果的镜头中用合适景别、遮挡关系与光线明确呈现；“受伤/有火/保持一致”等词存在不证明画面可读，也不强求每镜特写。状态恢复、火势减弱或烟量变化须有已成立的时间/行动依据；不可为让脸清楚任意清空危险环境，也不可加浓到遮掉承重动作。计划出态、用户验收与执行者实际核过的范围分别记录；文件存在、哈希相同、静帧或未试听的判断都不能代替完整声画语义验收。沿现有接续块和分镜记录，不另建报告。

**衔接六式**（相邻两镜的切法，每镜卡上标注用哪式）：

| 式 | 内容 |
|---|---|
| 动作连续切 | 上镜动作中段切，下镜从同一动作接续 |
| 反应切 | 上镜动作 → 下镜切另一人的反应（反应比动作值钱） |
| 景别跳切 | 同主体换景别（全→特），信息递进 |
| Eye-Trace 切 | **下镜入画点承接上镜视线落点**——上镜看哪儿，下镜从哪儿入 |
| 遮挡过渡切 | 借前景遮挡物（人走过/门关上）完成过渡 |
| 动势匹配切 | 两镜动量守恒（上镜往左冲，下镜保持左向动势） |

**金句发酵镜头**：重台词/金句之后，反应**优先留在相邻镜内**（听者面部/手部微动作，无台词）；只有反应本身改变理解（意义变化发生在听者脸上）时才独立成 0.3-0.8 秒 Shot，让台词落地。**反应切是全序列最值钱的切法（v1.7.3 增 · 判断口径）**：动作让观众知道发生了什么，反应让观众知道这件事**意味着什么**——意义变化常常发生在听者脸上而非说者嘴上（「反应比动作值钱」）；连排反应镜时给每个反应不同的理解层次（一个先懂/一个半拍后懂/一个没懂），反应不是复读，是各自的选择。

## 3. 一镜一工作 + 补拍序列

- 一个镜头只干一件事：建立地理 / 跟随动作 / 揭示细节，不混。
- 信息不够时的补拍序列：**wide 建立 → medium 跟动作 → close-up 揭后果**，每镜附 continuity 声明（同位置/同状态/同光向）。

## 4. 结尾选型六类（按「下一条是什么」选）

| 类型 | 用法 |
|---|---|
| Resolve | 事件落地，段落收束 |
| Extension anchor | 停在可延展的姿态/视线上，供下镜接续 |
| Loop seam | 结尾状态=开头状态，可循环 |
| Hero hold | 英雄定格，情绪高点悬停 |
| Edit point | 为剪辑留的硬切点（动作中段/反应瞬间） |
| Reveal-punch | 揭示性收尾，钩子进下一集 |

> **集尾选型提示（v1.9.0 增 · v1.9.1 裁量收口 · 每集最后一镜）**：每集最后一镜优先 **Reveal-punch / Crisis-cut 型钩子**（与 storyboard-craft §17 集尾合同同口径）——钩子画面留到观众读完揭示或反应、情绪完成一次落点，预览时长只作剪辑起点，不作通过门槛；末帧保持未收束表情/动作。Resolve/Loop seam 只用于确无跨集钩子设计的集尾，不作为默认。

## 5. 重拍协议（出废片后）

1. **先定责任层，再判可用性**：对照批准正文、冻结请求/参考输入与实际成片，区分故事选择/因果不成立、镜头/提示词漏交代或指令冲突、模型未执行已清楚的指令。正文问题回创作侧；制作问题修对应镜头；缺少原请求或完整声画时保持待核，不把用户观察或推测写成技术定论。再给可用 / 可用但需修剪 / 局部可救 / 改写重拍 / 放弃的裁决。
2. **完整替换与范围控制**：定位实际问题、列必要修改、交付完整替换稿及真实输入，不只给零散补丁；修复范围由已证实缺陷与用户授权决定，不借局部返修重写无关内容。多个缺陷属于同一因果/动作链时一并修正，不能被“只改一个词/变量”阻止。 替换前后按 §2 的实际相邻选片重新核承接，计划状态不能替代生成结果。
3. **单变量仅用于归因对照**：需要判断哪个输入导致差异时，才在已授权预算内只改该变量；多变量整改可同时修复，但不把结果归因于某一个改动，不为凑 A/B 自动多付费。沿用既有提交确认要求和本次授权，不把每次修订变成重复询问。
3.5. **冻结证据与后段隔离**：保留原提交提示词、参数、真实资产清单、回执及错误 take；新稿另修订，不覆盖历史请求。错误 take 退出当前候选与接续参考链；依赖它的后段先按已核状态重判。记录实际成本，失败不等于退款，也不自动授权重试。
4. **预算约束**：单镜重拍服从用户已批准的调用/成本预算与工具/API 硬上限，不设脱离项目数据的通用次数。未给预算时先按 E01/已完成批次基线、镜头复杂度与工具单价试算并标假设；同一故障稳定复现、继续原路已无新增信息，或将触及批准预算/工具硬上限时，回沈砚报告已用量与换首帧/换模型/拆镜选项，不原地烧钱
