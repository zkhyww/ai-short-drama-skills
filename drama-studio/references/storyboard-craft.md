# 分镜质量规范（吸收自 DeepWhite 分镜构建器 + Seedance 提示词库 + 船长AI视界，按需加载）

> 只吸收「分镜写作质量」层：微节拍、提示词固定结构、表情/语气拆解、防错清单、光影 contract、运镜四原则、字数约束、风格母版、表情三轴。不吸收交互式确认门（资产/空间/时间/结构/交付/QA 六大 Gate）——与我们的「两个弹窗」哲学冲突；只轻量保留「多角色同框写清空间位置」。
> **导演视听判断（v1.7.3 增）**：分镜是翻译不是重写（§10「分镜不做新决定」）；本文件各节之外，每镜动笔前过一条导演判断——**这一镜让观众看什么？**（看见信息/看见关系/看见变化/看见代价）答不出时先回查信息、关系、秘密距离和情绪落地等隐性价值；显性隐性都不成立，才判为装饰镜（删除或合并）。
> **使用时机**：下发景川写任何分镜前必读，把下面命中条目原文贴进景川模板。动作戏时叠加打斗规范——`genre-and-fight-rules.md` 为**跨 Skill 引用：drama-crew/references/genre-and-fight-rules.md**（本包无本地副本）；无法读取 crew 包时，使用本文件已有的「起手→交锋→受击→结果」摘要执行，不另建副本。

## 1. 微节拍（MICRO BEATS）—— 泛情绪必须拆成身体事件

**泛情绪词不能代替可拍表演，但也不禁止它作为方向提示。** 承重表演或已出现泛演/机械表情时，从肌肉、呼吸、眼神、姿态和节奏中选实际需要的可见载体；普通功能句只写变化项，不要求全身部位逐项动一遍。以下是取材示例，不是情绪发生的固定生理顺序。

常用情绪拆解速查：

| 情绪 | 可执行身体版本（任选组合） |
|---|---|
| 震惊/冻结 | 身体冻结0.3-0.5秒 → 瞳孔放大 → 嘴唇微张无声 → 冻结后一次延迟急促鼻吸气 → 眼睛锁定触发源不眨眼 |
| 愤怒/决心 | 咬肌透过皮肤可见收紧 → 鼻翼在重音词上扩张 → 瞳孔收缩、视线聚焦变窄 → 眼角外缘收紧（不夸张眯眼）→ 高潮时刻不眨眼 → 下颌向前顶出一瞬又压回 |
| 焦虑/紧张 | 喉结吞咽一次 → 台词前短促鼻吸气 → 舌尖舔润下唇 → 脸颊毛细血管轻微泛红 → 关键词时瞳孔放大 |
| 悲伤/脆弱（不落泪版） | 眼角外缘下垂 → 眼眶湿润有眼神光但不落下 → 眉头中央皱起 → 嘴唇轻颤一次 → 头部微垂 → 肩膀像失去支撑般下沉 |
| 控制/冷静/优越感 | 呼吸平稳均匀 → 手指手臂放松 → 缓慢均匀眨眼 → 下颌微抬 → 微笑逐渐建立（不一开始就是完成的笑） |
| 压抑情绪 | 面部肌肉对抗涌上来的情绪 → 咬肌缓慢收缩 → 喉结一次延迟用力的吞咽 → 眼眶积水光不落下 → 一次缓慢深控制的吸气 → 下颌微抖一下立刻收紧 |

**单镜头内情绪弧线不固定顺序、步数或七拍**：先写本镜的刺激、人物正在压住什么、可见泄漏或选择，以及结束状态；只保留真正发生的节点。编号节拍可用于复杂承重表演的整理，不得为补齐模板伪造过渡。

**承重台词才展开前/中/后三件套**：重大转折、证据揭示、关系摊牌、季终等承重台词，按需写台词前的准备或遮掩、台词中的重音与身体泄漏、台词后的结果或余波。普通功能句继承人物表演档案，只写本句确有变化的动作，禁止句句塞吞咽、眨眼和停顿。

**多人反应按叙事职责安排**：承重群像若同步反应会显假，可让一个先懂、一个迟疑、一个没注意；但**不要求人人错峰反应**，虚化背景与未命名群演只需保持区域、朝向和环境活动连续。明确的集体口令、惊吓或仪式可以同步。不写夸张鬼脸，不默认流泪（剧本明确要求才哭）。

## 2. 镜头内容核对顺序（五字段，不是最终输出 Schema）

先按下列五字段核对镜头内容是否完整；它们是分镜诊断顺序，不与 `prompt-assembly.md` 的最终格式竞争。最终交付只输出 §2 路由命中的一种正文：通用四区块，或明确启用的 30 秒直出专项八段式：

```
画面动作概述：一句话看见什么、主要动作、人物状态、情绪/叙事功能（**先答「观众看什么」再答「画面有什么」**——这一镜让观众看见信息/关系/变化/代价的哪一个；观众要看的点决定画面里留什么、删什么）
画面构图：初始构图，优先用左/中/右三分之一、前景/中景/远景、负空间、遮挡、接触点、相互位置关系（百分比只作辅助锚点）
机位：摄像机位置 + 景别 + 角度 + 焦段 + 运镜方式 + 运镜中必须保持的构图关系
动作：按时间顺序写动作/物体运动/特效/微表演，不抽象概括
音效：每镜头必写；贯穿全场的声音写「延续全场音效」并在环境活动段细述
```

- 通用多镜头段开头写「多机位剪辑」，内部 `【镜头N｜时间范围】` 分段；30 秒专项在 Block 7 写实际镜头、时间范围与切点。
- 单镜头段开头写「单镜头，无剪辑。预计时长约X秒」；30 秒专项一镜到底写一个覆盖 `00:00–00:30` 的 Shot 和连续动作节点，不为三镜起排强造切点。
- 多角色同框/关键道具落面/复杂机位关系时，必须写清：米制距离、相对方位、谁在谁面前/背后/左/右、谁看向谁、谁遮挡谁、道具在具体表面位置、易错的高度/眼线/左右关系（轻量版空间确认——不弹窗，直接写进提示词）。
- 对白处理下沉到路由后的唯一正文位，但同一句对白/OS/VO 的**逐字正文只出现一次**：通用【声音】或专项 Block 5；视觉时间线只写说话人、声音类型、口型区间、动作与反应，重音引用台词 ID 或关键词。

## 3. 表情/语气元提示词（AI 表演指令）

**表情取材**：嘴、眼、眉、头肩与身体都是可选载体，不是逐项清单。只选本镜可读且真正承重的变化，例如 `她嘴角刚提起，听见人名后停住，目光转向门口`；不写精确嘴角角度，不把整张脸同时推到最大幅度。

**台词语气拆解**：按闻笙回注的意图与变化选择发声方式、节奏、音调与停连，普通句不强制列满参数。完整台词只放路由后的唯一正文位（通用【声音】/专项 Block 5，不可用「说了一句话」代替）；视觉段只引用台词 ID、声音类型和表演区间，专项 Block 8 不复写台词。

## 4. 防错警告清单（投喂前必查）

每个提示词按需附 `⚠️` 警告，关键错误用 `⚠️⚠️⚠️`：

- **身份漂移**：每个角色服装和脸部识别点保持一致（配合锚定表）
- **句柄/道具污染**：禁止把 A 角色衣服/发型/道具套到 B 身上；道具必须落在指定表面/手里/墙上
- **漂浮道具**：道具必须有接触阴影和重量感
- **多加镜头**：本段严格只有 N 个镜头，禁止自动补镜头
- **焦点漂移**：焦平面第一帧到最后一帧锁定目标，禁止中途换焦
- **空间镜像**：禁止左右颠倒、前后错位
- **背景空掉**：有人群/工作环境必须保留背景具体行为，禁止空旷化
- **画面污染**：禁止出现字幕、水印、分镜框、标注线、台词框
- **专项结构污染**：30 秒直出专项必须恰有八个固定顺序标题且只交一条 Prompt Unit；Block 5 是对白唯一正文，Block 6 未使用写 `NONE`/`无`，Block 7 只引用台词 ID/口型/声音进度，Block 8 不复写台词
- **专项状态污染**：参考与 Panel 必须实际可达；真人/3D 负面锁不得混用；手持道具须有占手→交接/放置→跨镜位置链；候选音色文字不得冒充已冻结母音色

## 5. 光影 contract（光源必须有动机）

灯光不是「好看的滤镜」，是物理光源 + 情绪表达。写光前回答：**光从哪里来？软还是硬？表达什么情绪或信息？**

必写要素：动机光源（画面内可见或可推断的物理来源：窗/灯/屏幕/月光）+ 方向与高度 + 软硬质感 + 色温 + 明暗比 + 阴影方向/长度/边缘 + 主体分离 + 皮肤/材质反应 + 是否随时间变化。

速查（情绪 → 光源）：
| 情绪/任务 | 可执行光源 |
|---|---|
| 夜景压抑 | 暖色台灯来自画左，蓝色月光勾勒肩部轮廓，走廊暗影拉长 |
| 发现/揭晓 | 门缝开启，一道细白光逐渐变宽，照亮空气里的浮尘 |
| 威胁/风暴 | 冷色阴天光，闪电间歇性闪亮让剪影瞬间锐化 |
| 高级感 | 窄暖光条扫过金属表面，黑色亚克力反光保持干净 |

## 6. 运镜四原则（动作/打斗镜头）

| 拍摄内容 | 镜头方式 |
|---|---|
| 正常速度对招 | 中近景 + 侧面 + 带移动感 |
| 蓄力大前摇 | 低角度仰拍 + 合理镜头突出威力 |
| 快速攻防 | 带角度视角 + 镜头移动显速度 |
| 特写 | 破绽/转折点的过渡标点，不滥用 |

配合打斗规范使用（跨 Skill 引用：drama-crew/references/genre-and-fight-rules.md，读不到时用本节「起手→交锋→受击→结果」摘要）。打斗场时长由「争什么、策略如何变化、结果留下什么」决定；单个生成 Clip 按 prompt-assembly §1.5 的能力限制优先级执行，超出本次接口真实上限时在动作链自然段与意义变化处切分，不给整场打斗设通用秒数。

## 7. 字数与时长约束

- **仅用户明确暂不选型时（通用保守模式）**：每条可复制的视频提示词正文建议 `≤2200 中文字符`，单 Clip `≤15 秒`；超长先压缩（删重复形容词→合并背景→缩短非关键音效→减普通防错项，保留素材句柄/风格控制/核心动作/构图/机位/关键特效/每镜音效），连续节拍共用角色/地点/情绪/机位逻辑时可在上限内合并，不机械切碎。
- **已选模型时（含未回答默认 Seedance 2.0 VIP Fast / 15 秒）**：按目标模型能力卡及本次 provider/adapter/version 当前接口逐模式执行；文生、图生、参考生、首尾帧的 Prompt 长度、Clip 时长、参考资产与模式组合分别核对，不使用统一字符或秒数上限。
- 提示词开头**禁止**加固定尾巴（如「15秒。21:9。」），时长作为元数据写在小节标题或总览表。

## 8. 全片风格母版（资产阶段生成 · 分镜阶段继承）

风格母版（下表八字段）在**资产建档阶段生成初版 M1**（丹青任务内产出，并入既有「资产确认弹窗 2」一并确认锁定）——不在景川阶段新增生成动作；**跳过资产阶段（经资产缺口判断确认已有资产库完整覆盖/快做分流）时，由景川在首批分镜开头生成 M1，直接用于本批提示词并随首批分镜展示，不新增停点**。分镜阶段每条提示词在「画面构图」前引用母版编号（如 `母版M1`），不重复贴全文：

| 字段 | 内容 |
|---|---|
| 类型基调 | 都市写实/玄幻奇幻/民国质感… |
| 时代设定 | 明确年代与年代特征（服饰/器物/建筑） |
| 色彩方案 | 主色/辅色/高光色；冷调/暖调/高饱和/低饱和 |
| 用光哲学 | 自然光感/戏剧布光/硬光/柔光（接光影 contract） |
| 写实等级 | 写实/半写实/动漫风；规定皮肤与材质细节程度 |
| 摄影语言 | 运镜习惯/景别偏好/手持感/稳定性 |
| 美术材质 | 场景质感/道具质感/服装面料 |
| 风格禁区 | 禁止出现的视觉元素清单 |

- 资产阶段生成 M1 → **并入既有「资产确认弹窗 2」一并确认**（不新增独立停点）；资产已锁定或 planning_only 时母版只展示不拦截；后续段继承
- 单独复制任一资产不丢全片视觉风格——风格由母版保证，不由单条提示词重复堆砌

## 9. 表情三轴 + 情绪路径（补强微节拍）

**表情三轴**（承重表演镜或出现表情漂移风险时标；普通镜继承角色表演档案，不逐镜填表）：
- 内部情绪压力 1–5：内心风暴强度
- 外显幅度 1–5：脸上/身体的表现程度
- 自我控制 1–5：压抑/失控程度（1=完全失控，5=完全自控）

**情绪路径不固定顺序**：可从基线、识别、抵抗、生理泄漏、顶点/决定、余波中选本镜真实发生的节点；有人先行动后意识到，有人直接冻结，也有人全程不泄漏。判断标准是刺激、选择与结果可读，不是六步齐全。

**可见部位选择**：眼神、眼睑/眉、呼吸、嘴部、下颌、头肩、手与声音是可选载体；每镜选最能承载变化且目标模型能稳定交付的少数部位，禁止整张脸同时最大幅度，也不要求按固定身体顺序逐项走完。

**承重表情内嵌因果**（普通表情不必展开整条）：
`触发（什么事件）→ 目标（要什么）→ 阻碍（什么挡住）→ 应对策略（角色如何处理）→ 可见结果（观众读到什么）`

**无人脸镜头**若承担情绪任务，写明由哪个空间、道具、声音或动作结果承载；只做地理、转场或信息建立时，写清其实际职责即可，不机械补情绪句。

## 10. 节拍认领对账（轻量版，吸收自 shuohao · 只收规则不收工程）

分镜与剧本的关系必须**可对账**，防止分镜自己加戏或改剧本时镜头失效：

- 每个 S 段开头标注认领声明：`认领：第X集第X场｜剧本节拍 [起—止]`（如 `认领：第3集第2场｜节拍 ③—⑦`）。**镜头不跨场**——一个 S 段只认领同一场内的连续节拍。
- **节拍完整覆盖（v1.8.0 增）**：同一场的每个可拍剧本节拍最终应被**一个且仅一个 S 段认领**；有意省略的对白或动作必须注明省略理由——禁止静默漏拍，也禁止同一节拍被两个 S 段重复消费。
- **分镜不做新决定**：认领范围外的内容不拍；剧本没有的台词/道具/反应不自行补写（场景细节化允许，剧情新增禁止）。
- **失效点名**：剧本返修后，凡认领的场次/节拍区间对不上的 S 段，由沈砚按 `script_rev` 判定影响面并点名失效范围，景川按新剧本重出该段，严恪启用时抽查复核——不静默沿用旧分镜（制作团内闭环，不跨团调 crew 角色）。
- 无人脸/纯环境镜头标注 `认领：第X集第X场｜氛围衔接`。

## 11. 人物形象锚定（身份锚点 + 辨识特征，吸收自船长 + shuohao）

锚定表不只是「发型+服装」，每个主要角色必须给**身份锚点**（AI 出图/换镜头时能认出「是这个人」的特征）：

| 锚点层 | 写什么 |
|---|---|
| 面部辨识特征 | 按本剧实际碰撞与当前画幅可见性，从已确认或标明为制作设计的持久特征中择要；痣、疤、胎记等只有已有事实时才写 |
| 体态与声线 | 身高参照、肩背形态，以及剧本/角色档案已确立且当前辨识需要的走停节奏或手势；声线特征（低沉/清亮/沙哑） |
| 服装与道具 | 只锁当前辨识、状态或跨镜连续真正依赖的色板、单品与随身道具 |
| 皮肤与质感 | 按已确认身份、项目风格和当前辨识风险选择肤色、肤质或年龄感细节，不为齐表补写 |

**身份碰撞核查**：按当前画幅、实际参考图/生成结果与资产证据判断角色是否会被观众认错；共用面部、声线形容词本身不构成失败，已确认的共同特征必须保留。只有当前帧或参考中出现真实身份混淆，才调整造成碰撞且非继承事实的必要生产设计，并用结构、服装、状态或构图等当前可见差异解决；不得为追求词面不同重写已确认身份事实。

**无参考图铁律**：没有真实人物参考图时，**不虚假声称「保留本人长相」**——锚定表用「辨识特征清单 + 提示词描述」锁形象，不承诺还原真人。有参考图时另附 `参考图：[路径]` 并注明用途。

## 12. 1:1 单镜映射与镜头切分铁律（吸收自 LibTV 全流程工作流）

**1:1 单镜映射（v1.7.4 口径精化）**：一镜一**主动作或一段连续表演职责**。新的动作链、视线转移、对白切换、情绪转折都是**切镜诊断信号**，不是自动切镜命令；只有当前镜已无法清楚承载新的注意力、空间关系、叙事职责，或目标模型在该组合上出现生成风险时，才切镜并递增镜号。长镜中的自然对话交替、连续视线变化和同一策略下的情绪推进可以保留。

**同一条动作链的连续小动作（准备→发力→接触→收势，见 dim-action 四段式）优先保持因果连续、留在同一镜内**，写成一条连贯进行的动作——切镜的判据是「换了一件正在做的事」，不是「动作有变化」；当可读性、时长或模型能力要求拆镜时（如 1.5-2.5s 快剪镜），**在动作链的自然段间边界切开**（段间点：准备→发力 / 发力→接触 / 接触→收势），并继承姿态、方向和接触状态。确保每个镜号画面单一、明确，防止 AI 生成时把多动作揉成糊状。

**景别规范**：竖屏人物戏慎用大远景（人脸过小易丢表演）；承担地理建立、孤独尺度、权力悬殊表达时可用；日常以中景、近景、面部特写、道具特写为主，建立局部空间感，聚焦人物神态。

**运镜原则（严禁炫技）**：多用固定、轻微推/拉、横移浅景深、越肩、极速前推急停（撞击感）。复杂花哨运镜是 AI 视频崩坏的主因。

**视听配合**：
- 音效（SFX）必须**精准具体**——衣服摩擦、木门吱呀、清脆金属声、咀嚼声（禁止写「音效：紧张的音乐」这类抽象描述）
- BGM 随情绪段落明确起承转合——垫乐起 / 甜宠推进 / **戛然而止**
- 对白短小、高情绪张力

**时长与剪辑节奏**：镜数按 prompt-assembly §2.5 随组时长与叙事调整；声音容量只用 dim-audio 的发声/停顿估算与实读口径，不另设每分钟镜数或配音语速上限。

**分镜输出表格字段**：以 SKILL.md「唯一事实源」分镜总表 Schema 为准（镜号/所属Clip/场景/时长/景别/运镜/光影/站位/表演/台词音效/资产ID/情绪强度/叙事目的/结尾选型），本文件不另设字段清单，只补质量要求：画面内容列须写动作/神态细节，参考对白/音效/BGM 写进台词音效列。

> 一张分镜图（一条提示词）**只表现一个时间点、一个核心动作**。

**场次镜头结构判断（v1.8.0 增 · 内部判断，不增 Schema 字段）**：写一场分镜前先判本场结构——**连续长镜**（连续空间中动作关系的变化本身就是信息，如追逐、对峙环绕，切开会破坏空间真实感与紧张感）/ **覆盖组**（须分别看清说话、反应、证据、空间或后果，用正反打与插入镜交付）/ **混合**（长镜建立空间与关系、切镜交付信息与反应）。结构判断决定切分策略，不改变 1:1 单镜映射口径。

**对白跨画面连续（v1.8.0 增 · 判断口径）**：台词跨听者反应/道具/环境镜继续时，写清三件事——①当前画面里可听的说话者是谁（画外延续）；②声源为何仍可信（位置、距离、环境不突变）；③什么触发切回说话者、新画面增加了什么信息（反应/证据/空间后果）。满足这三问的画外对白镜是叙事选择，不是断音故障。

## 13. 视觉资产三件套 + 检验规则（吸收自 LibTV）

**资产三件套（角色，缺一不可）**：定妆照 + 肖像特写 + 三视图。三者共同锁定角色一致性，只给定妆照会在换景别时漂移。

| 资产 | 作用 | 生成后检验（逐项过） |
|---|---|---|
| **定妆照** | 锁定整体造型（年龄/发型/妆容/服装/配饰） | ① 角色一致 ② 服装材质清晰 ③ 配饰齐全 |
| **三视图** | 锁定正面/90°侧面/背面全身，供多角度镜头参考 | ① 角色一致 ② 发型无变化 ③ 服装颜色款式长度一致 ④ 配饰位置不丢失 ⑤ 身高比例统一 |
| **肖像特写** | 锁定脸型/五官/妆容/气质，供近景与特写控制 | ① 脸型五官一致 ② 发型妆容无变化 ③ 年龄气质不跑偏 ④ 面部皮肤自然（无塑料感） |

**场景资产六要素**：时代背景 / 地点 / 空间结构 / 核心陈设 / 时间 / 画面灯光 / 整体氛围
**场景检验 4 项**：① 符合时代地点 ② 空间结构清楚 ③ 关键物品完整清晰 ④ 灯光风格符合氛围

**场景九宫格多机位公式**（同一场景要换机位时用——多角度 ≠ 多个不同场景）：
保持建筑结构/空间布局/材质/光线/风格完全一致，核心空间锚点不变，生成 3×3 排版图，九机位为：
`① 正面全景 ② 左前斜拍 ③ 右前斜拍 ④ 正左侧 ⑤ 正右侧 ⑥ 中央平视主机位 ⑦ 门口朝内 ⑧ 靠窗朝内 ⑨ 高位俯视`

**关键道具检验 4 项**：① 造型符合时代背景 ② 材质颜色结构清晰 ③ 无明显变形/多余零件 ④ 方便佩戴与互动

**分镜关键帧三段式**（每条分镜提示词按此顺序组装）：

```
【资产一致性约束】保持参考图中{角色}的五官/脸型/发型/妆容/服装/配饰一致；保持参考图中{场景}的{结构}一致
【画面内容】{什么时间}，{谁}在{哪里}{做什么}，{什么情绪}；人物表情{具体描述}
【构图机位角度】采用{景别}，摄像机位于{位置}，以{平视/微仰/俯视}{斜拍/正拍}，画面同时展示{人物}、{场景元素}
```

> **画面五要素**（缺一即不合格）：什么时间 + 谁 + 在哪里 + 做什么 + 什么情绪。

**图生视频公式**：`{人物}正在{核心动作}，动作{速度节奏}。先{动作1}再{动作2}，表情{情绪}，视线看向{目标}。镜头{固定/缓推/跟随/平移}。场景中{灯笼/发丝/衣袖/烛火}轻微自然运动。`

## 14. AI 生成可行性诊断（吸收自 xq359 · 按实际能力与失败选路线）

分镜写完后，对承重画面先核**当前 provider/adapter/version 的实际能力、可用参考素材与后期条件**，再看本项目是否已有对应失败。下列 5 类只是需要核验的任务类型，不是「不可生成」清单；能力与素材能支持时保留核心看点和关键过程，只有真实限制或具体失败出现时才拆镜、换输入或交后期，且改法仍须兑现该段承诺：

| 需核验任务 | 先核什么 | 保留内容的执行路线 |
|---|---|---|
| **群戏**（多人同框且各有动作） | 当前模型的人数、身份与动作稳定性；角色参考和合成条件 | 能稳定交付则按原调度直拍；否则分层/分镜生成再合成，用声音与反应镜补空间，但保住群体规模、关键人物与事件结果 |
| **复杂动作**（打斗缠斗、关节技、精细手部操作） | 动作参考、首尾状态、多模态能力及具体畸形/穿模失败 | 优先用相称动作参考或分段完成；失败时拆到可读的准备、接触、结果镜或后期衔接，不能只剩前后两张而丢掉该段承诺的关键过程 |
| **文字画面**（报纸/屏幕/信件/招牌上的字） | 当前文字生成能力、可用原图/版面资产与后期合成 | 有合格文字资产则作为参考或后期贴入并保住阅读动作；实际乱码时再把文字层交后期，不默认改成台词/旁白而删除观众必须看见的证据 |
| **精确物理交互**（倒水、系鞋带、写字、递物接物） | 道具端点、手部/动作参考、接口控制能力与具体失败 | 能力允许时完整表现关键接触；不稳时换动作视频/首尾帧、拆到承担关键步骤的镜头或后期完成，不能自动移出画外或从交互完成后起镜 |
| **变身过程**（变装/变身的连续中间态） | 变身前后资产、中间态设计、当前时长/参考能力与实测失败 | 过程是核心看点时保留可读阶段并给足实际时长；只有中间态已失败或接口受限才用遮挡、分镜或后期桥接，仍呈现承诺的变化过程与结果 |

> **能力限制改变执行路线，不改变内容承诺（v1.7.3 增）**：拆镜、换输入或后期是为保住叙事功能与关键过程，不是预先删掉难拍内容。刀落下、物件被交出、文字被读到或人物完成变身若是该段承诺，就必须由画面或经批准的后期路径成立；只有经当前事实允许，才可改变结果本身。

> 动作戏另叠加打斗规范（跨 Skill 引用：drama-crew/references/genre-and-fight-rules.md，读不到时用本文件「起手→交锋→受击→结果」摘要）与第 6 节运镜四原则。诊断结果由沈砚归档，作为 QC「平台/载体错位」判定输入与景川返修依据（制作团内闭环：诊断与返修由沈砚/景川/严恪分担，不跨团调 crew 角色）。

## 15. 草图画板规范（文生分镜图模板 · 吸收自 DeepWhite 草图故事板）

**用途**：把分镜总表转成**可直接喂给文生图模型的"故事板图片"**——分镜图作为图生视频的参考图（首帧/参考）。丹青出图、景川在提示词中引用时按本模板执行。

**故事板图片整体结构**（自上而下）：
1. **全局信息区（顶部）**：整页通用信息，一句带过（镜头数/场景/统一风格），不写长段。
2. **色卡区**：一排可视化色块（**4-6 个**）统一本段画质颜色——必须画出色块，不只写色名。
3. **箭头图例区**：注明「红色实线箭头 = 人物/物体运动方向」。
4. **单镜头面板（每镜一块）**：
   - 顶部信息栏：`镜头编号 / 景别（WS/FS/MS/CU/ECU）/ 机位角度（平视/俯拍/仰拍/侧拍/背拍/过肩/主观）/ 运镜（固定/推/拉/摇/移/跟/环绕/手持）`
   - 分镜草图区：**黑白线条简洁草图**，面积大于文字区；有运动必须画红色箭头标方向；文字只保留草图表达不了的镜头控制项。

**电影制作板（可选，整段 16:9 视觉规划）**：共享创意指导（顶部栏：镜头数/统一调色板/环境）→ 角色多角度参考（正/背/侧/特写/放松姿态 + 服装配饰）→ 环境与场景（含**俯视移动路径 + 机位标注**）→ 故事板 6 帧（每帧含镜头类型/大小/运动/动作情绪简述）→ 灯光情绪备注 → 情绪关键词块 → 音频音调指示 → 电影摄影笔记。

**30 秒专项四区参考总表（可选）**：单张 16:9 图分成角色三视图 / 关键道具 / 三个关键分镜 / 纯场景四区，供 prompt-assembly Block 1 绑定。只使用已生成且可达的资产/Panel 编号；它是普通参考而非首帧。已有多图分别承担角色、首帧、环境职责时直接沿用，不强拼总表；一镜到底项目不因“三个关键分镜”起排建议强拆三镜。

**图生视频引用话术**：只引用实际 provider 已接收的素材标签与故事板 Panel，并写清它控制的构图/动作职责及不控制项；没有真实引用时按文字资产描述，禁止造 `@图片1`。模型卡不支持音频时才加「无音频」，不用故事板时完全省略引用。

## 16. 叙事目的列 + 时长双维估算（v1.7.0 新增 · 吸收森海分镜法）

> 每个镜头必须能回答"**为什么这个镜头必须存在**"——不是"好看"，而是"为什么在这个时刻出现"。答不上来时先回查隐性价值（关系位移/秘密距离/情绪落地，见 prompt-assembly §2.5 三无镜回查口径）——显性隐性都立不住的镜头 = 删除或合并进相邻镜。

**叙事目的七分类**（分镜总表「叙事目的」列按此填，写法必须具体到视听手段：✅"用背对背构图展现两人疏离，为冲突铺垫"；❌"展现内心矛盾"没说怎么展现、"推进剧情"所有镜都在推进）：

| 目的 | 说明 | 典型用法 |
|---|---|---|
| 建立 | 建立空间/时间/情绪 | 开场镜头、环境介绍 |
| 推进 | 推动剧情向前 | 动作反应镜头 |
| 揭示 | 揭示关键信息 | 证据发现、真相暴露 |
| 强调 | 强调重要时刻 | 高潮表情、关键道具 |
| 过渡 | 连接两个场景 | 空镜、转场 |
| 情绪 | 传递情绪而非信息 | 慢镜头、定格、延展 |
| 反射 | 角色内心外化 | 反射映像、主观镜头 |

**时长双维估算**（分镜总表「时长」列的填法依据，两维交叉取值）：
- **按叙事目的**：推进/升级 2.5-3.5s（最快）｜交代建立 4-5s｜情绪氛围 4-5s｜转折翻转 5-7s｜升华主旨 6-10s（最慢）
- **按景别**：特写 2-4s｜中景 3-5s｜全景 4-5s｜远景 5-7s
- 拆入路由后的视觉时间线（通用【画面内容】/30 秒专项 Block 7）时按 prompt-assembly 时间块纪律合并：时间块以动作或意义的自然边界、观众可读性与目标模型能力为准；短块若已独立完成信息可以保留，与相邻块同属一条动作链且合并后更清楚才合并，不为凑固定秒数硬并；各块加总仍须等于生成时长。

**导演意图两字段（每场一填，进分镜总表批头）**：
- **关键信息揭示**：本场核心信息「观众知道? 角色知道?」；在该字段内标 `show_now` / `withhold_now`，前者写本场允许观众读到的最强结论，后者写仍须保留的未知。观众知道+角色不知道=悬念；角色知道+观众不知道=反转原料；
- **禁止出现清单**：把 `withhold_now` 对应的不许提前出现的表情、道具状态、字幕、声音或构图写清，防 AI 生成与终编时泄底；不得为隐藏信息改写剧本正典。

> **信任观众（v1.7.3 增 · 总判断）**：观众能从两个镜头的对比里读出的东西，不需要第三个镜头去解释；角色停顿、误判、回避的镜头是给观众留的参与空间，不是废镜。剪掉「观众已经懂了」的镜，保留「观众正在懂」的过程——解释性插入镜通常比它想澄清的问题更糟。

**可剪性（v1.7.4 增 · 判断口径，非覆盖清单）**：可剪性不是每场固定拍全景/中景/近景/正反打全套，而是在**重要动作、反应或台词附近**给剪辑留自然选择。通常值得考虑的时机：一次表演或生成结果可能不稳定；某句台词既可落在说话者也可落在听者反应上；动作跨镜衔接容易跳变；重要信息可能需要早一点或晚一点揭示；需要用手部/道具/环境/旁观者反应藏接缝。相邻镜之间给动作与对白留少量重叠，剪辑才有调整空间——但不为「覆盖」生成没有叙事价值的重复角度，重叠是有目的的余量，不是保险费。

**连续性不止服装道具左右（v1.7.4 增 · 判断口径）**：跨镜还要保持**情绪连续与注意力连续**——相邻镜头应能回答：人物刚才在看什么？他听见了什么？情绪走到哪一步（在压着/在准备爆发/已作出决定）？下一个镜接的是同一反应，还是有意跳过一段时间？动作完全一致但情绪突然归零，同样是不连续。反过来，手的位置略有出入但表演与意义顺畅，通常不值得为表面完美牺牲最好的一次表演——连续性服务于理解与感受，不服务于逐帧比对。

## 17. 集边界制作合同（集首与集尾的视听执行 · v1.9.0 增 · v1.9.1 裁量收口）

> 剧本端（drama-crew）已规定每集开头 3 秒钩子与结尾卡点（writing-craft §2/§11）；本节只管这两端**落到分镜与提示词时怎么做**，不重复剧本判断。观众划走发生在集首与集尾两个瞬间，这两端的生成优先级高于集内常规镜头。

- **集首三问（E01 与每集通用）**：①**第一镜是否冷开场**——直接落在冲突/悬念/反差的画面上（情绪峰值或动作中段），**禁 logo/标题卡开头，禁无叙事功能的空镜占位建立帧**（建立信息塞进第一镜的背景层，不单独占一镜）；**环境本身承担威胁/线索/冲突/尺度关系时允许环境镜头冷开**（与 dim-shot-size「空镜合法口径」一致——禁的是占位，不是空镜本身）；②**首帧是否按「首帧即起始物理状态」精调**——只有构图、主体可读性或动作起势存在真实不确定时，才做少量单变量对照；第一版已经清楚就停止，不为凑版数继续生成，对照调用计入本批已批准预算；③**无声音是否成立**——静音看第一镜，情绪是否还读得出（大量观众静音刷到，字幕钩子+表情张力必须扛住静音测试）。
- **集尾钩子的视听执行**：①结尾选型按 shot-contract 六类落（Reveal-punch/Crisis-cut 等），但**钩子画面本身给足可读时长**——悬念揭晓后的反应镜/危机逼近的逼近镜应留到观众读完揭示或反应、情绪完成一次落点，再按表演、台词、音乐与整体节奏微调；预览时长只作剪辑起点，不作通过门槛，禁在情绪峰值硬切黑场；②集尾最后一帧保持**情绪未收束的表情或未完成的动作**，不用平静收势帧；③生成式 AI 显式标识应覆盖**视频起始画面与播放周边适当位置**并保留隐式元数据；使用人工智能技术生成、制作的微短剧另在**每集明显位置**添加提示标识。审批编号不由制作侧生产：**仅在上游已提供正式审批结果与对应编号时**，才按分类原样植入片头明显位置并标注剧名；**制作侧不申请、不推断、不生成、不预填审批编号**，内部样片不放审批编号占位，也不因缺编号改变钩子镜头。
- **跨集首尾衔接（连看体验）**：下一集首镜与上一集尾镜**不要求画面字面连续**（跨集跳接是观众默认语法），但**情绪强度必须可逆推**——上集尾是崩溃，本集首不能从无关日常冷启动；合法接法二选一：**直接续压**（崩溃→救援无效）或**有效反差**（崩溃→表面平静，情绪在憋，观众知道要爆）。禁上集尾与本集首情绪类型无关（崩溃→欢快日常 = 追更断点）。
- **集内风格值守**：每集沿袭全剧风格母版（§8）与既定色调之外，允许**集级情绪微调**（本集整体偏冷/偏暖跟剧情阶段走），但同一集内色调统一；跨集色调节奏变化的幅度 ≤ 母版允许的差异项范围，观众感知应是「剧情变了所以色调变了」，不是「换了个剧组」。
- **批量生产优先级（execution 多集排产时）**：先做 E01 全流程验证（资产/风格/抽卡系数基线）→ 用户确认后再批量；批量阶段**同角色镜头集中生成**（同角色跨集镜头一批跑完，最小化风格漂移），集间空档期回头补不着急的镜头——顺序错 = 返工翻倍。
