# 失败图谱（严恪·QC 核查清单 + 景川投喂前自检，按需加载）

> 合并来源：seedance-2.0 failure-atlas（23 条）+ storyboard-craft 防错清单（8 条）+ ACTING 烂表演图谱（15 选 8）+ CINEDANCE 高发失败。按七类归并去重。
> 用法：`review_state=reviewed` 的常规批由严恪先跑七类快扫；命中题材风险、用户失败反馈、主评分偏低或 QC 黄红项集中时，才对命中类目逐镜深扫；`review_state=unreviewed|not_provided` 按 role-cards 严恪卡的从严合同执行。景川交付前按本批风险过一遍。

## 1. 身份漂移类

| # | 症状 | 修复方向 |
|---|---|---|
| 1.1 | 跨镜变脸/五官漂 | 回资产库锚定描述；提示词加一致性锁定句；身份参考图置顶 |
| 1.2 | 同批角色一张脸 | 身份区分门复核：按实际碰撞与当前画幅可见性补足持久区分项，并保持跨镜状态连续 |
| 1.3 | 服装/道具跨镜变 | 资产库服装字段+跨切连续性锁 |
| 1.4 | 多重曝光（人脸堆叠） | 负面提示词加「多重曝光」；逐人绑定身份与位置。多人共享一条承重行动/注意链时可同镜，不用“一镜一主体”删掉参与者 |

## 2. 空间站位类

| # | 症状 | 修复方向 |
|---|---|---|
| 2.1 | 站位含糊/左右互跳 | 站位五要素补齐；180° 轴线核对 |
| 2.2 | 空间镜像（反打镜像房间） | 反打保持左右关系；越轴插中性机位 |
| 2.3 | 视线反向/没看对话对象 | 视线锁写入；躯干与视线分开描述 |
| 2.4 | 角色与地标距离失控 | 弱词换可测量锚点（1 米内/手扶门把） |

## 3. 动作物理类

| # | 症状 | 修复方向 |
|---|---|---|
| 3.1 | 漂浮/滑步/CG 跑 | 物理锁：脚跟触地+重心转移+摩擦 |
| 3.2 | 多个独立主动作已互相干扰、关键因果读不清 | 先按当前画面与实际失败重排主次/错峰；仍互扰才拆镜。连续动作节点不等于默认切点 |
| 3.3 | 手-道具接触出现具体崩坏/穿模 | 核当前输入、参考与模型能力，换动作参考、拆到可读步骤或交后期；保住已锁关键接触与结果，不因复杂或多人就预先移出画外 |
| 3.4 | 动作后的身体/物件状态与已锁结果不符 | 只补本段已承诺的疲劳、伤态、形变或无伤稳定结果；没有新增代价不构成缺陷，不强加喘息、踉跄、手抖或破坏 |
| 3.5 | 手持道具跨镜换手、消失或无交接落点 | 按 asset-library 的占手与生命周期回查起始手位→交接/放置→跨镜持有者或精确位置；画外不等于消失，不删已锁道具 |
| 3.6 | 竞赛/载具只有欢呼蒙太奇，已锁路径、接地/承载、控制者或判定结果读不清 | 回 dim-action 补器具身份、有效动作、对手响应、运动路径/支点与可见判定证据；不改输赢 |
| 3.7 | 工序/维修跨切复原、缺件却凭空完成，或多人协作被压成单人特写 | 回上一切点核同一物件、工具接触面、占手、进度与交接；保留共同动作链，只有具体失败才拆镜/换输入 |
| 3.8 | 动物/异种或水下/失重场被套成人类陆地步态、手指口型、脚跟落地 | 按已定形态、感知、承重方式、介质、支点与推进重写；不发明能力、伤亡或拟人设定 |

## 4. 光影类

| # | 症状 | 修复方向 |
|---|---|---|
| 4.1 | 平光无层次（flat front light） | 背光锁：主体在相机与亮背景之间 |
| 4.2 | 跨镜光向跳反 | 连续性锁：主光方向一致 |
| 4.3 | 光影与情绪脱节 | 重写光影动机，写不出换自然光 |

## 5. 表演类（烂表演 8 条高发项）

脸谱化 / 等 cue / 单一战术 / 手势复读台词 / 情绪无台阶 / 威胁预告 / 无叙事动机的机械式群体同步 / 死眼——修复见 `references/dimensions/dim-performance.md` 第③节。合唱、球队配合、仪式齐声，以及服务于实际行动的节奏、队形、交接等有意同步合法，不按此项判失败。

## 6. 音频类

| # | 症状 | 修复方向 |
|---|---|---|
| 6.1 | 音效堆砌无留白 | 只留关键音效，静默即张力 |
| 6.2 | BGM 盖台词/前景演唱，或“无BGM”误删剧情内音乐 | 对白 0dB 基准、BGM ≤-18dB；前景演唱按可懂度与乐器分层，剧情内歌唱/演奏保留实际声源、进度与接续/中断 |
| 6.3 | 全员一个嗓 | 声线矩阵 ≥2 维差异 |
| 6.4 | 唇形不对/静默者说话 | 按台词 ID 与声窗核可见说话人；L-Cut 切听者后声音延续，但听者不代动嘴，OS 不驱动口型 |
| 6.5 | 台词截断/跨剪辑重说或断音 | 按 dim-audio 核完整声窗与实际音轨；30 秒直出专项不足时先重排，仍不足则回剧情层等待裁决，不延长、拆分/分单或加速；其他时长按 dim-audio 对应任务分支处理；不平均截句，跨独立 Clip 不靠重复提示词续声 |
| 6.6 | 30 秒专项在 Block 5/7/8 重复对白/歌词，或文字音色被写成已冻结母音色 | Block 5 保留唯一逐字发声正文；Block 7 只留声音 ID/可见发声区间/进度；Block 8 只写环境、拟音、声线、剧情内音乐执行与背景 cue，母音色状态按实际试听冻结与绑定证据写 |
| 6.7 | 用普通说话 WPM/字速或 40–55 词预算认证歌唱时长，乐句/声部与画面进度矛盾 | 普通说话仍按 dim-audio 原口径；演唱改按实际乐句/参考音轨、换气、延音、重叠声部及进入/接续/中断核时，母音色不当词曲/节奏参考 |

## 7. 结构类

| # | 症状 | 修复方向 |
|---|---|---|
| 7.1 | 人物镜/动作镜空镜开场（首帧无角色且环境不承担叙事功能） | 首帧占位锁；**承担地理/时间/威胁/情绪意义的环境镜头冷开合法（与 dim-shot-size 口径一致）** |
| 7.2 | 镜头漂移（一镜多内容类型） | 拆镜；FOV 与内容类型对齐 |
| 7.3 | 复合运镜失控 | 一镜一次运动，写死时长与落幅 |
| 7.4 | 提示词出现禁用词 | 黑名单替换（见 asset-library 第 9 节） |
| 7.5 | 跨 Shot 状态重置（服装/伤口/道具变） | 跨切连续性 7 项锁（见 prompt-assembly 第 3 节） |
| 7.6 | 八段标题缺失/乱序、双交格式、时码不覆盖实际片长或声画正文重复 | 回 prompt-assembly §2，所有时长采用统一中文八段；实际调用单位与项目/接口一致，不把两次调用冒充一次 |
| 7.7 | 项目语言锁被平台默认覆盖，或八段夹带模板占位/伪造参考、Panel、场内文字设备 | 英文/中文项目按锁定语言与口音输出；只留实际生产内容，Block 6 不用写 `NONE`/`无`，参考只绑定已可达素材 |
| 7.8 | 潜入场因观众可见而让角色全知，或闪回/梦境/平行层的身份、物件、伤损、光声状态污染现实层 | 回剧本披露边界与 prompt-assembly 分层连续性：分别锁每层状态、进入/退出提示和返回继承；不默认做旧、不补历史事实 |
| 7.9 | 实际出镜故事角色因未具名/低频被并入场景，或总表用构图/空场景替代关键道具职责 | 按事件职能核 N 人 N 份独立参考；纯背景群演才并场景。总表分别核关键道具身份/状态、关键构图与纯场景区，不以图多代替职责 |
