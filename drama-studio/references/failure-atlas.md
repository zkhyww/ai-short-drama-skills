# 失败图谱（严恪·QC 核查清单 + 景川投喂前自检，按需加载）

> 合并来源：seedance-2.0 failure-atlas（23 条）+ storyboard-craft 防错清单（8 条）+ ACTING 烂表演图谱（15 选 8）+ CINEDANCE 高发失败。按七类归并去重。
> 用法：`review_state=reviewed` 的常规批由严恪先跑七类快扫；命中题材风险、用户失败反馈、主评分偏低或 QC 黄红项集中时，才对命中类目逐镜深扫；`review_state=unreviewed|not_provided` 按 role-cards 严恪卡的从严合同执行。景川交付前按本批风险过一遍。

## 1. 身份漂移类

| # | 症状 | 修复方向 |
|---|---|---|
| 1.1 | 跨镜变脸/五官漂 | 回资产库锚定描述；提示词加一致性锁定句；身份参考图置顶 |
| 1.2 | 同批角色一张脸 | 身份区分门复核（≥3 结构轴、≥2 脸部、禁词级雷同） |
| 1.3 | 服装/道具跨镜变 | 资产库服装字段+跨切连续性锁 |
| 1.4 | 多重曝光（人脸堆叠） | 负面提示词加「多重曝光」；一镜一主体 |

## 2. 空间站位类

| # | 症状 | 修复方向 |
|---|---|---|
| 2.1 | 站位含糊/左右互跳 | 站位五要素补齐；180° 轴线核对 |
| 2.2 | 空间镜像（反打镜像房间） | 反打保持左右关系；越轴插中性机位 |
| 2.3 | 视线反向/没看对话对象 | 视线锁写入；躯干与视线分开描述 |
| 2.4 | 角色与地标距离失控 | 弱词换可测量锚点（1 米内/手扶门把） |

## 3. 动作物理类

| # | 症状 | 修复方向 |
|---|---|---|
| 3.1 | 漂浮/滑步/CG 跑 | 物理锁：脚跟触地+重心转移+摩擦 |
| 3.2 | 一镜多动作打架 | 拆镜；多人动作三层制归位 |
| 3.3 | 手-道具崩坏（多人时） | 接触简化或移出画外 |
| 3.4 | 打完无代价 | 生理成本补写（喘息/踉跄/手抖） |

## 4. 光影类

| # | 症状 | 修复方向 |
|---|---|---|
| 4.1 | 平光无层次（flat front light） | 背光锁：主体在相机与亮背景之间 |
| 4.2 | 跨镜光向跳反 | 连续性锁：主光方向一致 |
| 4.3 | 光影与情绪脱节 | 重写光影动机，写不出换自然光 |

## 5. 表演类（烂表演 8 条高发项）

脸谱化 / 等 cue / 单一战术 / 手势复读台词 / 情绪无台阶 / 威胁预告 / 群体同步 / 死眼——修复见 `references/dimensions/dim-performance.md` 第③节。

## 6. 音频类

| # | 症状 | 修复方向 |
|---|---|---|
| 6.1 | 音效堆砌无留白 | 只留关键音效，静默即张力 |
| 6.2 | BGM 盖台词 | 对白 0dB，BGM ≤-18dB |
| 6.3 | 全员一个嗓 | 声线矩阵 ≥2 维差异 |
| 6.4 | 唇形不对/静默者说话 | 只有说台词者嘴唇动 |

## 7. 结构类

| # | 症状 | 修复方向 |
|---|---|---|
| 7.1 | 人物镜/动作镜空镜开场（首帧无角色且环境不承担叙事功能） | 首帧占位锁；**承担地理/时间/威胁/情绪意义的环境镜头冷开合法（与 dim-shot-size 口径一致）** |
| 7.2 | 镜头漂移（一镜多内容类型） | 拆镜；FOV 与内容类型对齐 |
| 7.3 | 复合运镜失控 | 一镜一次运动，写死时长与落幅 |
| 7.4 | 提示词出现禁用词 | 黑名单替换（见 asset-library 第 9 节） |
| 7.5 | 跨 Shot 状态重置（服装/伤口/道具变） | 跨切连续性 7 项锁（见 prompt-assembly 第 3 节） |
