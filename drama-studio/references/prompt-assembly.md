# 提示词装配规范（景川·唯一终编使用，按需加载）

> 核心命题：一个镜头同时满足景别/运镜/光影/站位/动作/表演/风格/音效多维度。
> 机制：**镜头诊断 → 维度映射 → 字段回填 → 唯一终编整合 → 九层仲裁 → 失败图谱**。
> 铁律：**并行调多个生成器=人脸漂移主因；所有维度由景川单点终编成一条提示词**。

## 1. 镜头类型 → 维度装配映射表

| 镜头类型 | 必装维度 | 选装维度 |
|---|---|---|
| 对话正反打 | 站位 / 表演 / 音效 | 景别 / 运镜 / 光影 |
| 情绪特写 | 表演 / 光影 | 音效 / 运镜 / 景别 |
| 打斗动作 | 景别 / 运镜 / 动作 / 光影 | 站位 / 表演 |
| 建立镜头 | 景别 / 运镜 / 光影 / 风格 | 音效 |
| 悬疑揭示 | 光影 / 表演 / 站位 / 音效 | 运镜 |
| 转场空镜 | 风格 / 光影 / 运镜 | — |

维度卡位置：`references/dimensions/dim-*.md`（景别/运镜/光影/站位/表演/动作/**特效**/风格/音效/**配乐** 共 10 张；特效卡仅在含法术/能量/变身等超自然镜头时装配，配乐卡在需要音乐 cue 时装配，其余按镜头类型命中）。**沈砚按命中维度 Read 卡片原文贴进景川模板；未命中不读不贴**。

**能力限制优先级（全包唯一口径）**：execution 实时 provider/adapter/version schema > 用户指定的目标模型能力卡 > 未指定模型时的通用保守默认。`planning_only` 指定目标模型时也须按能力卡规划；进入 `execution` 后再由实际调用者用本次接口实时 schema 复核并覆盖冲突项。下文的单 Clip `≤15s`、中文 `≤2200 字` 只适用于未指定模型的通用保守模式；指定模型时，时长、Prompt 长度、参考资产上限与模式组合分别按模型卡及所用接口确定，不把某一 provider 的字段或上限外推为模型通用事实。

## 1.5 三层单位定义（v1.7.2 定版 · 全包唯一口径，其他文件只引用不复写）

| 层 | 定义 | 关键约束 |
|---|---|---|
| **Shot（剪辑镜头）** | 剪辑意义上的最小叙事镜头：一镜一主动作、一镜一个内容类型 | 常规 2-6s；有明确表演/揭示动机可延长，是否拆分按叙事完整性与上述能力限制优先级判断；分镜表一行 = 一个 Shot |
| **Clip（生成片段）** | 一次视频生成调用产出的片段：单条提示词 → 单个媒体文件 | 未指定模型时单 Clip `≤15s`、英文 40-110 词/中文 `≤2200 字`；指定模型时按模型卡及 provider/adapter 实时 schema 分模式确定。**不固定含 2-3 个 Shot**——未指定模型默认 1 Shot/Clip，模型卡与接口确认支持多镜时才合并多个 Shot，总时长不得超过本次接口上限（见第 3 节多镜头语法） |
| **Prompt Unit（提示词包）** | 一次模型调用的完整提示词包：七段式正文+模型能力卡参数+资产引用+全局负面 | 对应第 2 节七段式骨架；一 Clip 一 Prompt Unit，装配自检按 §7 过一遍 |

**换算关系**：单集时长 T 秒 → Clip 数按「Shot 数 ÷ 每 Clip 实际 Shot 数」估算（默认 1 Shot/Clip；模型支持多镜时按模型上限合并），**镜头数只作剪辑节奏参考，不作生成调用公式**。分镜表、提示词清单、回传统计一律以这三层单位命名，禁止出现「镜头/片段/提示词」混指。

## 2. 七段式终编骨架（唯一最终输出 Schema）

**三层解耦视角**（吸收 manju-laoli）：①②段 = L1 全局不变量（跨镜不动）；③-⑦段 = L2 空间镜头变量（逐镜重写）；全局负面 = L3 分层排除。L1 层跨镜逐字复制，L2 层每镜新写，L3 层全项目一份。

```
① 定调参数：画幅/写实等级/风格母版继承声明/全局限制（无字幕/无变脸/无畸形/唇形同步）
② 主体细节：角色资产引用（@资产名短锚点+当前状态+服装）+一致性锁定句结尾
③ 分镜时序：[x-x秒]: 运镜+景别+主体+核心动作+限制（多镜头用 Shot 标签，见第 3 节）——**动作写可观察结果**（身体/物体/画面发生了什么：位置、朝向、速度、接触、可见的可见变化），不写心理与情绪名词；情绪由肌肉与姿态结果承载（与 dim-performance 防崩禁忌同源）
④ 光影色调：光源+色温+方向+聚焦+情绪效果+氛围（全局一次，微调标注）
⑤ 物理与站位：站位五要素/物理锁勾选项/空间锚点
⑥ 音频设计：台词 ID/说话人/对白·OS·VO 类型/逐字正文（唯一位置）+声音指纹与母音色绑定+命中的表演变化+环境音/关键音效时间/BGM（按需）
⑦ 目标落点：本镜结尾选型（Resolve/Extension anchor/Loop seam/Hero hold/Edit point/Reveal-punch）
```

**五字段 → 七段式映射**：storyboard-craft §2 的五字段只用于内容核对——「画面动作概述」进入③并为⑦提供叙事落点；「画面构图+机位」拆入①/③/⑤；「动作」进入③的时间轴；「音效」进入⑥。角色资产、风格母版与光影分别补入②/①/④。核对完成后只交付七段式，不并列输出两套固定顺序。

**说话文本单一真源**：同一句对白、OS 或 VO 的**逐字正文只出现一次**——放在⑥音频设计的对应说话条目中，并沿用 crew 口径 `OS=角色内心独白`、`VO=画外音`。③视觉时间线只写说话人/声音类型、口型区间、动作、反应与时间，不再复制台词全文；需要强调重音时引用台词 ID 或关键词，不把整句再贴一遍。OS 不驱动角色说话口型，VO 的画外发声者不借听者动嘴；已有 OS/VO 不被通用「无旁白/无画外音」覆盖。声音设计回注⑥后才冻结正式对白视频提示词；候选音色生成明确标预览范围。这样既保留口型与表演控制，也避免两份文字在修订时互相打架。

**长度约束**：未指定模型时，单 Clip 提示词英文 40-110 词 / 中文 `≤2200 字`、覆盖 `≤15 秒`，超长出下一条；指定模型时按能力限制优先级逐模式核对 Prompt 与时长上限，不使用统一字符或秒数上限。
**画面超载风险**：不按秒数机械数事件元素。若同一时间块出现多个彼此独立的主动作、空间关系改写、视线转移或必须分别读清的因果结果，先判断能否收成一条主动作链；收不拢或模型无法稳定交付时才拆镜。背景细节与同一因果链的连续反应不因“数量多”自动判超载。
**时间戳连续无缝**：多镜头/多段时，镜头 N 的结束时间 = 镜头 N+1 的起始时间，不重叠不留空。

## 2.5 节奏 → 镜头数映射（镜头数量自适应，不做固定值）

> 下表只是在没有项目实测时的首轮排片参考，不是镜数、时长或通过门槛；表演完整性、信息可读性、目标模型能力与成片节奏优先，项目跑出可用基线后按实测调整。

| 节奏类型 | 通用 15 秒样例内镜头数 | 单镜时长 | 适用 |
|---|---|---|---|
| 快节奏（打斗/反转/追逐） | **6-10 镜** | 1.5-2.5s | 高潮、对抗、打脸瞬间 |
| 中速（对话/攻防） | 3-5 镜 | 3-5s | 常规叙事 |
| 慢节奏（情绪/氛围/留白） | 2-3 镜 | 5-8s | 虐点、悬念、情绪沉淀 |
| 一镜到底 | 1 镜 | 10-15s | 长镜头表演、独白、压迫感静置 |

**时长预算参考**（吸收 manju-laoli）：总时长 T 秒按「Shot 数 ÷ 每 Clip 实际 Shot 数」估算 Clip 组数（默认 1 Shot/Clip；模型支持多镜时按本次接口上限合并）。未指定模型时单 Clip `≤15s`；指定模型时按能力限制优先级逐模式确定。单镜常规 2-6s，有明确表演/揭示动机可延长；按剧本情绪曲线把快/慢节奏分配到对应段，**禁止场景 1:1 平均压缩**——镜头数只作剪辑节奏参考，不作生成调用公式。

**镜头三任务**（每镜通常至少完成一项，三无镜头回查再定去留）：改情绪 / 推动作 / 加压力。**判断方法**：查无三任务时先别急着删——问「这一镜观众看见什么」（storyboard-craft 导演判断），若它在做隐性价值加载（关系位移/秘密距离/情绪落地，见 story-structure §2 缓冲段），把它改写成立，而不是当废镜剔除；显性隐性都立不住的才是装饰镜。
**悬念披露权限（内嵌现有导演意图，不新增 Schema）**：对关键事实标 `show_now` / `withhold_now`——前者只允许本镜应让观众读到的最强结论，后者列出本镜必须避免提前泄露的表情、道具状态、字幕、声音或构图信息。两者共同约束③动作与⑦落点；隐藏信息不能靠改写正典事实实现。
**取舍优先级**（Murch 剪辑六律，镜数或时长承载不下时据此裁量）：情感 > 剧情 > 节奏 > 视线 > 构图 > 空间。这里表达的是判断顺序，不把助记百分比当评分公式。

## 3. 单条多镜头语法

- **仅在目标模型卡与本次接口同时确认支持多镜时**，单 Clip 才可含 2-3 个真镜头：显式 `Shot 1: ... / Shot 2: ...` 标签，Clip 总时长与每镜可用范围按能力限制优先级确定；未指定模型或未确认支持时 1 Clip = 1 Shot
- 即梦等中文流程用【时间轴】`0-3s: ... / 3-7s: ...` 骨架——**两种语法不混用**
- 跨 Shot 连续性锁：同角色表/同地理/同银幕方向/同视线/同光向/同服装状态/同伤口道具状态
- 剪辑类型工具箱：HARD CUT / SMASH CUT / MATCH CUT / INSERT CUT / REVERSE CUT / WHIP CUT 为默认六式；**转场按意义选择（v1.7.4 增，陆离同步）**：叠化=时间流逝/记忆渗入/两状态短暂重合、淡入淡出=明确段落或时间边界、遮挡/甩镜/动作接切=让画面运动完成过渡——判断标准是转场**是否改变了时间、空间、情绪或意义**，六式内按功能选，六式外按意义取用；不为显技巧加转场，也不因工具箱拒绝当前场景真正需要的表达（平台硬性限制除外）

**时间划分先行**（吸收 deepwhite PROMPT_TIMING，防时长失控）：
1. 每条提示词**先划时间块**（Shot/时间轴），再写内容——不是写完后数秒数。
2. **内部时长加总 = 生成时长**：单条内各块时长相加必须等于该条生成时长（如 10s 条 = 4s+3s+3s），块总和不符=未装配；块时长按上述能力限制优先级确定，指定模型时还须区分文生/图生/参考生/首尾帧等调用模式。
3. **单块最小 2s**（过碎=模型跟不住）；**切点优先跟着意义走（v1.7.3 增 · 判断口径）**：块边界优先落在**意义变化处**（谁占上风变了/谁懂了/谁慌了/话题换了），秒数整齐是手段不是目的——意义没变时同一动作链留在同一块（与 dim-action「动作链四段式」同口径），意义变了哪怕不足 2s 也与相邻块合并处理而不是硬撑时长；**场景内重计时**：切场景后时间轴从 0 重排，不延续上一场景的剩余秒数。
4. 禁过度拆分：一个 5s 内能讲完的动作，不拆成两条（拆分=衔接风险翻倍）。

**条件式故事板引用**（吸收 deepwhite STORYBOARD_ASSETS，防提示词污染）：
- 故事板引用**用才写**：当且仅当该镜头确实依赖某资产/某参考图时，才写 `SB-xx` 或 `@资产名` 引用；不用的**完全省略，禁止占位**（空引用=污染提示词，模型会抓取无关内容）。
- 引用统一用资产 ID（asset-library 体系），不写描述性重复（资产已在库，引用即可）。
- **参考图控制边界合同（v1.8.0 增）**：每张参考图写清**锁什么**（身份/构图/风格/动作，以其一为主职责）与**明确不锁什么**（其余维度允许模型发挥）——多参考时各图主职责尽量不重叠；确需共同控制同一维度时，必须写明**优先级、融合关系，以及发生冲突时保留哪张参考**，防止多图争夺同一职责导致崩坏；与 §4「参考生/首尾帧写明各参考素材分别控制什么」同源。

## 4. 双版本提示词与生成模式职责

| 版本 | 结构 | 用途 |
|---|---|---|
| 文生图 | 画风前缀+场景资产+人物资产+动作表情+构图光影+画质参数 | 出首帧/关键帧/资产图 |
| 图生视频 | 精简主体动作+运镜动态+环境氛围变化，**控制动作幅度防崩坏** | 首帧驱动生成 |

**生成模式中的文字职责（v1.7.4 增 · 只写会改变当前镜头的内容）**：三种模式的文字分工不同——**文生视频**：文字建立主体/场景/构图/动作/光线/运动，各维度都要写；**图生视频**：静态信息已由图片提供，文字重点写主体如何运动/环境如何响应/摄影机是否动/运动的速度节拍与结束状态/哪些必须保持不变，**不必重新堆满首帧已清楚表达的内容**；**参考生/首尾帧**：写明各参考素材分别控制什么（身份/风格/构图/动作），防多参考争夺同一职责。控制要求越高描述越具体，允许探索时有意留出解释空间——不是每条提示词都填满全部维度。

**首帧即起始物理状态（v1.7.4 增）**：图生视频的输入图不是漂亮参考图，它已经在下指令——构图、外观、光线、空间与**隐含运动**（运动模糊暗示正在移动/飞起的尘土暗示车辆行驶/前倾抬腿挥手暗示动作方向/衣发与环境的方向线影响运动判断）都由首帧先行决定。首帧暗示「高速前进」而文本要求「完全静止」= 模型同时收到两个相反指令：此时**调整首帧或顺着已有运动设计**，而不是不断给文本加锁对抗首帧。

**首尾帧边界**：**首帧只写开始时已经成立**的身份、构图、位置、光线、道具状态与动作起势，不把本 Clip 中途才发生的结果偷塞进开场；**尾帧只写目标终点**及必须保留给下镜的可见状态，不复述完整过程，也不提前写下一镜尚未发生的动作。过程变化只写在③时间线中。

**全局负面提示词**（全项目复用一份）：畸形手指/面部崩坏/五官扭曲/多肢体/穿模/低画质/水印/字幕/多重曝光（人脸堆叠时专用）。**负向约束仅 5-10 项**，只写本项目最可能的失败点——堆得越多，模型注意力越被稀释。

**失败先查指令打架（v1.7.4 增 · 与重拍协议衔接）**：结果不稳定不一定是提示词不够长，常见根因是**视觉指令互相冲突**——首帧姿势与目标动作方向相逆（见本节「首帧即起始物理状态」）/ 同时要求大动作与面部绝对稳定 / 摄影机运动与主体运动互相抵消 / 短时间内塞多个需完整完成的动作 / 参考图之间人物服装视角光线不一致 / 既要求严格复现又要求自由发挥 / 抽象情绪与可见动作无对应。命中时**优先删除冲突项与次要要求**，而不是继续叠加形容词与负面限制（重拍协议「一次一变量」也据此定位变量：先删冲突，再谈替换）。

**强关联分镜成组**：同场景连续镜头只有在**实际 provider 支持**视频续接、首尾帧或可复用尾帧输入，且该镜确需字面画面连续时，才成组写首帧/尾帧/上下衔接说明，并把已验收尾帧作为下一镜输入。provider 不支持、只支持参考图或本镜只需语义连续时，改用资产 ID + 接续状态块传递身份、位置、方向、情绪与道具状态，不虚构「尾帧即下一镜首帧」能力。

**三条制作合同（v1.8.0 增 · planning 与 execution 通用）**：
- **时长语义**：分镜总表的时长 = 导演最终使用的成片时长；技术生成时长可因模型缓冲略长，**不得为填满技术生成时长而新增内容**——多出的时长剪掉，不是加戏。
- **技术切分服从叙事**：Shot/Clip 的技术切分服从连续表演与叙事功能——切点优先落在动作链自然段边界与意义变化处（与本文件 §3「时间划分先行」同口径）；禁止为凑生成时长上限把一个完整表演硬拆或硬并。
- **参考图控制边界**：见本文件 §3 末条合同——每张参考图锁什么、不锁什么写清；主职责尽量不重叠，确需共同控制同一维度时写明优先级、融合关系与冲突保留项。

**生成成本与抽卡预算（v1.9.0 增 · v1.9.1 裁量收口 · execution 启用时生效，planning_only 豁免）**：

> AI 视频的抽卡成本随模型、镜头复杂度、首帧质量与目标精度变化，不把通用经验次数当项目配额。重拍协议（shot-contract §5）管**单镜出废片后怎么办**，本合同管**开抽之前怎么把废片率压下来**。两级预算配合：先降废片率，再按项目预算与故障性质决定继续、改路或暂停。

- **分层生成路线（便宜验证、贵价定稿）**：结构验证（构图对不对/主体对不对/动作方向对不对）用低价或免费额度先跑——结构错的图不值得花高价视频积分；结构过关后**冻结提示词**再上目标模型出正式素材。便宜模型上反复润色措辞是白调（调的是它的怪癖），冻结后换模型只微调模型敏感的那一句。**冻结后换目标模型先判兼容（v1.10.1）**：Shot/Clip 结构、单镜时长、参考资产数量与类型、首尾帧、画幅、音频能力全部兼容才只微调措辞；任一不兼容时**仅受影响 Shot/Clip 对应提示词失效**（重拆 Clip/改参考组合/换音频方案），未受影响兄弟镜头继续有效；按 SKILL.md「换目标视频模型」行同口径执行——「只微调一句」只适用于能力对齐的模型间切换。
- **抽卡分级纪律（同一镜头连抽时的归因）**：同样提示词结果不同，先判断是模型随机波动还是同一故障在稳定复现；接近目标、预算仍有余量时可**原样再跑**（不加词），同一故障稳定复现或反复出现时即视为提示词、首帧或模型能力问题，进入重拍协议「修复四件套」。调整仍一次只验证一个变量；先补缺失信息还是先删冲突项，按故障证据选择，不机械规定先后。
- **静态图先审（生图便宜生视频贵）**：图生视频路线下，先用静态图确认角色/构图/风格，确认后再投视频生成——静态图返工成本远低于视频废片。
- **批级预估（沈砚派单前口算一行）**：优先采用用户已授权的调用次数或成本上限；未给预算时，用 E01/已完成批次的「实际调用次数 ÷ 可用 Shot 数」作项目基线，再结合本批镜头复杂度与工具单价给出预计区间并标明假设。没有项目实测时只给试算区间，不把行业经验写成调用配额。达到用户批准预算或工具/API 硬上限即暂停并回沈砚报告已用量、余量与换首帧/换模型/拆镜选项；复用既有 execution 确认，不新增弹窗，**禁不设上限的连续盲抽**。
- **成本记录消费**：execution 六字段追踪（SKILL.md 第 2 步）中的「尝试次数 + 实际成本」按批汇总进陆离批次汇总——抽卡系数显著高于预估的镜头，标记其提示词或首帧为「高耗模板」，下批优先修它（省的是真钱，不是指标）。

## 5. 冲突九层仲裁

维度要求打架时，按优先级牺牲后者：**安全 > 平台限制 > 用户硬性要求 > 参考图契约 > 连续性 > 物理因果 > 镜头剪辑逻辑 > 风格装饰 > 默认值**。
示例：风格母版要求宽画面但平台只有 9:16 → 平台赢；运镜想复合但物理不可读 → 物理赢；高速运动+表情清晰冲突 → 物理因果赢（快就保不了脸，保脸就降速）；同镜想变焦段造氛围 → 连续性赢（景深不可突变，靠机位不靠换镜头）。

## 6.5 物理措辞纪律（全部段落通用 · v1.12.0 增，消化情绪导演方法论）

> 七段式管结构，本节管**每个句子的措辞**。AI 视频模型执行不了修辞和精确物理值——两类词都是废指令，还会挤占有效 token。

**两禁**：
- **禁文学化修辞**：比喻/拟人/象征/夸张一律换成物理世界的字面描述——「心如刀割」→「双手按住胸口，呼吸急促，面部肌肉扭曲」；「杀气腾腾」→「下颌前伸，眼神直视前方固定一点，嘴角下拉」；「城市在夜色中沉睡」→「夜晚，建筑物静止，街道无人」。
- **禁 AI 执行不了的精确物理值**：毫米/厘米/厘米每秒/赫兹/精确角度/小数比例一律不写——模型无法验证这些数值，写了等于抽签。改用**相对化表达**。

**五维相对化正向措辞**（写什么，而不是只拦什么）：

| 维度 | 相对化写法 |
|---|---|
| 光线 | 光源位置（左/右/顶/侧后方）+ 明暗对比（面部大半阴影/半明半暗）+ 色温倾向（暖黄/冷蓝/中性白），不用 K 值小数 |
| 动作 | 起点→终点（身体部位 A 移动到 B）+ 耗时感（约 X 秒完成/缓慢/匀速/骤停）+ 力度质感（轻柔/用力/爆发/控制） |
| 表情 | 具体肌肉运动（皱眉肌隆起/眼轮匝肌收缩/嘴角下拉）+ 面部区域变化（额头横纹/眼角皱纹）+ 皮肤状态（苍白/泛红/出汗） |
| 声音 | 音量质感（耳语/低声/嘶喊）+ 音质质感（沙哑/颤抖/劈裂）+ 混响质感（干涩/空旷/回声），不用 dB 小数 |
| 空间 | 身体参照（一臂距离/一拳之隔/指尖到手腕）+ 画面比例（人物占画面 1/2 或 1/10）+ 方位关系（左/右/前/后），不用毫米级描述 |

**与现有条款的关系**：§2③「动作写可观察结果」、storyboard-craft §3 表情拆解公式是同一纪律的分维度细化；asset-library §9 禁用词黑名单管资产层空话词，本节管全段落措辞——互补不重叠。装配自检（§7）新增对应核对项。
