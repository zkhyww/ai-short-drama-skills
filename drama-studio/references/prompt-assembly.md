# 提示词装配规范（景川·唯一终编使用，按需加载）

> 核心命题：一个镜头同时满足景别/运镜/光影/站位/动作/表演/风格/音效多维度。
> 机制：**观看重点与表现机会 → 镜头职责 → 方法/维度选择 → 字段回填 → 唯一终编整合 → 九层仲裁 → 失败图谱**。
> 铁律：多生成器并行可能增加身份与风格漂移风险；**所有维度仍由景川单点终编成一条提示词**。

## 1. 镜头类型 → 维度装配映射表

| 镜头类型 | 必装维度 | 选装维度 |
|---|---|---|
| 对话正反打 | 站位 / 表演 / 音效 | 景别 / 运镜 / 光影 |
| 情绪特写 | 表演 / 光影 | 音效 / 运镜 / 景别 |
| 打斗动作 | 景别 / 运镜 / 动作 / 光影 | 站位 / 表演 |
| 建立镜头 | 景别 / 运镜 / 光影 / 风格 | 音效 |
| 悬疑揭示 | 光影 / 表演 / 站位 / 音效 | 运镜 |
| 转场空镜 | 风格 / 光影 / 运镜 | — |

六类基础镜型不是场面穷举。先从剧本的实际参与者、对象、过程/阶段、回应、状态与披露边界判断当前问题，再用下表把特殊机制落回同一套维度；同场可与基础镜型组合，不新增镜头类型、字段或流程：

| 实际机制命中 | 加装/重点维度 | 路由后正文必须可核什么 |
|---|---|---|
| 歌舞、演奏、戏曲 | 动作 / 表演 / 音效；有剧情内音乐再加配乐，换位/舞台多机位加站位与运镜 | 歌声/说话身份、实际曲目与音轨版本/区间、发声人与声部、可核实力证据；舞步短句/重拍/支撑与换位路线共享乐句进度，切机位不重唱或重置队形。只存在歌词时标乐句时间待锁，不造 BPM、试听或口型通过；普通后台对白/无声热身不装完整声乐专项 |
| 体育竞赛、载具 | 动作 / 站位 / 景别 / 运镜；按需音效 | 器具/球/车辆身份、运动路径、接地/承载、控制者/乘员、判定证据与已锁阶段结果 |
| 烹饪、工艺、维修等精细操作 | 动作 / 景别 / 站位；按需音效 | 同一物件与工具的接触面、占手、步骤进度、前后状态和去向；缺部件不凭空恢复 |
| 潜入、伪装 | 站位 / 光影 / 音效 / 表演 | 主体与观察者/监控/反射的可见性、声源、路线、伪装前后身份及谁能知道什么 |
| 多方谈判、庭审、仪式 | 站位 / 表演 / 音效；按需景别 | 发言/行动主体与对象、注意焦点、证物/座次/阶段、话轮或有意齐声及实际回应；只继承已定权限/程序，不编法律规则 |
| 动物、异种互动 | 动作 / 站位 / 表演；按需特效/音效 | 已定形态与肢体、承重/牵引/接触、可感知刺激和反馈；无拟人设定不套人类口型/手指/表情 |
| 水下、失重等特殊环境 | 动作 / 站位 / 音效；必要物理反馈加特效 | 介质、支点/漂浮、移动与视听范围、气泡/液体/反射等相称反馈，不硬套陆地脚跟与恒定空气声 |
| 闪回、梦境、平行时空 | 风格 / 光影 / 音效 / 站位；按需表演/特效 | 时间/空间/身份/物件状态分域、进入退出提示、声画边界与返回继承；不默认做旧或跨层污染现实 |

维度卡位置：`references/dimensions/dim-*.md`（景别/运镜/光影/站位/表演/动作/**特效**/风格/音效/**配乐** 共 10 张；特效卡在法术/能量/变身或承重物理效果需要设计时装配，配乐卡在需要背景 cue 或剧情内音乐设计时装配，其余按实际镜头职责命中）。**沈砚按命中维度 Read 卡片按需读取相关段落；未命中不读不贴**。

**空间与衔接风险覆盖映射**：无论上表类型，人物移动、道具交接、跨镜空间依赖或跨 Clip 接续命中时加读 dim-blocking 与 shot-contract §2；关键细节/反应难读、景别衔接疑点命中时加读 dim-shot-size。不要求每镜全卡齐套，命中片段随原任务注入。 明确需要动态白模验证时再读 [blender-previs.md](blender-previs.md)，按其参考职责把预演区间、占位对象与角色/道具资产绑定到当前格式；不新增平行模板，不用白模替代表演，也不把普通跨镜依赖一律升级为建模。

装配前由景川按任务入口、项目约束、当前阶段和当前创作问题写清观看重点与各镜职责，再从已有规则与本地方法为每个问题选择一个主方法；补充方法只补另一个明确缺口，已批准部分不重选。维度卡与方法只取本镜承担功能所需条目；同一方法的触发、传播、结果或余波可由不同镜头/阶段分别承担。用途、适用/排除条件、来源/版本、落位、证据与失败返回留在派单注入说明，不复制进本节可提交正文。默认同一执行者按景川职责直接判断并终编；只有实际拆分时才传必要方法与事实定位，不另写派单过程。

**能力限制优先级（全包唯一口径）**：execution 实时 provider/adapter/version schema > 已选目标模型与适配器能力卡（用户指定或项目默认）> 用户明确暂不选型时的通用保守规划。本次明确要求优先于已批准项目设置，二者均无对应值时才用相容默认。视频分辨率未指定时默认 **720p**。Dreamina **未指定模型**时，按单次 Clip 请求时长选：**4–15 秒用 `seedance2.0fast_vip`；>15–30 秒用 `seedance2.5`**。模型与单次时长都未给时仍可建议 `seedance2.0fast_vip` / 15 秒一组；单集总长不用于代选单次模型。显式模型不兼容或时长不受支持时报告差异，不静默换模型、改时长或拆分；显式且兼容的模型/分辨率继续保留。按实际选型加载命中卡；采用 Dreamina 执行 Seedance 时，`planning_only` 也加载 Seedance 与 Dreamina 两卡相关能力段落；正式执行仍须能力、登录、配额与预算预检，默认选型不等于付费授权。

输出格式先按 §2 的任务路由确定，时长、Prompt 长度、参考上限、音频与模式组合再按实际接口分别确定。Seedance 2.0 按卡为 4–15s，2.5 为 4–30s；Omni 1.1 Flash 的当前 Flow2API 卡区分文生 8/10s（默认 10s）与参考生仅 8s，不能把“Omni 10 秒”套给参考模式。**项目已锁定 30 秒直出专项与 Seedance 2.5 时，该锁优先于普通未回答默认值，不得回落到 `seedance2.0fast_vip` / 15 秒。**换时长必须重排画面及声音时间轴，不只改标题或强行加速。用户明确要求模型无关草案时才用通用保守模式，不把普通未回答当作暂不选型。

## 1.5 三层单位定义（v1.7.2 定版 · 全包唯一口径，其他文件只引用不复写）

| 层 | 定义 | 关键约束 |
|---|---|---|
| **Shot（剪辑镜头）** | 剪辑意义上的最小叙事镜头：一镜一主动作、一镜一个内容类型 | 常规 2-6s；有明确表演/揭示动机可延长，是否拆分按叙事完整性与上述能力限制优先级判断；分镜表一行 = 一个 Shot |
| **Clip（生成片段）** | 一次视频生成调用产出的片段：单条提示词 → 单个媒体文件 | 结合空间连续性、动作依赖与实际模型/模式能力确定单次时长；未指定模型时按本节默认路由。一组可含多个 Shot，不设通用镜数硬帽，不把一次提交暗拆成多次付费调用 |
| **Prompt Unit（提示词包）** | 一次模型调用的完整提示词包：按 §2 路由后的正文+实际请求参数+资产绑定 | 对应第 2 节；一 Clip 一 Prompt Unit，装配自检按 §7 过一遍 |

**换算关系**：按连续叙事与接口时长把 Shot 编入 Clip，调用数等于实际 Clip 数，重试另计；单集时长由实际使用的 Clip 片段累计，不按镜数推算。分镜表一行一 Shot，提示词清单一组一 Clip，禁止「镜头/片段/提示词」混指。 不设通用接触回避规则；必要互动按真实动作和能力设计。承诺的妆容、状态或情绪变化须在目标屏幕大小可读，前后保持同一身份并有成立的动作/时间与光源依据，不能靠换脸或无因换光冒充变化。

## 2. 统一中文八段式（所有 Clip 时长共用）

所有视频片段使用以下八段，不按 8/10/15/20/30 秒切换格式。每个 Clip 只交一份可直接提交的最终提示词；当前接口支持的时长、模式、参考类型仍须核验，统一格式不证明模型支持任意时长或精准多镜。总时长记为 T，镜头时间线覆盖 00:00 至实际 T，不写死 30 秒。旧四区块/英文八段只作既有资料兼容，发生修订时仅迁移受影响 Clip，不自动批量重生成素材。

标题默认中文，沿用项目语种与口音的逐字对白，不因中文标题翻译或改写已有台词。只有用户明确要求其他提示词语言时才等义翻译标题和说明，仍保留八段职责；不强制英文大写 BLOCK 标题。

八段固定顺序，内容按需要缩放：短片段可以一段一句；真实未使用的内容写“无”，待用户匹配的音色写“用户待匹配”，不能用“无”掩盖必需输入缺失。不重复展开项目基线或输出检查推导，所需基线应以本次接口可消费的简述/真实输入携带，不能假设跨调用自动记忆。模型请求参数与调用记录留原记录位置，不塞成第九段。图片提示词仍按图片职责编写，不强套视频八段。

```text
【一、主参考绑定】
全局声音与字幕约束：默认不生成叠加字幕或水印、不额外生成背景配乐；保留剧本对白、OS/VO、环境声、动作音效及已确认剧情内音乐。项目明确要求的例外按实际填写。
片段编号、实际总时长、目标画幅；实际角色/场景/道具/首帧或参考区域及其控制职责。无视觉输入时如实注明文字生成及必要描述，不造文件、句柄或已上传状态。
片段概述：一句话概括本段实际动作/关系变化与结束状态；实际 X 镜剪辑或一镜到底，目标 T 秒。不引用台词原句，不增加未发生的因果或结局。
【二、视觉风格与媒介】
已锁风格、媒介、必要光影质感及本片段相关的排除项；按 §4 负面约束选择真实风险并在对应段落落位，不复制模板审美或通用词库。
【三、道具与人物状态】
承重道具持有人、占手、交接/放置与去向；人物衣装、伤势等需要保持或发生变化的状态。没有相关对象或变化时简写，不补事件。
【四、场景与连续性】
地点、时段、光源世界方向、必要地标、出入口、视线/运动方向和起止状态；按当前片段实际空间依赖填写。人物世界位置与银幕左右分开；穿越/绕行写固定地标的进入面、路径、出口或受阻落点，第七段给出可辨接续，不只写“不越轴”。
【五、对白与发声时间】
每条：声音ID｜实际发声者/声源｜对白/OS/VO/演唱等类型｜预计起止秒｜有依据的语气、重音与停连｜逐字正文。
完整发声正文只在本段出现一次；可按声音ID/声窗、说话人及表演、独立一行逐字台词分行，不把全部工程字段挤成一句。内部核发音量、语速及停顿是否容纳，交付只保留必要时码和超载结论，不逐句列算式。用户改词先回唯一正文，再同步当前声音表、提示词与受影响镜头时窗/概述/提交记录；重新留足停连、听者反应和互斥动作，不能只换字不核容量、默认抢话或加速赶词。历史已提交版本保持不变。无逐字发声内容写“无”。
【六、场内文字】
实际文字载体、逐字内容、出现时段与可读方式；未使用写“无”，不自动增加字幕、水印或招牌。
【七、镜头与动作】
镜号｜起止秒｜切点或连续拍摄｜景别、相机位置/方向及运动｜可观察动作、站位、道具变化、反应与结束状态。引用声音ID及发声进度，不复写台词；镜数按叙事与容量，不固定三个镜头，不把一镜到底拆成假切点。
【八、声音与拟音】
继承用户提供的角色音色绑定，未选时标“用户待匹配”；必要环境声、接触拟音、进入/停止时点及按项目需要的音乐。普通声音随镜头一体设计，不要求另建母音色资产或逐句声音表。
```

**开头两项直接进入可提交正文**：第一段先写全局声音与字幕约束，素材职责之后写一句话片段概述，不另增第九/第十段、不另交摘要表。概述以简短为准，通常约 60 字以内，但不为字数删掉必要因果；一镜停留/余波可描述持续状态，不强造起承转合、终点定格或闭环。概述中的人物、动作先后、镜数和目标时长必须与第七段一致；改镜头同步改概述，不把三镜、27 秒或截图价格固化为默认。概述只概括已批准事实，不提前泄露后续 Clip，也不在概述重复第五段的逐字对白。

**默认禁叠加字幕，不禁剧情文字**：不生成自动对白字幕、说明性叠字或水印；第六段仍保留已锁的招牌、信件、屏幕等实体文字与披露时点。用户明确要生成字幕/字幕效果时按请求设计并标可读性核验，不以默认禁止覆盖授权。无额外 BGM 不等于无声、无 OS/VO 或无剧情内音乐；广播、人物演唱与演奏保留原声源与剧情作用。后期是否配乐按实际任务，不因禁 BGM 自动增加后期工作。此类约束降低歧义但不保证模型绝不生成字幕/音乐，结果仍须实看实听；不能仅凭价格、界面截图或提示词结构宣称成功率。

**输入音频职责隔离**：用户提供声音样本用于音色时，在第一段绑定实际音频与人物，注明只参考声音身份、共鸣与音质，不复制样本台词、情绪、语速、停顿或录音背景；本段语言、口音、逐字对白及表演按第五/八段。用户明确让样本同时控制表演、节奏或作为成品配音时分别声明职责，不一律排除。原样本有混声/噪声时如实核可用性，文字排除不等于已完成去噪或拆轨；不触发自动提取母音色。第八段引用同一绑定，只写必要声音执行变化，不重复完整绑定说明。

以下 Block 1–8 仅为内部段落编号别名，实际交付使用上述中文标题。

Block 1 的默认视频参考组合是**独立角色参考 + 按集参考总表**：本集每个实际出镜故事角色逐人对应独立参考，承担投币、裁决、递物、见证或结尾回应等事件职能的未具名/短暂出镜人物仍计角色，只有纯人数、声势或环境活动的背景群演并入场景。总表包含本集实际关键道具（没有则省略）、按实际观看任务从本集分镜精选且经景川批准的关键构图与清晰空场景区域，不再复制角色三视图区；精选构图不设固定配额，也不扩成完整逐镜故事板。关键道具区、构图区和纯场景区各自履责，不能用构图数量替代道具身份/状态或角色参考。总表覆盖本集时由各 Clip 共享，但每个 Clip 只绑定当下相关 Panel，不重演全部构图；未来道具状态或构图按 `show_now / withhold_now` 分区提取/分离，必要时才窄补。场景/道具身份与就绪状态可指向同一文件+Panel，不要求另建独立图。未明确请求综合图板时，已有多图、旧按 Clip 表或 provider 更适合分图输入时直接复用，不批量改名或重复生成相同场景/道具/故事板。规划保持 `prompt_only`，文件、Panel、路径与职责核验后才可达；任何参考都不自动成为叙事首帧。

Block 2 的媒介由项目锁决定：真人写真人摄影与皮肤/材质约束，3D 写 3D 渲染、shader/texture 约束；二者的 Negative Locks 必须互斥匹配，不能同时要求真人皮肤与纯 3D 表面。Block 3 必须写清承重道具的占手、交接或放置、跨镜持有者/位置；画外不等于消失，背景陈设不逐件编造退场。不能为省事删除已锁道具。

第五段（Block 5）是对白、OS、VO、演唱/说唱/合唱等**逐字发声正文唯一位置**。普通说话按 `dim-audio.md` 内部核发音量、语速、完整声窗与停顿；普通交付不输出逐句字数、算式或独立参数表，明显超载时只说明缺口。演唱按该卡「演唱/说唱/合唱时间轴」绑定实际乐句、音轨版本与区间；无素材写依赖与未锁状态，不套对白 WPM/40–55 词、不造 BPM 或试听结论。中外语切换保留原词与已定口音，发音注记不替换或重复歌词。Block 7 只引用声音 ID、当下乐句/动作进度和可见发声区间；Block 8 分清歌声与说话声的实际绑定、场内伴奏和剧外配乐，不复写逐字正文、不让配乐改变清唱事实。母音色文字方向不冒充已冻结音频：只有真实资产已试听冻结且本次接口实际绑定时，才写 frozen 资产与引用；否则如实写候选/待选或仅声音指纹。

Block 6 不是强制制造文字设备：不用时保留标题并写 `NONE`（中文“无”）；使用时只写剧情中实际存在的实体、原始文字、透视、材质、光影、可读动作与起止时码，不擅改文字事实，也不把字幕/水印当场内设备。

Block 7 按实际观看任务排镜；一镜到底只写一个覆盖实际 T 的 Shot 与连续节点，多镜写真实切点，时间线覆盖实际片长。参考提示词里的“单幅/单一全屏画面”可能只排除拼图或分屏，不自动解释为一镜到底；以明确剪辑意图及实际画面判读。

**容量判断分清证据**：有对应成片时优先核其实际语种、声音、动作与切点；翻译文本的词数/字速只能评估该译文，不能据此断言原片偏满或失败。未试听不能认证逐字对白、语速或口型，抽帧不能代替正常速度完整声画验收。区分多场景时间省略与同场连续动作：前者可省略路程和过程，后者不能用剪辑跳过承重因果或让画外动作停摆。依据真实遗漏、互斥动作与反应可读性决定重排，不因固定秒数、镜数或文字长短机械拆组，也不把一条示例成功推广为任意复杂度均可实现。

**五字段 → 八段映射**：storyboard-craft §2 只作内容核对。参考归第一段，风格归第二段，道具状态归第三段，场景空间归第四段，逐字发声归第五段，场内文字归第六段，机位/动作/构图归第七段，其余声音归第八段。不另交并行骨架，结尾按本片段接续职责选择，不强行故事闭环。

**参考总表请求与人物垫图**：总表的交付、按需版式、去重空场景、状态和风格边界以 asset-library §4 为主责。用户明确请求实际总表时，必须生成综合视觉图板，不能以索引或散图冒充；仅改提示词则交文本。含人物关键构图的生成输入实际绑定对应角色图，标明身份/衣装/风格/空间职责，排除已否决素材；无人物画面无需强加人物图。总表内不默认重复独立角色三视区。已批准资产重排不重复确认，新主要资产沿既有确认规则。

**有图与无图**：有实际可用参考图时只补身份锚点、当前状态与图片未表达的变化，并写清控制职责：角色参考默认独立绑定身份/外观；按集参考总表按 Panel 绑定道具、构图与场景。`文件 + Panel` 是资产记录/Prompt 的引用关系，生成接口仍提交真实文件路径；provider 不能可靠区分区域时才窄导出所需 Panel。参考外观不自动控制动作，构图参考不改写身份，实体参考不自动产生派生效果。无图时从已确认的文字资产补足物理描述并规划所需补图，不造 `@图1`、假句柄或空占位；文字资产 ID 不等于媒体引用。

**一镜到底共用外壳**：第七段（Block 7） 只写一个 Shot 的连续相机轨迹与动作时间节点，不把节点标成多个剪辑镜头。多机位才逐分镜标切点；固定机位不能同时推进或跟随，若先固定后移动须分别说明时段。

**逐字发声正文单一真源**：同一声音 ID 的对白、OS、VO、演唱、说唱或合唱**逐字正文只出现一次**：统一放第五段（Block 5）。第七段（Block 7） 只引用声音 ID、声音进度、可见发声/口型区间及反应，不按镜头平均截句或重贴全文。L-Cut 让完整声音跨画面连续播放，反打后仍是原声音类型；只驱动当前可见实际发声者的嘴，听者或未发声者不代动嘴，OS 不驱动口型，已有 OS/VO 不被通用「无画外音」删除。普通说话按原字速口径核时；演唱、说唱与合唱按实际音轨/乐句核时，不套普通字速认证。普通声画由同一执行者终编，音色由用户匹配；仅实际接口必需但缺失的声音输入阻塞相关调用。容量、气口与跨独立 Clip 的执行边界见 `dimensions/dim-audio.md`，切画面不增加声音时间。

**长度约束**：按已选模型与接口逐模式核对 Prompt 和时长上限；默认 15 秒不附带虚构的统一字符上限。仅用户明确暂不选型的草案采用 §6 通用保守规划。
**画面超载风险**：不按秒数机械数事件元素。若同一时间块出现多个彼此独立的主动作、空间关系改写、视线转移或必须分别读清的因果结果，先判断能否收成一条主动作链；收不拢或模型无法稳定交付时才拆镜。背景细节与同一因果链的连续反应不因“数量多”自动判超载。
**时间戳连续无缝**：多镜头/多段时，镜头 N 的结束时间 = 镜头 N+1 的起始时间，不重叠不留空。
**并行参与不等于多主动作**：合唱、乐队、球队配合、多方仪式或共同操作可以在同一时间块并行，只要共享一个可读的动作/注意链，并写清各主体、对象、声部/器具、接触与回应；“一镜一主导动作”不等于“一镜只许一人动”。随机点头、把其余参与者一律降为微动作或单人特写都不能替代已锁协作。
**分层连续性**：闪回、梦境、平行时空及伪现实为每层分别继承时间、空间、身份、物件、知情与声画状态；切换只用实际需要的可见/可听提示，不默认做旧滤镜。某层的伤损、道具变化、光源或声音不得无因写入另一层，返回后的继承服从剧本。

## 2.5 按组时长与叙事分配镜头

> 下表只是在没有项目实测时的首轮排片参考，不是镜数、时长或通过门槛；表演完整性、信息可读性、目标模型能力与成片节奏优先，项目跑出可用基线后按实测调整。

| 情形 | 排片方法 |
|---|---|
| 用户已选 15 秒多机位及快切偏好 | 可参考 5–8 个分镜，先保对白和动作可读性；只用于该偏好，不是通用镜数要求或模型精准切镜保证 |
| 30 秒 / 10 秒 / 8 秒或更短 | 按实际声窗、动作链和意义变化重新排镜，不按秒数比例机械倍增镜数 |
| 表演留白或一镜到底 | 按叙事需要减少镜数；一镜到底为一个 Shot，动作节点不是剪辑切点 |

**时长预算**：先给完整发声与不可省略的动作留出时间，再排视觉切点。**禁止场景 1:1 平均压缩**，也不为凑 5–8 镜硬塞动作、砍台词或加速。成片使用时长与技术生成时长分开记录，镜头数只作剪辑节奏参考，不作生成调用公式。 提示词时码是计划；生成后以生成音频及实际选片的发声、停顿和剪辑入出点为编辑证据，不能按计划窗口宣称口型或音画同步。ASR 只辅助识别/定位语音，静帧只支持可见状态与构图，二者不能独自证明动态动作、完整发声或口型成立。

**时长容量按任务核验**：单次时长按项目与接口，镜数由观看任务、完整表演及实际切点决定。英文普通对白可按 130–150 WPM 首估，中文可按 3–3.5 发音字/秒首估，均另留气口/反应；演唱按实际乐句/参考音轨核算。估算不是强制语速或效果保证。容量不足先重排；用户已锁单次时长与调用数时，不静默延长、拆分付费调用或加速，仍不足则回用户裁决受影响内容。

**镜头三任务**（每镜通常至少完成一项，三无镜头回查再定去留）：改情绪 / 推动作 / 加压力。**判断方法**：查无三任务时先别急着删——问「这一镜观众看见什么」（storyboard-craft 导演判断），若它在做隐性价值加载（关系位移/秘密距离/情绪落地，见 story-structure §2 缓冲段），把它改写成立，而不是当废镜剔除；显性隐性都立不住的才是装饰镜。
**悬念披露权限（内嵌现有导演意图，不新增 Schema）**：对关键事实标 `show_now` / `withhold_now`——前者只允许本镜应让观众读到的最强结论，后者列出本镜必须避免提前泄露的表情、道具状态、字幕、声音或构图信息。两者共同约束第七段（Block 7） 的动作与结尾落点；隐藏信息不能靠改写正典事实实现。
**取舍优先级**（Murch 剪辑六律，镜数或时长承载不下时据此裁量）：情感 > 剧情 > 节奏 > 视线 > 构图 > 空间。这里表达的是判断顺序，不把助记百分比当评分公式。

## 3. 单条多镜头语法

- §2 路由后的正文是交付格式，不是多镜能力证明：Seedance 按已加载两卡规划多镜；未确认多镜能力的接口只能把多机位标为待验证，或说明改为一镜到底/多次生成剪辑的取舍，不承诺一次精准执行，也不暗增调用数。30 秒专项的八段仍描述一个 30 秒 Clip，接口不支持时保留规划并报告执行差异，不能把两次 15 秒冒充一次 30 秒调用。
- 通用中文交付采用 §2 的 `分镜N丨功能丨起止秒丨…`；30 秒专项按 Block 7 的字段与项目语言写。若实际 API 需要 `Shot` 标签或 `multi_prompt` 等结构，由调用者从同一时间轴映射参数，不另交一份竞争正文。
- 跨 Shot 连续性锁：同角色表/同地理/同银幕方向/同视线/同光向/同服装状态/同伤口道具状态；存在闪回、梦境或平行时空时先按叙事层分域，再核进入/退出与返回继承
- 剪辑类型工具箱：HARD CUT / SMASH CUT / MATCH CUT / INSERT CUT / REVERSE CUT / WHIP CUT 为默认六式；**转场按意义选择（v1.7.4 增，陆离同步）**：叠化=时间流逝/记忆渗入/两状态短暂重合、淡入淡出=明确段落或时间边界、遮挡/甩镜/动作接切=让画面运动完成过渡——判断标准是转场**是否改变了时间、空间、情绪或意义**，六式内按功能选，六式外按意义取用；不为显技巧加转场，也不因工具箱拒绝当前场景真正需要的表达（平台硬性限制除外）

**时间划分先行**（吸收 deepwhite PROMPT_TIMING，防时长失控）：
1. 每条提示词**先划时间块**（Shot/时间轴），再写内容——不是写完后数秒数。
2. **内部时长加总 = 生成时长**：单条内各块时长相加必须等于该条生成时长（如 10s 条 = 4s+3s+3s），块总和不符=未装配；块时长按上述能力限制优先级确定，指定模型时还须区分文生/图生/参考生/首尾帧等调用模式。
3. **切点跟着意义走**：谁占上风/谁懂了/话题变了再切，不设所有镜头最小 2s；短于 2s 的镜头需保持信息与动作可读，复杂动作不能硬塞。每组从 0 计时到组尾，同一 Clip 内切场景不重置时间；只有下一 Clip 才从 0 重新计时。音频区间可跨多个视觉块，不能随每次切镜重复领时间预算。
4. 禁过度拆分：一个 5s 内能讲完的动作，不拆成两条（拆分=衔接风险翻倍）。

**条件式故事板引用**（吸收 deepwhite STORYBOARD_ASSETS，防提示词污染）：
- 故事板引用**用才写**：当且仅当该镜头确实依赖某资产/某参考图时，才写 `SB-xx` 或 `@资产名` 引用；不用的**完全省略，禁止占位**（空引用=污染提示词，模型会抓取无关内容）。
- 引用统一用资产 ID（asset-library 体系），不写描述性重复（资产已在库，引用即可）。
- **参考图控制边界合同（v1.8.0 增）**：每张参考图写清**锁什么**（身份/构图/风格/动作，以其一为主职责）与**明确不锁什么**（其余维度允许模型发挥）——多参考时各图主职责尽量不重叠；确需共同控制同一维度时，必须写明**优先级、融合关系，以及发生冲突时保留哪张参考**，防止多图争夺同一职责导致崩坏；与 §4「参考生/首尾帧写明各参考素材分别控制什么」同源。
- **排除参考图的附带内容**：角色身份图中的棚拍背景、固定姿势或展示用表情不自动进入剧情；场景图中的陌生人物不自动成为本剧角色。逐图确认本镜要继承的角色、空间、道具及光线职责，只处理实际干扰项，不重复描述整张图。参考图上的文字先区分剧情证据、需保留的场内文字和无关背景字符；前两者保留已定含义与披露时机，必要时单独制作或后期合成，无关字符才按项目要求去除或弱化。不得以通用“禁字”删掉剧情证物，也不能把全体角色限定为某国籍、肤质、睁眼姿势或每场更换风格；造型与风格继承项目锁定事实。
- 视频任务先复用独立角色参考；景川从本集分镜选出按集参考总表所需的关键构图，丹青只在现有参考无法承担本批职责时窄补，不强制关键帧。总表覆盖本集时供各 Clip 共享，但每个 Clip 只绑定相关 Panel，并用 `show_now / withhold_now` 隔离尚未发生的状态；未明确请求综合图板且已有合格分图或旧按 Clip 表能满足可见性/provider 上限时，不为新版式重画；纯资产任务不需要故事板引用。

## 4. 按请求选择提示词与生成模式职责

只交当前请求与实际生成模式需要的提示词，不默认同时交文生图和图生视频。需要实际首帧时必须有可用图片文件，描述仅代表规划。

| 版本 | 结构 | 用途 |
|---|---|---|
| 文生图 | 画风前缀+场景资产+人物资产+动作表情+构图光影+画质参数 | 出首帧/关键帧/资产图 |
| 图生视频 | 精简主体动作+运镜动态+环境氛围变化，**控制动作幅度防崩坏** | 首帧驱动生成 |

**生成模式中的文字职责（v1.7.4 增 · 只写会改变当前镜头的内容）**：三种模式的文字分工不同——**文生视频**：文字建立主体/场景/构图/动作/光线/运动；**图生视频**：静态信息已由真实首帧提供，文字重点写运动、响应、摄影机、节拍、结束状态与保持项，不重复堆满静态细节；**参考生/首尾帧**：写明独立角色参考、按集总表的本 Clip 相关 Panel 或复用分图分别控制什么，防多参考争夺同一职责。静态图只证明对应静态职责，不保证连续动作已经成立；参考帧只有实际符合开场状态并被 provider 作为首帧输入时才承担首帧职责。

**首帧即起始物理状态（v1.7.4 增）**：图生视频的输入图不是漂亮参考图，它已经在下指令——构图、外观、光线、空间与**隐含运动**（运动模糊暗示正在移动/飞起的尘土暗示车辆行驶/前倾抬腿挥手暗示动作方向/衣发与环境的方向线影响运动判断）都由首帧先行决定。首帧暗示「高速前进」而文本要求「完全静止」= 模型同时收到两个相反指令：此时**调整首帧或顺着已有运动设计**，而不是不断给文本加锁对抗首帧。

**参考画幅按用途继承**：按 asset-library §4 分开锁总表画布、目标构图 Panel 与首帧。横版或 21:9 总表可服务 9:16 视频，但直接指导镜头的 Panel 必须按目标画幅构图；空间关系宽图仅传空间职责。每镜只绑定相关有效区域，实际首帧单独提供比例、清晰度和起始状态均匹配的文件，不能上传整张总表冒充首帧。

**角色参考不等于首帧**：角色综合设定板或既有定妆照、肖像、三视图用于锁身份与外观；它们的中性姿势、视线、白/灰底、分区排版不控制剧情开场。需要图生视频首帧时，复用其身份信息来制作或选择符合本镜叙事起始状态的实际图片，不让角色板覆盖剧本规定的姿态、动作方向、构图、机位或场景。

**本机 MiniMax H3 模式路由**：目标为本机 Comfy H3 时，按实际输入选画布号，详见 `h3-comfy-mode-routing.md`——无参考图→11 文生；有明确首帧→20；有首尾帧→21；要保持人物/服装/场景或其他参考职责→30 参考图。禁止按脚本文件名或「默认文生」固定 11。30 号整板/裁图与槽位统一按该主责文件 §2，保留已批准且实测适配的输入组合，不固定裁脸或三张配方。20/21 的首帧必须是本镜开场物理状态，不能用身份板或空场景冒充。

**首尾帧边界**：**首帧只写开始时已经成立**的身份、构图、位置、光线、道具状态与动作起势，不把本 Clip 中途才发生的结果偷塞进开场；**尾帧只写目标终点**及必须保留给下镜的可见状态，不复述完整过程，也不提前写下一镜尚未发生的动作。过程变化只写在【画面内容】时间线中。

**负面约束按本 Clip 风险装配**：先识别已锁事实、参考附带内容与本镜可能出现的错误；已有明确排除项就不重复堆词。第二段汇总媒介/画质相关的少量排除项，第三段放身体结构、接触与道具状态，第四段放拓扑/轴线与光向，第八段放声音限制；不另加第九段，不因缺少“Negative Prompt”标题就判缺项，也不虚构接口的独立负面参数。参数面有专用字段时才映射同一组约束。按实际风险选项，不固定数量或全项目无差别词库：近手操作核手指数量与关节、抓握点、接触先后及手—物穿透；复用外观核五官/衣装漂移和纹理闪烁；空间转向核出入口、地标与光源世界方向；相机核无动机突变焦/畸变。人体项不套给无人风景或无人物产品片，卡通变形/颗粒等项目已锁审美不被写实负面词取消；剧情内文字仍按第六段保留。每个排除项尽量配同处可执行的正向状态，如握持接触面和物件去向；先删冲突、补承重因果，不能用“禁止穿模”替代动作设计，不能把负面词当效果保证。

**失败先查指令打架（v1.7.4 增 · 与重拍协议衔接）**：结果不稳定不一定是提示词不够长，常见根因是**视觉指令互相冲突**——首帧姿势与目标动作方向相逆（见本节「首帧即起始物理状态」）/ 同时要求大动作与面部绝对稳定 / 摄影机运动与主体运动互相抵消 / 短时间内塞多个需完整完成的动作 / 参考图之间人物服装视角光线不一致 / 既要求严格复现又要求自由发挥 / 抽象情绪与可见动作无对应。命中时**优先删除冲突项与次要要求**，而不是继续叠加形容词与负面限制（按重拍协议定位责任层与真实冲突，单变量仅用于归因对照，不限制必要的关联整改）。

**强关联分镜成组**：同场景连续镜头只有在**实际 provider 支持**视频续接、首尾帧或可复用尾帧输入，且该镜确需字面画面连续时，才成组写首帧/尾帧/上下衔接说明，并把已验收尾帧作为下一镜输入。provider 不支持、只支持参考图或本镜只需语义连续时，改用资产 ID + 接续状态块传递身份、位置、方向、情绪与道具状态，不虚构「尾帧即下一镜首帧」能力。 先按 shot-contract §2 确定接续类型与计划入/出态，再选参考方式；近乎同机位的字面接续可用已核剪辑出点的有效帧，换角度/换空间时以角色身份参考、场景拓扑及新构图承担各自职责，不强迫空景尾帧补出已离场人物。通用格式把地点/状态和变化写入【画面内容】相应起止段；30 秒专项分别落在 Block 3 道具、Block 4 空间和 Block 7 时间线，声音按原唯一正文位处理。不新增一套可投喂格式或把内部接续表整块重复贴入 Prompt。

**三条制作合同（v1.8.0 增 · planning 与 execution 通用）**：
- **时长语义**：分镜总表的时长 = 导演最终使用的成片时长；技术生成时长可因模型缓冲略长，**不得为填满技术生成时长而新增内容**——多出的时长剪掉，不是加戏。
- **技术切分服从叙事**：Shot/Clip 的技术切分服从连续表演与叙事功能——切点优先落在动作链自然段边界与意义变化处（与本文件 §3「时间划分先行」同口径）；禁止为凑生成时长上限把一个完整表演硬拆或硬并。
- **参考图控制边界**：见本文件 §3 末条合同——每张参考图锁什么、不锁什么写清；主职责尽量不重叠，确需共同控制同一维度时写明优先级、融合关系与冲突保留项。

**生成成本与抽卡预算（v1.9.0 增 · v1.9.1 裁量收口 · execution 启用时生效，planning_only 豁免）**：

> AI 视频的抽卡成本随模型、镜头复杂度、首帧质量与目标精度变化，不把通用经验次数当项目配额。重拍协议（shot-contract §5）管**单镜出废片后怎么办**，本合同管**开抽之前怎么把废片率压下来**。两级预算配合：先降废片率，再按项目预算与故障性质决定继续、改路或暂停。

- **分层生成路线（便宜验证、贵价定稿）**：结构验证（构图对不对/主体对不对/动作方向对不对）用低价或免费额度先跑——结构错的图不值得花高价视频积分；结构过关后**冻结提示词**再上目标模型出正式素材。便宜模型上反复润色措辞是白调（调的是它的怪癖），冻结后换模型只微调模型敏感的那一句。**冻结后换目标模型先判兼容（v1.10.1）**：Shot/Clip 结构、单镜时长、参考资产数量与类型、首尾帧、画幅、音频能力全部兼容才只微调措辞；任一不兼容时**仅受影响 Shot/Clip 对应提示词失效**（重拆 Clip/改参考组合/换音频方案），未受影响兄弟镜头继续有效；按 SKILL.md「换目标视频模型」行同口径执行——「只微调一句」只适用于能力对齐的模型间切换。
- **抽卡分级纪律（同一镜头连抽时的归因）**：同样提示词结果不同，先判断是模型随机波动还是同一故障在稳定复现；接近目标、预算仍有余量时可**原样再跑**（不加词），同一故障稳定复现或反复出现时即视为提示词、首帧或模型能力问题，进入重拍协议「修复四件套」。调整仍一次只验证一个变量；先补缺失信息还是先删冲突项，按故障证据选择，不机械规定先后。
- **静态图先审（生图便宜生视频贵）**：图生视频路线下，先用静态图确认角色/构图/风格，确认后再投视频生成——静态图返工成本远低于视频废片。
- **批级预估（沈砚派单前口算一行）**：优先采用用户已授权的调用次数或成本上限；未给预算时，用 E01/已完成批次的「实际调用次数 ÷ 可用 Shot 数」作项目基线，再结合本批镜头复杂度与工具单价给出预计区间并标明假设。没有项目实测时只给试算区间，不把行业经验写成调用配额。达到用户批准预算或工具/API 硬上限即暂停并回沈砚报告已用量、余量与换首帧/换模型/拆镜选项；复用既有 execution 确认，不新增弹窗，**禁不设上限的连续盲抽**。 预估、provider 本任务扣费与账户余额分别记录；实际参数/参考和价格异常按 Dreamina 卡处理，明显且未解释的价格偏差先停依赖批次。
- **成本记录消费**：execution 六字段追踪（SKILL.md 第 2 步）中的「尝试次数 + 实际成本」按批汇总进陆离批次汇总——抽卡系数显著高于预估的镜头，标记其提示词或首帧为「高耗模板」，下批优先修它（省的是真钱，不是指标）。

## 5. 冲突九层仲裁

维度要求打架时，按优先级牺牲后者：**安全 > 平台限制 > 用户硬性要求 > 参考图契约 > 连续性 > 物理因果 > 镜头剪辑逻辑 > 风格装饰 > 默认值**。
示例：风格母版要求宽画面但当前接口只有 9:16 → 说明冲突并按已有平台约束处理；复合运镜的通道不可达或真实产物不可读 → 修对应路径/速度，不因“复合”自动否决；高速动作与表情是否兼得 → 核相对运动与实际小样，不预判脸必糊；变焦、移焦或景深变化 → 保留有动机的连续过程，修无因跳变。

## 6.5 物理措辞纪律（画面指令适用，不改剧本原话）

> §2 路由后的正文管结构，本节把画面要求翻译成可见动作与物理关系。对白/OS/VO 中的比喻、人物口头禅和原始数字逐字保留，不因视觉措辞检查而改词；不强制所有表演都写肌肉术语或伴随大动作。

**两禁**：
- **禁文学化修辞**：比喻/拟人/象征/夸张一律换成物理世界的字面描述——「心如刀割」→「双手按住胸口，呼吸急促，面部肌肉扭曲」；「杀气腾腾」→「下颌前伸，眼神直视前方固定一点，嘴角下拉」；「城市在夜色中沉睡」→「夜晚，建筑物静止，街道无人」。
- **避免不可验证的伪精度**：画面描述中不必靠毫米/赫兹/精确角度堆控制感，可用相对关系；时间码、台词中的数字、已确认的空间尺寸和实际接口/混音参数不受此禁令影响，不能删掉可执行数值。

**五维相对化正向措辞**（写什么，而不是只拦什么）：

| 维度 | 相对化写法 |
|---|---|
| 光线 | 光源位置（左/右/顶/侧后方）+ 明暗对比（面部大半阴影/半明半暗）+ 色温倾向（暖黄/冷蓝/中性白），不用 K 值小数 |
| 动作 | 起点→终点（身体部位 A 移动到 B）+ 耗时感（约 X 秒完成/缓慢/匀速/骤停）+ 力度质感（轻柔/用力/爆发/控制） |
| 表情 | 具体肌肉运动（皱眉肌隆起/眼轮匝肌收缩/嘴角下拉）+ 面部区域变化（额头横纹/眼角皱纹）+ 皮肤状态（苍白/泛红/出汗） |
| 声音 | 音量质感（耳语/低声/嘶喊）+ 音质质感（沙哑/颤抖/劈裂）+ 混响质感（干涩/空旷/回声），不用 dB 小数 |
| 空间 | 身体参照（一臂距离/一拳之隔/指尖到手腕）+ 画面比例（人物占画面 1/2 或 1/10）+ 方位关系（左/右/前/后），不用毫米级描述 |

**与现有条款的关系**：§2 第七段（Block 7） 的可观察动作、storyboard-craft §3 表情拆解公式是同一纪律的分维度细化；asset-library §9 禁用词黑名单管资产层空话词，本节管画面指令措辞——互补不重叠。装配自检（§7）并入既有「命中维度的契约要素」核对。
