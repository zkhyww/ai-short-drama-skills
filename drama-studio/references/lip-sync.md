# 对口型工作流（唇形师 · 按需岗位）

> 职责边界一句话：**闻笙管台词与成品音轨，景川管镜头设计与口型可见度，唇形师管音素对齐与口型生成参数，陆离管成片音画同步复核。** 触发对口型需求时才读本文件；不触发不读。**兼任口径（v1.7.2 定版）**：包内 6 agent 无独立唇形师编制——唇形师职责由**闻笙兼任**（音素对齐+口型生成参数）、**景川提供镜头参数与可见度判定**，沈砚按两条既有角色卡合并下发；本文件即兼任时的职责契约与验收标准。

## 1. 触发条件

仅用户明确要求口型修复/精配，且有实际素材与可用工具时启用。普通可见对白不自动开唇形师、拆音轨或调用外部 TTS；保持声画一体，默认人物音色由用户匹配。用户已授权修复范围内按实际问题执行，不重复问同一授权。未授权的外部声音处理只列方案，不擅自替换已批准声音。OS 不驱动画中口型，VO 保留画外声源；真实原生音视频失败时先定位，再按授权处理。

## 2. 四角色职责边界（防止越权）

| 角色 | 管什么 | 明确不管什么 |
|---|---|---|
| **闻笙**（声音导演） | 继承台词终稿、声音指纹与母音色卡、逐句意图/潜台词/重音/停连/语调、成品配音音轨、TTS 适配参数 | 不管口型怎么动、镜头怎么拍 |
| **景川**（分镜师·唯一终编） | 镜头设计：口型可见度判定、景别/角度/遮挡决策、提示词内对白写法 | 不管音素时间戳、口型参数 |
| **唇形师**（按需·对口型执行） | **音频驱动/音素对齐/口型生成参数**：输入音轨→字词时间戳→口型驱动参数→出对口型片段 | 不改台词、不改镜头、不做最终混音 |
| **陆离**（剪辑合成） | 成片时间线：音轨与画面**同步复核**（±口型容差）、混音、字幕对齐 | 不重新生成口型 |

> 主理人沈砚统一调度：闻笙先出音轨 → 唇形师对齐生成 → 景川确认镜头内口型可见性 → 陆离合成复核。唇形师只对音轨+镜头参数负责，不越权改创意。

## 3. 输入契约（唇形师接单必须收齐）

```
① 配音音轨文件（闻笙交付，标注采样率/格式）
② 台词文本 + 逐句时间戳（起止秒）
③ 目标片段：镜头号 / 画幅 / 分辨率 / 帧率
④ 人物资产图（口型生成参考，正脸/微侧脸各 1 张）
⑤ 可见口型比例判定（景川交付：全可见/半可见/侧脸可见）
⑥ 目标视频模型（决定对口型工具选型）
```

缺任一 → 回沈砚补齐再开工，不许猜。

## 4. 音素对齐与口型生成（工具中立）

**后备修复流程**（先验证所选工具；未指定且无可用能力时只交方案，不伪造执行）：
1. 按实际工具时长上限与完整意群切分音轨，不把某个旧接口的 9 秒限制套给所有模型。
2. 生成**字词级时间戳**：每个字/词的起止毫秒表。
3. 用人物正脸资产图 + 单句音频 + 时间戳驱动口型：
   - 已验证可用的平台对口型/局部音频编辑功能 → 按本次实际接口提交，不把原生音视频生成等同于独立修嘴 API；
   - 独立对口型工具（如 Wav2Lip 类、SadTalker 类，或用户指定工具）→ 按其参数格式提交。
4. 口型生成参数建议：`face_align` 对齐正脸；背景静态化降低漂移；唇部区域单独强化。

**时长映射**：按 dim-audio 的完整声窗估算与实听结果对齐；帧率只影响对齐采样精度，不决定每秒能说几个字。长句可用 L-Cut 延续声音、切换画面，但音频总时长不足仍须延长或重排，不能只拆画面就声称解决。

## 5. 镜头适配（景川配合）

- 口型镜优先**近景/特写 + 正脸或 3/4 侧脸**，避免大侧脸/仰角/逆光（口型不可见=白对齐）。
- 嘴部被手/杯/遮挡的镜头**不接对口型**（改配音后期覆盖或换景别）。
- 多人对话按实际工具的说话人绑定能力处理；只有工具仅支持单人或已复现串嘴时才拆镜/遮挡或分人修复，不无条件把其他演员冻结成静帧。
- 承重句后是否留反应按表演落点决定；不以统一秒数拖住每个句尾。
- L-Cut 按实际音轨起止秒与可见说话人区间驱动口型；听者反应镜/道具镜延续原对白，不借听者嘴部发声，也不把对白改成 OS。

## 6. 音画同步 QC（陆离复核）

| 检查项 | 容差 |
|---|---|
| 字起始 vs 嘴动 | ≤ ±100ms（Vidu Q3 宣称 ±15ms 为参考量级） |
| 句尾 vs 嘴停 | ≤ ±150ms |
| 无台词段嘴不乱动 | 0 容忍 |
| 配音/字幕/画面同一时间轴 | 逐句对齐 |

失败 → 定位是音轨问题（回闻笙）/口型生成问题（回唇形师）/镜头问题（回景川），**一次只改一个变量**（重拍协议）。

## 7. 已知冲突与降级

- **模型无原生口型**（如 Sora 2 无对口型参数）→ 走外部工具或提示词「嘴部微动自然」兜底，标注 needs_confirmation。
- **音轨超过实际工具上限** → 按意群分段或换已验证路线，保持完整台词，不套通用 30 秒阈值。
- **嘴型与台词语言不匹配**（中文音轨+英文口型模型）→ 换支持中文的工具或平台内建功能。
- 口型生成失败 → 降级为「不拍嘴」：切遮挡/背影/特写局部，台词保留（后期配音），向用户明示取舍。
