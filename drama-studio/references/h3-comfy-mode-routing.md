# 本机 MiniMax H3 工作流模式路由（Comfy Desktop）

> 仅当目标模型是本机 MiniMax H3 / Hailuo H3，且执行渠道是本机 Comfy `:8188` 的 `H3本地视频` 画布时加载。Dreamina / Seedance / 即梦 CLI 不走本表。
> 用户原话「以后就这样」：按**实际输入材料**选号，不按脚本文件名，不把 11 号当默认。

画布根目录：

`%LOCALAPPDATA%\Comfy-Desktop\ComfyUI-Installs\ComfyUI\ComfyUI\user\default\workflows\H3本地视频\`（仅适用于已安装相应画布的本机；实际目录与节点能力须核验）

## 1. 模式路由表

先看本镜**实际有什么输入**，再打开对应号的 JSON。用户点名号优先于推断；点名与材料冲突时停下来说明，不静默改号。

| 条件 | 号 | 画布 | 节点 / 模式 |
|---|---|---|---|
| 纯文字、没有参考图、没有首帧 | **11** | `01_文生视频/11_文生视频_日常8步_1152x640_10秒_已实测.json` | 文生 T2VA。预览 4 步用 `10_`，正片 8 步用 `11_` |
| 有明确首帧（该镜起始物理状态图，不是设定板） | **20** | `02_首帧图生视频/20_首帧图生视频_8步_1152x640_10秒_待出片验收.json` | 首帧图生 I2VA，`MiniMaxH3ImageToVideo` |
| 有首帧和尾帧 | **21** | `03_首尾帧视频/21_首尾帧视频_8步_1152x640_10秒_待出片验收.json` | 首尾帧 FL2VA，同一 ImageToVideo 节点吃首尾两图 |

不要：

- 按 `submit_*.py` 文件名、上次用过的脚本或「默认文生」选号
- 为准备 30 号任务去探测、复制或改 11 号图
- 把 `90_旧版回退/` 当生产图
- 把 Dreamina `text2video` / 即梦网页当成 11 号

## 2. 30 号参考图：按本镜职责选，不固定张数配方

30 号保存的画布只接 **一张** `LoadImage` → `ref_images.ref_image_0`。多图时在同一 Fused 栈上加 `LoadImage` + `ref_images.ref_image_N`，这是项目分叉，不是第二份已验收模板。UNET / CLIP / VAE / sampler 必须与 30 号画布一致。

**张数、槽位、图种都随本镜实际要锁的职责变。** 「单人正脸 + 单人正脸 + 无人场景」只是某条双人酒店门口连续性的**示例**，不是 30 号默认配方，不要每条都凑这三张。

选图顺序：

1. 列出本镜真正要锁的职责（脸/身份、服装、地点、道具、动作参考等）。没有的职责不占槽。
2. 每个职责只绑一张主责图；多图不要抢同一职责。写清每张锁什么、不锁什么。
3. 单人镜可以只有一张身份图；无人空镜可以只有场景图；道具特写可以只有物件图。不要为填满模板补无关图。
4. 锁人物身份+服装时：先沿用已批准且实测适配的输入组合；新选时可用已批准的**一人一张综合设定板**，按实际区域说明肖像锁脸、全身视图锁同一人的身材与服装，不固定左右位置。用户明确指定整板时保留整板，不自行改成只裁脸；若实际缩放后不可辨，先说明具体缺口再调整。只锁局部，或整板压缩后确实看不清且允许调整输入时，从同一已批准原板窄导出对应分图，保留所需衣装/身体职责，不重新造脸。**同一人的多视图不是多人**，板的中性姿势、灰棚底与拼图版式不进入成片；表情宫格、多人合影或多角色拼板不能当单人身份 `ref_image`。整板和裁图均需实测验收，不保证其中一种必然稳定。
5. 需要锁地点时：用本镜已批准、与职责匹配的场景图。画面空间只能用该图里已有的床、窗、灯、门；板上看不见的卫生间、电梯或第二道门不要写进提示词，也不要靠运镜走进去。换房间就切分镜、换场景板、固定机位。
6. 本镜其实是 20/21 时：首帧必须是开场站位/朝向/光线的实际状态图，不能用身份板或空场景冒充。

综合设定板仍是丹青的身份资产（一人一板）；是否裁、裁哪一块，看本镜要锁什么，不看固定三槽。

`H3SLAAttention.reference_protection`：人物身份条用 `Light`。`Off` 保身份不足；`Heavy Enforcement` 与 max ref-size 冲突。无人/纯场景条按实际风险，不必机械开 Light。

## 3. 本机稳定档（RTX 4080 SUPER 16GB）

| 参数 | 值 |
|---|---|
| 分辨率 | **1152×640**（30 号原生，先在此验脸）。脸稳后再候选 1280×704。禁止 1280×720（非 32 倍数）。禁止 1344×768 + 10s + 多参考（OOM，会打崩 `:8188`） |
| 时长 | `length` 243，24fps，约 10.125s |
| 步数 | 8（试片 4 步走 `10_` 文生预览，不拿 4 步当 30 号正片） |
| 采样 | `res_multistep` + scheduler `simple` |
| Sigma shift | 视频 12，音频 3 |
| SLA | 0.90 / block 64 / min_seq_len 8192 |
| 权重 | Fused Turbo8 INT8：`minimax_h3_fused_refdelta_r1024_turbo8_mystic07_int8_convrot` + `qwen3vl_32b_minimax_h3_nvfp4_awq` + 双 VAE。不要把未验证的 `heretic` / `generation_tail` CLIP 换进本图 |

对白条：约 10 秒只留 2–3 句完整短句，提示词写 `speaking at a normal conversational pace`。一场戏的对白不要塞进一条。

## 4. 执行入口（Hermes / 本机）

- 生成执行走 **default 会话** + Hermes skill `h3-local-video`。提示词六段格式读 Codex `h3-prompt-writing`（`subject_definitions` … `non_diegetic_music`）。
- Profile `h3-director`（总导演）禁用 `terminal` / `image_gen` / `video_gen` / `skills`：只协调，不 `POST /prompt`。
- 一次 POST；记下 `prompt_id`。连接断开先查 `/history` 与队列，禁止同一进行中的 id 重提。
- 回复里写明**实际号**（11/20/21/30）。跑了 30 不要说成 11。
