# 维度卡 · 景别（dim-shot-size）

> Contract 结构：①契约要素 ②选择表 ③修复规则。读这一张 = 拿到景别维度全部可执行规则。
> 装配位置：提示词「分镜时序」段的景别字段 + 「定调参数」段的镜头参数。

## ① 契约要素（每镜必齐 3 项）

1. **叙事功能**：本镜为什么是这个景别（特写=亲密/细节/反应；近景=对话情绪；中景=关系与动作；全景=环境/肢语/权力格局）。景别是叙事选择，不是构图偏好。**景别改变观看关系（v1.7.3 增 · 判断内核）**：选景别 = 选观众与人物的距离关系——特写是被迫贴近（无处可躲，共享呼吸），中景是社交距离（看得清关系看不全心思），全景是旁观（人被环境吞没时观众也帮不上忙）。同一动作换景别 = 换观众立场：审讯戏拍刑讯者的特写是把观众放在施压者一侧，拍受审者特写是放在受难者一侧——先想「这一镜让观众站在谁那边」，再定景别。
2. **景别**：特写 / 近景 / 中景 / 全景 / 大全景，五选一写死。
3. **取景范围**：先写清需要看见的主体范围、承重动作/道具及前后景关系；镜头参数是辅助，不能单凭 FOV 或焦段保证构图。使用对角视场角时须结合画幅、实际机距与主体大小，不套固定数值组合。

## ② 选择表（内容类型 → 景别+镜头）

| 观看重点 | 景别起点 | 实际构图依据 |
|---|---|---|
| 微表情、欲言又止、听者理解变化 | 近景/特写 | 眼神对象与细微变化可读，保留必要视线空间 |
| 对话关系、站位与持物 | 中景/双人关系镜 | 看清相对位置和承重手部，不让裁切隐藏交接 |
| 路线、追逐、出口与障碍 | 全景/大全景 | 出入口连通关系和移动路径可辨，人物不被环境淹没 |
| 证据、机关或道具状态变化 | 细节镜 | 对象可辨、变化可读，前后能定位回持有人/地标 |
| 窥视或隔离感 | 按关系择取 | 遮挡与压缩服务视点，不能挡掉本镜必须交付的信息 |

**构图舒适与重点可读**：每镜先定一个主注意点，其他元素形成必要关系层次；检查人物头顶空间、视线/运动前方空间、背景线条与头部的干扰、边缘切割、前景遮挡和画幅内实际字幕/UI 占区。三分法、居中、对称或负空间按戏选择，不规定永远居中或固定留白比例；有意的拥挤、偏置和压迫构图可以保留，但不牺牲承重动作与信息的可读性。画幅变化后重新核，不只照搬参数。

**相邻景别与机位衔接**：先核主体是谁、观众注意点在哪里、动作/视线接到何处，再决定尺度与角度变化。近似角度和尺度的两个静态画面若造成无意跳动，才扩大差异、改切动作阶段或选择有功能的反应/细节；约 30° 只作传统连续剪辑启发，不是生成验收阈值。全景直接到特写可以有效揭示，不要求每次“全→中→近”走齐；相同景别的正反打也可成立。关键交接或大幅位移后空间难以辨认时才补关系/地理镜，不为景别丰富自动加镜。角色跨节点大移动按 shot-contract §2 的接续选路处理。

## ③ 修复规则

| 失败 | 加锁 |
|---|---|
| 长焦镜里环境漂移变清晰 | 「全镜背景保持压缩虚化，不变广角覆盖；变远靠机距不靠换镜头」 |
| 广角里人物变小变远 | 「相机保持物理贴近，前景身体存在感大于自然比例，不切长焦」 |
| 一镜里又面部特写又地理环境又微距细节 | 镜头漂移——拆镜，一个镜头只承载一个内容类型 |
| 人物镜/动作镜首帧无角色 | 首帧占位锁：「第一帧已含全部必需角色在正确位置，无空建立帧」。**该锁只限人物镜/动作镜**——承担地理建立、时间变化、情绪过渡或意义转场的空镜合法，其首帧主体可以是空间、道具、光线或环境运动（与 prompt-assembly「转场空镜」装配行、storyboard-craft 叙事目的「建立/过渡」一致） |
