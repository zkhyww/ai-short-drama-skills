# 维度卡 · 运镜（dim-camera-move）

> Contract 结构：①契约要素 ②选择表 ③修复规则。

## ① 契约要素（基础镜头每镜必齐前 4 项；复杂跟拍/环绕/FPV/连续长镜命中时补第 5 项）

> **运镜总判断（v1.7.3 增）**：镜头运动需要**动机**——因什么动、往哪去、在什么时刻停（第 1 项「绑定节拍」的判断内核）。**静止同样是运镜决策**：固定镜头不是偷懒，是让画面自己动（主体表演/环境变化承载注意力），或让内容在静置中产生重量（对峙/宣判/凝视）；「镜头该不该动」先问「这一镜观众看什么」，再选动或不动。

1. **绑定节拍**：运镜必须挂在动作节拍上，不是装饰——「缓慢推近，**在她手停下的那一刻落幅**」。写清：因什么动、在什么时刻停。
2. **一次运动**：一镜一个主动作运镜（推/拉/摇/跟/升降 五选一），**复合运动默认禁止**（又推又摇=漂移主因）。**情绪特例（显式声明才允许）**：选择表中「愤怒/爆发=手持破碎」等情绪驱动复合运动，仅当导演意图字段显式声明「为情绪有意失稳」并在镜头卡注明理由时放行，写明「情绪特例：{理由}」；未声明按默认禁止处理。**矛盾指令铁律**：高速运动+表情清晰必二选一（快就保不了脸）；**景深不可突变**——同镜内焦段不跳，变氛围靠机位不靠换镜头。
3. **操作员身体**：相机是人在扛——手持写「呼吸感、微沉降、步伐重量、有机的不完美修正」；禁「数字抖动、随机晃动、稳定器顺滑」（除非就是要稳定器感）。
4. **机位高度与角度**：腰平/眼平/胸平/贴地/高角度俯拍 + 仰/俯/平，写死。
5. **复杂运镜物理通道（v1.8.0 增）**：复杂跟拍/环绕/FPV/连续长镜必须写清**可执行起点、通过通道、人物/道具避让和终点**——摄影机不能穿过人物、墙体或无解释的障碍；空间无法抵达时**拆镜**，或用有动机的遮挡（墙体/背影/黑暗）桥接，不写物理上不可能的运镜。

## ② 选择表

**情绪 → 运镜**（基础六式 + 细化映射吸收 deepwhite CAMERA_EMOTION）：

| 情绪/功能 | 运镜 | 节奏/落幅细节 |
|---|---|---|
| 压迫感逼近 | 慢推（dolly-in） | 落幅在反应点 |
| 抽离/结局感 | 慢拉（dolly-out） | 人越来越小 |
| 跟随对抗 | 跟拍 | 保持相对距离不变 |
| 揭示信息 | 摇镜或横移 | 从 A 摇到 B 的因果 |
| 压迫升级 | 低角度仰拍 + 缓推 | — |
| 无力/渺小 | 高角度俯拍 + 静止 | — |
| **愤怒/爆发**（deepwhite） | **手持破碎**：快速急推 + 轻微水平倾斜 + 步伐颠簸 | 节奏加快、帧间抖动；避免稳定器感 |
| **震惊/愕然**（deepwhite） | **静止停顿后极慢推**：先 0.3-0.5s 画面完全静止，再极慢推近 | 静止即情绪，推近即逼近真相 |
| **判决/宣判**（deepwhite） | **正上方俯拍 + 冻结**：定格 0.3-0.5s 再切 | 俯拍=审判视角，冻结=不可逃 |
| **崩溃/心死**（deepwhite） | **缓拉 + 人物出画/失焦**：情绪到顶后抽离 | 与「抽离」不同：先贴近再迅速拉开 |
| **甜蜜/心动**（deepwhite） | **极缓推 + 微仰角**：对焦在眼神，浅景深 | 速度是所有推镜里最慢的，呼吸感 |
| **惊悚/战栗**（deepwhite） | **手持低机位 + 缓慢横移**：贴地平移，阴影入画 | 低机位=弱小视角，横移=危险临近 |

**景别 → 手持等级**（吸收 XiaoLuo 分级）：

| 景别 | 支撑 |
|---|---|
| 特写/大特写 | 三脚架级稳定+微呼吸（防抖坏脸） |
| 中近景 | 轻手持，有机微晃 |
| 全景/动作 | 全手持或移动设备，能量感 |

**摆钟时间块**（多节拍镜头）：每 2-3 秒一个时间块，**每块只保留一个未解决的变化**（上一块的悬念在下一块开头解决），上一段结束动作=下一段起始状态。

## ③ 修复规则

| 失败 | 加锁 |
|---|---|
| 镜头无故乱动 | 删运镜，改静止机位+主体动 |
| 推拉速度不均/飘 | 写死时长与落幅：「0:00-0:04 匀速推近，0:04 落幅后固定」 |
| 切镜后空间跳乱 | 跨切连续性锁：同角色表/同地理/同银幕方向/同视线目标/同光线方向 |
| 稳定器感毁手持戏 | 「肩扛质量感、步伐传导、呼吸微浮动」三选二写入 |
