# 维度卡 · 特效（dim-vfx）

> Contract 结构：①契约要素 ②选择表 ③修复规则。
> 适用：法术/能量/变身/异能/粒子/烟尘/水花/破碎/传送门等超自然或强化视觉效果。写实题材无特效镜头不装配本卡。
> 吸收来源：seedance-vfx Effects Contract + CINEDANCE 物理锁粒子条目。

## ① 契约要素（按承担特效功能的镜头/阶段取用）

1. **源头（source）**：需要交代成因的阶段写特效从哪来——角色掌心/法器/天空/地面裂缝/伤口；已由前镜建立的常驻或余波镜可继承，不为齐项重复生成源头。
2. **材质（material）**：围绕主效应选明确构成物，不堆抽象“震撼能量”。按需要写边缘形态、疏密与速度差，例如细碎冰晶外缘松散、中心密集，前沿快速扩散、余屑缓慢下落；不强制每镜列全属性。
3. **运动路径（motion path）**：承担行进或作用的阶段写起点→轨迹→终点，有方向有速度；静态附着、持续照明或结果镜写它保持的状态，不硬造移动。
4. **与光和物体的交互**：发光特效按场景与人物受光关系产生相称反光；实体特效按已锁结果表现接触、位移、形变或无损反馈。没有伤害/破坏授权时，不为证明接触补裂地、溅伤或生理代价。
5. **结束或持续状态**：按剧情写熄灭、蒸发、落地成灰、回收、稳定持续或跨镜残留；只有本段承诺结束时才必须消散，不要求每个特效镜各自收尾。
6. **时序职责**：`forms（成形）→ travels（行进/作用）→ settles（结束/持续结果）` 是整条特效因果的阶段，不是每镜齐套项；各镜只承担可读的阶段，一镜仍保持一个主特效焦点。

**绕开脆弱锚**：特效路径避开脸/手/关键道具（这些区域崩了全镜废）；发光强度以不洗白人物面部细节为上限。

## ② 选择表

| 特效类型 | 写法要点 |
|---|---|
| 法术/能量攻击 | 源头、路径、命中与结束由承担对应阶段的镜头分配；命中反馈服从已锁伤态/破坏结果，消散或残留时长按剧情与当前能力决定 |
| 变身/觉醒 | 先锁变身前后资产与观众必须看见的变化阶段；中间过程是核心看点时给足可读时长，不设固定秒数。按当前模型/参考能力尝试，只有具体失败后才用拆镜、遮挡或后期桥接，仍保留承诺的过程 |
| 传送/闪现 | 消失点粒子塌缩+出现点粒子聚合，两端各半镜，禁全程虚化拖影 |
| 气场/压迫感（无形特效） | 用环境反应写：烛火压矮/纸张震动/尘埃悬停/对手后退半步——**看不见的特效比看得见的更高级** |
| 烟尘/水花/破碎（物理特效） | 回 dim-action 物理锁：粒子随风、液体粘滞、碎片有重量与落点 |
| 异能被动（常驻微特效） | 按叙事必要性选择可持续的主视觉信号（如眼中微光），锁定强度与状态以防跨镜漂移；数量服从项目设计与当前能力，不设每场固定配额 |

**预算原则**：单镜围绕一条主特效因果链组织，次级特效只有在同一因果链中承担环境反应或结果证据时才保留；多粒子+变形+大范围等高负荷特效镜的密度是成本与稳定性风险信号，具体数量按叙事必要性、目标模型能力和项目批准预算决定，不设单集通用配额。特效是为叙事服务的，不是烟花秀——回 Director's Read 问「没有这特效，这场戏还成立吗」，不成立才保留为主特效。

## ③ 修复规则

| 失败 | 加锁 |
|---|---|
| 需要交代成因的特效漂浮无源头 | 在承担成形/作用的镜头补源头与去向；结果镜可引用前镜来源，不重复造接触 |
| 特效不发光却照亮/发光不照亮 | 光交互写死：「蓝光在人物面部与地面投下同色反光」 |
| 特效盖住脸/手 | 路径改写绕开；或把脆弱锚移出特效区 |
| 结束状态与剧情承诺不清 | 按已锁结果写消散、稳定持续或跨镜残留；只有应结束却无收尾时才补消散 |
| 一镜多个主特效打架 | 砍到 1 个，其余降级为环境微光或删 |
| 变身中间态出现具体崩坏 | 先换输入/参考或拆分可读阶段；仍失败再用有动机遮挡或后期桥接，保留本段承诺的关键变化过程与新形态结果 |
