# 维度卡 · 特效（dim-vfx）

> Contract 结构：①契约要素 ②选择表 ③修复规则。
> 适用：法术/能量/变身/异能/粒子/烟尘/水花/破碎/传送门等超自然或强化视觉效果。写实题材无特效镜头不装配本卡。
> 吸收来源：seedance-vfx Effects Contract + CINEDANCE 物理锁粒子条目。

## ① 契约要素（每个特效镜必齐 6 项）

1. **源头（source）**：特效从哪来——角色掌心/法器/天空/地面裂缝/伤口。无源头的特效=漂浮贴图。
2. **材质（material）**：火/冰/雷/光/水/烟/尘/能量粒子/血，选 1-2 种写死，不堆。
3. **运动路径（motion path）**：起点→轨迹→终点，有方向有速度（「从掌心呈锥形向前喷出 2 米」）。
4. **与光和物体的交互**：发光特效必须照亮周围环境与人物（蓝光打脸）；实体特效必须与物体碰撞（地面龟裂/水花溅到人）。
5. **消散（dissipation）**：特效怎么结束——熄灭/蒸发/落地成灰/回收进法器。**禁永续无果特效**。
6. **时序三步**：`forms（成形）→ travels（行进/作用）→ dissipates（消散）`，一镜一主特效。

**绕开脆弱锚**：特效路径避开脸/手/关键道具（这些区域崩了全镜废）；发光强度以不洗白人物面部细节为上限。

## ② 选择表

| 特效类型 | 写法要点 |
|---|---|
| 法术/能量攻击 | 源头在掌心或法器+锥形或束状路径+命中点环境反应（坑/烟/碎裂）+命中后 0.3s 内开始消散 |
| 变身/觉醒 | 从身体轮廓向内发光→粒子包裹→新形态亮相；中间态不超过 1 秒（中间态是高风险场景，先读模型卡；失败参考 storyboard-craft 可行性诊断） |
| 传送/闪现 | 消失点粒子塌缩+出现点粒子聚合，两端各半镜，禁全程虚化拖影 |
| 气场/压迫感（无形特效） | 用环境反应写：烛火压矮/纸张震动/尘埃悬停/对手后退半步——**看不见的特效比看得见的更高级** |
| 烟尘/水花/破碎（物理特效） | 回 dim-action 物理锁：粒子随风、液体粘滞、碎片有重量与落点 |
| 异能被动（常驻微特效） | 常驻特效每场只能 1 个（如眼中微光），强度写死不变，防跨镜漂移 |

**预算原则**：单镜围绕一条主特效因果链组织，次级特效只有在同一因果链中承担环境反应或结果证据时才保留；多粒子+变形+大范围等高负荷特效镜的密度是成本与稳定性风险信号，具体数量按叙事必要性、目标模型能力和项目批准预算决定，不设单集通用配额。特效是为叙事服务的，不是烟花秀——回 Director's Read 问「没有这特效，这场戏还成立吗」，不成立才保留为主特效。

## ③ 修复规则

| 失败 | 加锁 |
|---|---|
| 特效漂浮无源头 | 补源头+接触点：「从 X 发出，命中 Y，Y 表面留下 Z」 |
| 特效不发光却照亮/发光不照亮 | 光交互写死：「蓝光在人物面部与地面投下同色反光」 |
| 特效盖住脸/手 | 路径改写绕开；或把脆弱锚移出特效区 |
| 特效永不消散 | 补消散方式与时长：「命中后 1 秒内熄灭成青烟」 |
| 一镜多个主特效打架 | 砍到 1 个，其余降级为环境微光或删 |
| 变身中间态崩坏 | 改两镜：变身前定格 →（黑场/粒子遮挡过渡）→ 变身后亮相，不生成中间过程 |
