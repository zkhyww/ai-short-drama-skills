# 维度卡 · 音效（dim-audio）

> Contract 结构：①契约要素 ②选择表 ③修复规则。

## ① 声画核对维度（按当前声音职责取用，不逐镜填四格）

1. **三层世界声**（A1 环境层/A2 动作层/A3 点效层）+ 关键音效 + 音乐层：A1 证明地点时间空间（一个声学空间一个底床，换场景必换或给声音桥）；A2 证明可见动作接触（时机材质匹配）；A3 标记高信息事件（稀疏，一 cue 独占瞬间）。**对白以 0dB 作相对主音量基准**；承担前景表演的歌唱/说唱/念白不是 BGM，按可懂度、实际声部与戏剧焦点相对配平，其余层递减。**背景配乐与剧情内音乐的完整规则见 `references/dimensions/dim-music.md`**。
2. **只写反应声**：声音是角色与世界对事件的反应（椅子刮地/呼吸一滞/门轴声），**不写覆盖声**（不用音乐盖掉表演、不用音效填满每秒）。**声音讲画外故事（v1.7.3 增 · 判断口径）**：画面拍不到的，声音可以讲——画外一声关门比拍人离开更冷，邻室的争吵、楼上的脚步、突然停掉的电视，都在扩展画面外的世界与悬念；留白处的静默不是空缺，是让观众竖起耳朵的张力（与「对峙静默=room tone」同一原理）。画外声要有**可推断的来源**（画外故事与画内事实一致，不凭空发声）。
3. **关键音效标时间**：与分镜时间线对齐（「0:02 信封撕开的脆响，-6dB」）。
4. **发声、声部与口型按声音类型分开**：剧本已写明的对白、OS（内心独白）、VO（画外音）、歌唱、说唱、戏曲念白/唱腔或合唱都是有效输入，不需要用户再次授权。对白与可见演唱只驱动实际发声者的口型/发声动作；OS 不驱动角色说话口型；VO 保留画外声源，听者不代动嘴。合唱、对唱和乐队写清可见发声人、声部/乐器、进入、接续、重叠与中断；无普通对白不等于无表演声音。未要求不擅加旁白或字幕，也不能用「无画外音/无BGM」删掉剧本已有声音。

### 原生音频双轨制（v1.13.4 增 · Seedance 2.0 音视频联合生成口径）

Seedance 2.0 原生支持音频与视频联合生成——对白、环境音、动效音、BGM 在同一次生成内产出，**默认走原生音频轨，TTS 独立配音降为后备**。提示词侧落实：

- **Seedance 提示词格式（与剧本母稿格式分层）**：按火山方舟 Seedance 2.0 提示词指南，先写角色、动作、表情与发声方式，再把**台词内容放在 `{}` 内**；音乐用 `（）`、音效用 `<>`、字幕用 `【】`。例如：`林晚放下手机，眼眶微红，轻声说{原来是这样}`。多角色逐角色分行，禁止两人台词挤一行。Dreamina 页面示例也接受 `Girl says happily: "..."` 一类自然语言引号句式，但不能把它写成覆盖所有接入方的唯一官方格式；`execution` 服从本次 provider/adapter 的当前指南与实测。
- **音色锚定**：每个独立 Clip 在第一段将实际音频绑定人物与控制职责，第八段引用该绑定并写必要声线/执行变化；没有音频时第八段如实写用户待匹配或已确认方向。只作音色参考的样本不继承原台词、情绪、语速、停顿或背景声，本段表演按剧本与第五段；用户明确要样本控制节奏/表演或作为成品音轨时分开声明。下个独立 Clip 重新携带实际需要的绑定，不假定跨调用有记忆；文字方向不保证锁音色，不冒充已冻结音频。 固定文字声线时，把稳定身份方向（已确认的年龄感、语言/口音、音高和音色特征）与本句音量、急缓、情绪、气息变化分开；跨独立请求重复同一方向只能提高可比性，不能保证同音色。未实际试听的特征不反推为已确认声音事实；用户接受画面或整段不自动等于音色冻结。
- **用户选声与按需母音色复用**：默认用户针对人物匹配声音，普通镜头只继承实际选择与声线方向，不自动筛选、提取、冻结音色或拆音轨。未提供选择时标“用户待匹配”，角色/声音逻辑编号不冒充平台 voice_id。已冻结母音色或用户提供实际音频且接口支持时，按本次真实参数绑定；只有明确委托声音管理才启用 asset-library §7，不能只靠重复文字音色描述声称已锁定音色。实际音频参考与首尾帧模式互斥时说明差异，不静默改模式或转 TTS；仅缺接口必需输入时暂停相关调用。
- **音效具体化**：写"脚步声踩在湿石板上"不写"合适的背景音"；生成提示词写对白清晰、关键声可辨及背景避让；dB 数值留给实际后期混音及测量，不承诺生成模型精确执行电平。
- **翻车回退（涉及外部配音/拆音轨须已有用户授权）**：音色跨镜漂移/口型乱动/串音——先带已冻结母音色参考重生最小受影响 Clip；长对话戏持续不稳定或当前接口不接受音频参考时，才由已选外部 TTS 生成逐句 WAV，再走 lip-sync 与 `scripts/assemble_timeline.py --external-audio` 合成。外部音轨必须预先按整段成片时间线对齐，脚本不会把逐句 WAV 自动定位到镜头；`replace` 替换整条音轨（环境声/动效也须纳入外部混音），`mix` 仅适用于已移除冲突原人声的底轨或新增非冲突声层，不可把新配音叠在旧对白上。官方 `dreamina` CLI 没有独立 TTS 子命令，不得虚构 `dreamina audio`。

**普通说话容量与连续声窗（制作侧说话估算口径）**：按项目语言分流，不把一种语言的配额硬套另一种。中文写实情感对白首轮按 **3–3.5 发音字/秒纯发声 + 情绪呼吸停顿**估算，这是制作默认，不是统一行业标准；4–4.5 字/秒可见于较快表达，不能拿来保证每个人都说得完。30 秒直出专项的英文普通对白首轮按 **40–55 个发音词、130–150 WPM + 情绪呼吸停顿**估算；40 不是补话下限，无任何逐字发声内容才写 `NONE`。项目指定其他语言、英语口音或角色语速时按实际实读/试听修正。数字、英文、缩写按实际读法展开估时，标点不计字但停顿计时。每句保留 `声音ID / 发声者 / 类型 / 完整正文 / 起止秒 / 覆盖镜号`，普通任务直接落第五段发声时码，不另建逐句参数表；专项工程才按需输出表格。

**演唱/说唱/合唱时间轴**：不使用上述字速、WPM 或 40–55 词预算认证歌唱时长。优先读取已绑定的实际乐句/歌曲参考时间轴；没有音轨且只做原创规划时，旋律走向、BPM、拍号与乐句长度只能作为明确的制作设计建议并标未锁，再按乐句、换气、延音、休止、声部重叠及进入/接续/中断估时。指定曲目、歌词或编曲但素材不可用时列真实依赖，不能用母音色或普通说话时长替代。可见发声区间、乐器/肢体接触和表演进度与画面使用同一时间轴；每个 Clip 不强制唱完整句或统一收尾，跨 Clip 只有实际完整音轨或自然乐句边界才可连续。

- 普通说话估算式：所需声窗 = 实际发音量 ÷ 选定语速 + 气口停顿。30 个中文发音字约需 8.6–10 秒纯发声，再加停顿；英文以 `发音词数 / WPM × 60` 计算纯发声。例如 55 词按 130 WPM 发声约 25.38 秒，再加 8 秒气口与反应，总计约 33 秒，不能通过 30 秒专项容量核对。若实读整句时长已含停顿，不重复加。发音量与算式用于内部容量核对，不要求写入最终 Prompt；普通说话逐句发音量求和必须等于 第五段的内部声窗预算 的说话总发音量；顺序对白的逐句起止声窗时长求和必须大于或等于“纯发声时长 + 已声明停顿”，否则总预算或声窗至少一项不成立。演唱另按上段实际乐句/音轨核验，不代入本公式。
- 同一声窗内顺序发声的所有角色共用时间，不能各领取一次完整组时长；不借抢话/叠音作弊扩容。反应画面可与声音同时发生，必须在说完后才发生的动作另留时间。
- 先以完整句/意群和表演估时，试听后修正。30 秒直出专项容量不足时先重排画面，仍不足则回剧情层等待裁决；不得延长、拆分/分单或加速。其他时长沿用通用回退：先重排画面、延长到接口允许的时长，或在自然意群处分组。确需改写台词退回剧本侧，不自动删词、断句或加速保住旧秒数。规划估算通过不等于真实语音/口型已通过。

**相对电平基准**（混音参考，吸收 manju-laoli）：**0dB 为相对基准（以对白电平归一，非绝对响度）**——对白 0dB / 关键音效 -6dB / BGM -14~-18dB / 环境底噪 ≤-20dB；前景演唱/说唱按可懂度与戏剧焦点建立人声—乐器层级，不把它整体压成 BGM，也不覆盖同段承重对白；交付前按平台响度规范整体拉齐。

**声线矩阵**：任意两个高频对话角色，声线差异 ≥2 个可听维度（音高/语速/音色/口音/节奏），防 AI 配音全员一个嗓。

**声音的视点与距离（v1.7.4 增 · 判断口径）**：声音不是给画面配一个对位音效的客观平面，它可以表现**观众正跟随谁的感受**——人物紧盯某件事时其他环境声暂时退后；受冲击时现场声短暂变闷/失真/只剩呼吸；门外的脚步可以先让观众听见、人物稍后才发现（先闻后见=悬念）；远处声音要有距离、遮挡与空间反射，不与近处同样清晰；画外声扩展看不见的空间（与「声音讲画外故事」同源）。按职责分清来源：被摄者的对白、呼吸与动作声跟随人物和画面；摄影者/记录者的呼吸、脚步或操作声只有主观记录视角确需时才进入；画外声音负责扩展未入画空间或先行信息，不伪装成画内同步声。全部声层的清晰度追随注意力与心理状态，不追求均匀同等清晰，也不为凑三类来源全部加入。

**声音与画面不必同时切换（J-Cut / L-Cut）**：J-Cut 是后续画面的声音先进入；L-Cut 是前一画面的声音在切画面后继续。对话中可以先看到说话人开口，再切听者反应、相关道具或空间，原对白连贯播放、不断句、不加速；仍保留该台词的对白身份，不因人在画外就改写成 OS 或旁白。反应镜中的听者保留自然表演，不替声源动嘴。按叙事需要使用，不每句套反应镜。

先为整句分配连续音频起止秒，再在该区间排视觉切点；完整正文只放在格式路由的唯一对白位（通用【声音】/30 秒专项 Block 5），视觉段（通用【画面内容】/专项 Block 7）按台词 ID 标发声进度与可见口型区间，专项 Block 8 不复写台词。**L-Cut 不增加声窗容量，也不是把台词按镜头平均切碎。** 声音可跟随人物感受或扩展画外空间，不能因此打乱其来源与时间。

**执行边界**：同一原生生成 Clip 内可提示连续对白跨镜，但必须实听确认无截词、重说、加速或串嘴。跨独立生成 Clip 不能只凭重复文字承诺无缝声音：采用自然意群切分，或使用一条实际完整音轨，让剪辑在切画面时延续其对应时间段。保持原生音频优先，必要时才用外部 TTS；`assemble_timeline.py --external-audio` 只接受预先按整段时间线对齐的音轨，不会自动逐句定位。按实际音轨决定画面入出点，不反过来压缩长句。

依据：[Adobe J-Cut / L-Cut](https://www.adobe.com/creativecloud/video/discover/j-cut-and-l-cut.html) 定义剪辑关系；[W3C SSML 1.1 prosody](https://www.w3.org/TR/speech-synthesis11/#edef_prosody) 指出语速随语言、声音与处理器而异，停顿另有 break。两者不证明中文统一字速，也不代表视频接口支持 SSML 参数。

**情绪→TTS 参数映射**（配音交付时用，吸收 aladin-drama-dub；**方向性参考非通用规范**——pitch ±Hz、rate ±% 的取值范围与符号方向随 TTS 供应商而异，交付前按所选供应商文档适配）：愤怒=style angry + rate+10% + pitch+6Hz；悲伤=rate-8% + pitch-3Hz；急促=rate+15%；耳语=volume-6dB + rate-10%。逐句合成，改句只重录该句。

### 逐句声音表演合同（防机械配音）

`emotion/style` 只能说明大类情绪，不能代替人物表演。闻笙先继承角色的声音指纹和已冻结母音色，再按台词的戏剧动作写**变化项**；普通功能句无需把下列字段全部抄一遍，承重台词至少明确 `speech_action + subtext + operative_words + thought_beats`：

| 字段 | 要回答的问题 | 写法示例 |
|---|---|---|
| `speech_action` | 这句话正在对对方做什么 | 试探 / 压住 / 诱导 / 讨好后反咬 |
| `subtext` | 嘴上没说出的真实意思 | 我知道真相，但等你先露底 |
| `operative_words` | 哪 1–3 个词承载转折或攻击 | 重读「你」「早就」「知道」 |
| `thought_beats` | 思维在哪换挡，怎样停连 | `你早就知道 / 还看着我去查`；斜线处短停 |
| `tempo_curve` | 语速怎样变化 | 前慢压住，中段加速，末尾骤停 |
| `intensity_curve` | 力度/音量怎样起伏 | 低压 → 短促抬强 → 收回，不一路喊满 |
| `pitch_contour` | 音高与语调怎样走 | 低起、关键词上扬、结尾下坠 |
| `pause_and_breath` | 哪些停顿与气息有意义 | 开口前吸气；关键词后停半拍；末句气息不断 |
| `terminal_contour` | 句尾是落、扬、悬还是吞回 | 下落封口 / 上扬试探 / 悬停未说完 |

**抑扬顿挫原则**：音高、时长、强度和停顿必须服务 `speech_action` 与 `subtext`，不是随机起伏；一句内部至少有可听的主次关系，承重词突出，非承重字退后。标点只提供初始分句，最终停连按思维节拍、呼吸和对手反应决定。避免全句同速、同强、同高，也避免每句都套同一套「先慢后快、句尾下沉」。

**供应商翻译**：支持 SSML 时把命中项翻译为 `prosody / emphasis / break / phoneme`；只支持自然语言控制时写成可听见的动作指令；只支持 `style/rate/pitch` 时保留完整表演意图，并把参数当近似映射。任何接口不支持的控制项不得伪造成已执行，改由分句生成、剪辑停顿、独立 TTS 或对口型链路实现。

技术锚：[W3C SSML 1.1](https://www.w3.org/TR/speech-synthesis11/) 的 `prosody/emphasis/break/phoneme` 与 [CosyVoice](https://github.com/FunAudioLLM/CosyVoice) 的说话人身份、情绪、语速和音量控制只用于定义可表达维度；实际字段、取值与可用能力始终服从本次 TTS/provider 的实时 schema。

## ② 选择表（场景 → 环境音底）

| 场景 | 环境音（参考 dB） |
|---|---|
| 雨夜室外 | 持续雨声 -12dB + 远处车声 |
| 豪门宴会 | 人群低语 -15dB + 杯盏轻碰 |
| 老宅室内 | 木地板吱呀/钟摆 -18dB |
| 医院 | 仪器滴声 -12dB + 脚步回响 |
| 对峙静默 | 房间底噪（room tone）-20dB，**留白即张力** |
| 舞台/现场演奏 | 场地底床 + 实际演唱/乐器声源与声部 + 观众反应；掌声/欢呼只在事件触发后进入，不盖掉表演进度 |
| 水下/失重/隔舱等特殊环境 | 按已定介质、舱体与叙事听觉规则写可听范围、遮挡、振动/设备传导与交流方式；不把恒定室内空气声或普通脚步硬套所有环境 |

**BGM 使用原则**：默认不额外添加背景配乐；此默认与不生成叠加字幕/水印一起在 prompt-assembly 第一段明示，不能只留在 QC；“无 BGM”只关闭非剧情背景 cue，不删除剧本内歌唱、演奏、广播/设备播放或仪式音乐。需要背景音乐时按 `dim-music.md` 写 cue（进入点/情绪/能量/退出），不盖台词或前景表演。

## ③ 修复规则

参考音频相关失败先分清平台回执、界面提示、用户判断与已验证事实。移除音频后成功只证明该次输入组合结果改变，不能据此宣布音频必然侵权或把该 provider 的失败推广为所有模型规则；如实保留未知原因与已执行的输入差异。后续是否上传、换来源或转外部配音服从现有授权，不自动提取/上传成片人声。

| 失败 | 加锁 |
