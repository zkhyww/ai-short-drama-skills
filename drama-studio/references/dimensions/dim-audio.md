# 维度卡 · 音效（dim-audio）

> Contract 结构：①契约要素 ②选择表 ③修复规则。

## ① 契约要素（每镜必齐 4 项）

1. **三层世界声**（A1 环境层/A2 动作层/A3 点效层）+ 关键音效 + 音乐层：A1 证明地点时间空间（一个声学空间一个底床，换场景必换或给声音桥）；A2 证明可见动作接触（时机材质匹配）；A3 标记高信息事件（稀疏，一 cue 独占瞬间）。**人声/对话始终主音量 0dB**，其余层音量递减。**氛围音乐与音乐 cue 的完整规则见 `references/dimensions/dim-music.md`**（安全时长/情绪矩阵/槽位制/母题法）。
2. **只写反应声**：声音是角色与世界对事件的反应（椅子刮地/呼吸一滞/门轴声），**不写覆盖声**（不用音乐盖掉表演、不用音效填满每秒）。**声音讲画外故事（v1.7.3 增 · 判断口径）**：画面拍不到的，声音可以讲——画外一声关门比拍人离开更冷，邻室的争吵、楼上的脚步、突然停掉的电视，都在扩展画面外的世界与悬念；留白处的静默不是空缺，是让观众竖起耳朵的张力（与「对峙静默=room tone」同一原理）。画外声要有**可推断的来源**（画外故事与画内事实一致，不凭空发声）。
3. **关键音效标时间**：与分镜时间线对齐（「0:02 信封撕开的脆响，-6dB」）。
4. **对话规则**：只有说台词的角色嘴唇动，其他人静默；**按表演和剪辑需要留气口**（参考：台词前后各 ≥1 秒静默、短句间 ≥0.5 秒，可按节奏调整）；无字幕、无旁白（除非用户要）、无画外音；情绪递进时声画同步（声线变化跟上表演强度）。

### 原生音频双轨制（v1.13.4 增 · Seedance 2.0 音视频联合生成口径）

Seedance 2.0 原生支持音频与视频联合生成——对白、环境音、动效音、BGM 在同一次生成内产出，**默认走原生音频轨，TTS 独立配音降为后备**。提示词侧落实：

- **Seedance 提示词格式（与剧本母稿格式分层）**：按火山方舟 Seedance 2.0 提示词指南，先写角色、动作、表情与发声方式，再把**台词内容放在 `{}` 内**；音乐用 `（）`、音效用 `<>`、字幕用 `【】`。例如：`林晚放下手机，眼眶微红，轻声说{原来是这样}`。多角色逐角色分行，禁止两人台词挤一行。Dreamina 页面示例也接受 `Girl says happily: "..."` 一类自然语言引号句式，但不能把它写成覆盖所有接入方的唯一官方格式；`execution` 服从本次 provider/adapter 的当前指南与实测。
- **音色锚定**：模型从角色描述推断声线（性别/年龄/地域线索）——把闻笙声音指纹的音色要点（音高/语速/质感）翻译进每镜对白行（"低沉沙哑的男声""清脆女声带喘息"），**每镜重复写**（各镜独立生成无音色记忆，不重复写会跨镜漂音）。
- **母音色复用**：角色尚无合格样本时，先从该角色首次发声起用原生音频生成候选；**已冻结母音色**且当前 provider 支持音频参考时，把母音色样本作为每个后续正式对白镜的音频参考，Dreamina 路由为 `multimodal2video --audio`。同时在 Prompt 中按上传顺序明确绑定音频编号、角色与音色用途，例如“音频 1 是林晚母音色，仅参考其音色”；Seedance 2.0 全能参考还须随镜带角色图或视频，2.5 才允许纯音频输入。这仍由 Seedance 原生生成对白、环境声与口型，不是独立配音；文字音色描述继续逐镜写以控制语气与表演变化，但**不能只靠每镜重复文字音色描述**声称母音色已锁。若 provider 不支持或音频参考实听仍不稳，外部 TTS 才是后备。
- **音效具体化**：写"脚步声踩在湿石板上"不写"合适的背景音"；混音层级（对白 0dB>关键音效-6dB>环境≤-20dB>BGM -14~-18dB）不变，只是从后期混音前移到提示词内声明。
- **翻车回退**：音色跨镜漂移/口型乱动/串音——先带已冻结母音色参考重拍受影响单镜；长对话戏持续不稳定或当前接口不接受音频参考时，才由已选外部 TTS 生成逐句 WAV，再走 lip-sync 与 `scripts/assemble_timeline.py --external-audio` 替换或混合音轨。官方 `dreamina` CLI 没有独立 TTS 子命令，不得虚构 `dreamina audio`。

**台词容量参考**：3.5–4.5 字/秒是**纯发声语速**；下表是把台词前后气口、停顿与反应一起计入后的**时间线有效语速**，所以更保守：3 秒约 ≤7 字（中文）/11 词（英文）；5 秒约 ≤12 字/20 词；7 秒约 ≤17 字/28 词；15 秒约 ≤45 字。**单句 >24 字建议拆 2-3 镜**（每镜约 ≤18 字，吸收 manju-laoli）；金句后的发酵时长按表演落点裁量，优先留在相邻镜内（见 shot-contract）。写台词先估时长并试听，气口、对白、反应共同纳入镜头总时长；数值只作排期风险提示，不自动判失败。

**相对电平基准**（混音参考，吸收 manju-laoli）：**0dB 为相对基准（以对白电平归一，非绝对响度）**——对白 0dB / 关键音效 -6dB / BGM -14~-18dB / 环境底噪 ≤-20dB；交付前按平台响度规范整体拉齐。

**声线矩阵**：任意两个高频对话角色，声线差异 ≥2 个可听维度（音高/语速/音色/口音/节奏），防 AI 配音全员一个嗓。

**声音的视点与距离（v1.7.4 增 · 判断口径）**：声音不是给画面配一个对位音效的客观平面，它可以表现**观众正跟随谁的感受**——人物紧盯某件事时其他环境声暂时退后；受冲击时现场声短暂变闷/失真/只剩呼吸；门外的脚步可以先让观众听见、人物稍后才发现（先闻后见=悬念）；远处声音要有距离、遮挡与空间反射，不与近处同样清晰；画外声扩展看不见的空间（与「声音讲画外故事」同源）。全部声层的清晰度追随注意力与心理状态，不追求均匀同等清晰。

**声音与画面不必同时切换（v1.7.4 增 · 叙事选择）**：**声音先入**——提前建立下一场期待/让观众先听见危险再看见来源/用一句话改变当前画面的含义/平滑连接两个空间；**声音延续**——上一场的情绪压到下一场/没说完的话留在新画面上/让反应镜头比说话者更重要/连接因果相关但空间不同的两场。声音桥、提前入声、延后出声都是叙事选择，按需要使用、不每场必用、也不只当转场装饰；与「关键音效标时间」配合时，画外/延后声的时间戳同样对齐分镜时间线。

**情绪→TTS 参数映射**（配音交付时用，吸收 aladin-drama-dub；**方向性参考非通用规范**——pitch ±Hz、rate ±% 的取值范围与符号方向随 TTS 供应商而异，交付前按所选供应商文档适配）：愤怒=style angry + rate+10% + pitch+6Hz；悲伤=rate-8% + pitch-3Hz；急促=rate+15%；耳语=volume-6dB + rate-10%。逐句合成，改句只重录该句。

### 逐句声音表演合同（防机械配音）

`emotion/style` 只能说明大类情绪，不能代替人物表演。闻笙先继承角色的声音指纹和已冻结母音色，再按台词的戏剧动作写**变化项**；普通功能句无需把下列字段全部抄一遍，承重台词至少明确 `speech_action + subtext + operative_words + thought_beats`：

| 字段 | 要回答的问题 | 写法示例 |
|---|---|---|
| `speech_action` | 这句话正在对对方做什么 | 试探 / 压住 / 诱导 / 讨好后反咬 |
| `subtext` | 嘴上没说出的真实意思 | 我知道真相，但等你先露底 |
| `operative_words` | 哪 1–3 个词承载转折或攻击 | 重读「你」「早就」「知道」 |
| `thought_beats` | 思维在哪换挡，怎样停连 | `你早就知道 / 还看着我去查`；斜线处短停 |
| `tempo_curve` | 语速怎样变化 | 前慢压住，中段加速，末尾骤停 |
| `intensity_curve` | 力度/音量怎样起伏 | 低压 → 短促抬强 → 收回，不一路喊满 |
| `pitch_contour` | 音高与语调怎样走 | 低起、关键词上扬、结尾下坠 |
| `pause_and_breath` | 哪些停顿与气息有意义 | 开口前吸气；关键词后停半拍；末句气息不断 |
| `terminal_contour` | 句尾是落、扬、悬还是吞回 | 下落封口 / 上扬试探 / 悬停未说完 |

**抑扬顿挫原则**：音高、时长、强度和停顿必须服务 `speech_action` 与 `subtext`，不是随机起伏；一句内部至少有可听的主次关系，承重词突出，非承重字退后。标点只提供初始分句，最终停连按思维节拍、呼吸和对手反应决定。避免全句同速、同强、同高，也避免每句都套同一套「先慢后快、句尾下沉」。

**供应商翻译**：支持 SSML 时把命中项翻译为 `prosody / emphasis / break / phoneme`；只支持自然语言控制时写成可听见的动作指令；只支持 `style/rate/pitch` 时保留完整表演意图，并把参数当近似映射。任何接口不支持的控制项不得伪造成已执行，改由分句生成、剪辑停顿、独立 TTS 或对口型链路实现。

技术锚：[W3C SSML 1.1](https://www.w3.org/TR/speech-synthesis11/) 的 `prosody/emphasis/break/phoneme` 与 [CosyVoice](https://github.com/FunAudioLLM/CosyVoice) 的说话人身份、情绪、语速和音量控制只用于定义可表达维度；实际字段、取值与可用能力始终服从本次 TTS/provider 的实时 schema。

## ② 选择表（场景 → 环境音底）

| 场景 | 环境音（参考 dB） |
|---|---|
| 雨夜室外 | 持续雨声 -12dB + 远处车声 |
| 豪门宴会 | 人群低语 -15dB + 杯盏轻碰 |
| 老宅室内 | 木地板吱呀/钟摆 -18dB |
| 医院 | 仪器滴声 -12dB + 脚步回响 |
| 对峙静默 | 房间底噪（room tone）-20dB，**留白即张力** |

**BGM 使用原则**：默认「无 BGM 只留对白与环境声」（与 storyboard-craft 全局设定一致）；用户明确要音乐或在安全时长内加氛围音乐时，按 `dim-music.md` 写 cue（进入点/情绪/能量/退出），不盖台词。

## ③ 修复规则

| 失败 | 加锁 |
|---|---|
| 音效堆砌每秒都响 | 删到只剩关键音效，静默处留白 |
| BGM 盖台词 | 「对白 0dB 主音量，BGM ≤ -18dB，台词出现时音乐避让」 |
| 全员一个嗓 | 声线矩阵核对，不足 2 维差异重写声线描述 |
| 台词像机器念稿 | 补 `speech_action/subtext/operative_words/thought_beats`，再写语速、强度、音高、停顿与句尾的变化项；禁只换 emotion 标签 |
| 音画不同步 | 关键音效时间戳与分镜时间块逐项对齐 |
