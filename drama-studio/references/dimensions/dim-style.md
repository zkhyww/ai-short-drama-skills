# 维度卡 · 风格（dim-style）

> Contract 结构：①契约要素 ②选择表 ③修复规则。全片风格母版详见 storyboard-craft 第 8 节（首集锁定后续继承），本卡管逐镜落地与防漂移。

## ① 契约要素（每镜必齐 5 项）

1. **母版继承声明**：本镜继承首集风格母版（类型基调/时代/色彩方案/用光哲学/写实等级/摄影语言/美术材质/风格禁区），只写差异项，不重贴全文。
2. **60/30/10 色彩**：主色 60% + 辅色 30% + 点缀 10%，用真实颜色名（暖赭/炭黑/锈红），从母版或参考图取，不临时发明。
3. **写实等级**：写实真人 / 半写实 / 漫剧（韩漫/日漫/国漫/CG）——与载体一致，全片不跳级。
4. **参考图职责**：每张参考图只管一件事（身份/环境/动作/节奏/风格/终点），一图多职=漂移主因。
5. **视觉母题随故事演变（v1.7.3 增 · 判断口径）**：贯穿道具/色彩/构图习惯这类母题（如情感线的贯穿符号，见 story-structure §3 铁律 6），其形态要跟着故事阶段**变**——同一枚戒指，蜜月期干净明亮、决裂期蒙尘、收官期归还时定格；母题不变=观众视而不见，母题的每次变形都是一次无声叙事。变形属于**继承差异项**（第 1 项「只写差异项」的正常用法），不算风格漂移；但变形要有叙事事件托底，不为变而变。

## ② 选择表

**平台适配微调**（提示词交付前按目标平台过一遍）：Sora=历史迁移参考、永不自动选择；可灵=精简光影音频保分镜运镜；即梦=强化风格关键词/漫剧友好；Vidu=全模块中文；LibTV=节点式每镜一节点；Seedance=时间轴结构。

## ③ 修复规则

| 失败 | 加锁 |
|---|---|
| 跨镜风格跳变 | 「继承风格母版：色彩方案/用光哲学/写实等级与首集一致」写进每镜定调 |
| 色彩脏/配色乱 | 回 60/30/10 重算，点缀色只能一个 |
| 参考图互相打架（风格图盖了身份图） | 职责重排：身份>空间>动作>风格，后者服从前者 |
| 提示词出现禁用词 | 黑名单：masterpiece/电影级/高级感/大片感/ cinematic（空话类）→ 换具体物理描述 |
