# 维度卡 · 站位（dim-blocking）

> Contract 结构：①契约要素 ②选择表 ③修复规则。本卡是本 skill 核心增量（多角色同框稳定器）。

## ① 契约要素（每镜必齐 5 项，即站位五要素锁）

先复用场景资产里的门窗、通路、家具与关键固定物的相对关系，镜头只改变观看位置，不重新设计房间。多人移动或复杂接触沿用下文风险触发的俯视示意，标起点、路径、落点及机位/轴线；普通对话用已有地标短述即可，不每镜重画。

**遮挡与穿越必须有路线**：钻下、绕过、穿门、从人后探出等动作，先写清从哪个地标面进入、经过哪条空隙、向哪个地标面离开或停住，何时被什么遮住，以及切回应出现的位置。以空间中的固定面命名，不只写随机位变化的“左边/后面”。路线须容得下身体和所持物，出口被占据时注明阻拦者与停止位置，不能默许穿过人、实体家具或封闭结构。关键进入/离开或转向至少在承重镜头中可辨；不必完整展示无意义路程，也不强制一镜到底。反应特写继承人物当时落点与视线对象；只见脸/头顶不能证明已经完成穿越。负面词“无瞬移/不越轴”不能代替上述正向调度。

每个出场角色锁定当前状态（不变项继承，只写变化）：**银幕位置**（画面左/中/右、前中后景）+ **世界位置**（房间哪里/与谁相对）+ **与地标距离**（可测量锚点）+ **身体朝向**（躯干朝谁/朝哪）+ **视线方向**（眼看谁——与躯干分开写）。

**禁弱词**：near/beside/附近/旁边/周围 → 换可测量锚点：「1 米内」「手扶门把」「背贴墙」「站在招牌正下方」「在出租车后门前」。**量词相对化**（吸收 Mx-Shell）：优先身体/画面相对量（一臂距离/画面 1/2/比对手高半头），禁 cm 级假精确（AI 执行不了精确数值，只会制造漂移）。

**180° 轴线**：先标本段的对话轴/行动轴与摄影机所在侧，正反打沿同侧组织相向视线；房间、人物和道具的世界位置不随反打镜像。人物真实移动、交换位置或摄影机连续跨轴可以改变银幕左右，但过程须让观众读懂，之后沿新轴组织。确需跨轴时可用连续运镜、轴线上中性视角或重新建立空间；正面对称/俯拍本身不保证中性，仍核实际轴线与地标，避免把不相连空间伪装成连续。

**距离分区（Proxemics）**：<0.5m 亲密或暴力（闯入=侵略）/ 0.5-1.2m 信任 / 1.2-3.5m 公事戒备 / 3.5m+ 疏离层级。**距离变化 = 节拍变化**——谁逼近、谁破距、谁僵住，就是戏。

**构图表现关系（v1.7.3 增 · 判断内核）**：站位与距离不只是防崩参数，是关系的可见形态——谁占画面更大、谁在前景谁被挡、两人同框时谁高半头、负空间把谁隔开，观众不用听台词就读出了权力与亲疏。写站位五要素时顺带自问一句：这个几何关系**表现**出的关系，和这场戏戏剧上的关系一致吗？（一致 = 站位在演戏；不一致 = 要么是刻意反讽，要么改站位。）

**人物调度先于摄影调度（v1.7.4 增 · 判断顺序）**：先想人物**为什么**站在那里、为什么靠近/退后/绕开/坐下/挡住别人，再决定摄影机放哪里。有戏的调度来自人物策略：想控制局面的人占出口、断别人路线；想逃避的人借整理东西/倒水/看手机避开对视；关系占优的人未必站得高，可能坐着不动让别人主动靠近；关系变化时，距离、朝向与行动权限跟着变。站位五要素负责**稳定**人物位置，本条负责**解释**人物为什么这样站、何时需要改变位置——人物关系没有进入空间时，再漂亮的运镜也只是在拍对白，先用调度让站位有理由，再谈机位。

**姿态可读性按缺口修正**：在人物动机、既定动作与承重接触成立后，才检查头、躯干、腿的朝向是否需要错开；转脸和歪头分别描述，眼神对象继续继承剧情。关节僵硬时只选择一个必要的屈肘、微屈膝或身体倾斜，不同时堆满动作。手腕与前臂、脚与腿的连接要符合支撑、持物和运动，不能为了线条优美强踮承重脚。手有明确落点；遮挡时交代它在何物后、仍在做什么，不能把画外或遮挡误判为缺肢，也不强制露出全部手指。姿态短述可用“站坐方式＋各部位必要朝向＋一个当前动作”，例如“侧坐椅上，躯干朝门，脸转向来人，右手扶椅背”；其余保持已定状态。

正面中性设定、僵住的反应、伤病代偿和运动中的有力折角均可成立，不为美姿改掉角色事实或把剧情镜摆成写真。修复时先区分朝向、弯曲、关节连接或遮挡问题，只改对应项；景别裁掉承重手脚时回 dim-shot-size 调整取景，不在看不见的位置堆细节。方法参考：[南鸢美姿文章](https://x.com/nanyuan0412/status/2098939503813759389)（2026-09-15 已读文字，配图示例未完整核验；非生成复现）。

## ② 选择表

**多人动作三层制**（焦点与复杂度分配工具，不是限制演员只能静止的硬规则；按时间窗区分主动作与反应）：

| 层 | 内容 | 用法 |
|---|---|---|
| 1 持续微动作（默认层） | 呼吸/眨眼/肩部微动/发梢飘/视线游离 | 所有非焦点角色 |
| 2 聚焦反应 | 一个人+可见反应+明确时间窗：「B 嘴角上扬，与 A 对视后避开」 | 优先突出承重反应；并行反应有叙事必要时写清人物与时序 |
| 3 大动作 | 站起/走动/转身/拿取，写清动机、路径与接触关系 | 叙事需要则保留；仅在实际执行不稳时错峰、拆镜或简化非承重动作 |

**镜头类型 → 焦点分配**：对话焦点可在说话人，也可随 L-Cut 转给听者的承重反应，不按“谁在说话”机械分层；群像保主焦点，背景有因果必要的行动仍保留。风险触发的空间图中，文戏标视线/出口/轴线，战斗标路线/掩体/高差/攻击范围，复用 asset-library 场景板，不另建固定图集。

## ③ 修复规则

| 失败 | 加锁 |
|---|---|
| 角色站位含糊/左右跳 | 五要素逐项补齐，缺项视为未装配 |
| 视线反向（没看对话对象） | 绑定实际对象、方位与高度，并继承剧本的看向/避开/再看节拍；不以全程死盯消灭合法表演 |
| 手-道具物理在多人时崩坏 | 按 failure-atlas §3.3 核当前输入、参考与模型能力，先保住已锁关键接触、转移及其结果；可换动作参考、拆到可读步骤或交后期。只有非承重接触才可简化；拆镜、单人视角或移出画外也必须让锁定动作、结果及观众可读的叙事功能完整保留 |
| 对话者嘴唇乱动 | 明确当前可见说话人及发声区间，其他人保留呼吸与反应但不代动说话口型；OS 内心独白、VO 画外音按剧本保留，不使用「无画外音」覆盖已有声音 |
| 同框角色出现身份混淆（一张脸演两个） | 回 asset-library 身份区分门，按当前帧/参考图和实际生产证据定位碰撞；保留已确认共同特征，只改真实造成混淆且非继承事实的必要生产设计，不以共用描述词直接判失败 |
| **左右颠倒/镜像站位**（吸收 deepwhite 俯视调度图） | **按风险触发**：两人普通对话不强制俯视图；多人移动、越轴风险、复杂道具互动或空间谜题（≥2 人且同框有位置关系且存在上述风险）**必须附俯视调度图**：画布俯视示意——谁在左/右、谁近门/窗、道具在哪个象限、机位在哪、人物朝向箭头；用文字+字符图或描述均可（「俯视：B 贴窗左，A 站门右，桌在中央偏左，机位在门侧」）。**命中风险场景却无俯视图=未装配** |
