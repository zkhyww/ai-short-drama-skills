# 维度卡 · 站位（dim-blocking）

> Contract 结构：①契约要素 ②选择表 ③修复规则。本卡是本 skill 核心增量（多角色同框稳定器）。

## ① 契约要素（每镜必齐 5 项，即站位五要素锁）

每个出场角色写死：**银幕位置**（画面左/中/右、前中后景）+ **世界位置**（房间哪里/与谁相对）+ **与地标距离**（可测量锚点）+ **身体朝向**（躯干朝谁/朝哪）+ **视线方向**（眼看谁——与躯干分开写）。

**禁弱词**：near/beside/附近/旁边/周围 → 换可测量锚点：「1 米内」「手扶门把」「背贴墙」「站在招牌正下方」「在出租车后门前」。**量词相对化**（吸收 Mx-Shell）：优先身体/画面相对量（一臂距离/画面 1/2/比对手高半头），禁 cm 级假精确（AI 执行不了精确数值，只会制造漂移）。

**180° 轴线**：对话双方银幕左右关系跨镜稳定；必要越轴时插中性机位（正面对称/俯拍）过渡；反打不得镜像房间。

**距离分区（Proxemics）**：<0.5m 亲密或暴力（闯入=侵略）/ 0.5-1.2m 信任 / 1.2-3.5m 公事戒备 / 3.5m+ 疏离层级。**距离变化 = 节拍变化**——谁逼近、谁破距、谁僵住，就是戏。

**构图表现关系（v1.7.3 增 · 判断内核）**：站位与距离不只是防崩参数，是关系的可见形态——谁占画面更大、谁在前景谁被挡、两人同框时谁高半头、负空间把谁隔开，观众不用听台词就读出了权力与亲疏。写站位五要素时顺带自问一句：这个几何关系**表现**出的关系，和这场戏戏剧上的关系一致吗？（一致 = 站位在演戏；不一致 = 要么是刻意反讽，要么改站位。）

**人物调度先于摄影调度（v1.7.4 增 · 判断顺序）**：先想人物**为什么**站在那里、为什么靠近/退后/绕开/坐下/挡住别人，再决定摄影机放哪里。有戏的调度来自人物策略：想控制局面的人占出口、断别人路线；想逃避的人借整理东西/倒水/看手机避开对视；关系占优的人未必站得高，可能坐着不动让别人主动靠近；关系变化时，距离、朝向与行动权限跟着变。站位五要素负责**稳定**人物位置，本条负责**解释**人物为什么这样站、何时需要改变位置——人物关系没有进入空间时，再漂亮的运镜也只是在拍对白，先用调度让站位有理由，再谈机位。

## ② 选择表

**多人动作三层制**（焦点与复杂度分配工具，不是限制演员只能静止的硬规则；按时间窗区分主动作与反应）：

| 层 | 内容 | 用法 |
|---|---|---|
| 1 持续微动作（默认层） | 呼吸/眨眼/肩部微动/发梢飘/视线游离 | 所有非焦点角色 |
| 2 聚焦反应 | 一个人+可见反应+明确时间窗：「B 嘴角上扬，与 A 对视后避开」 | 优先突出承重反应；并行反应有叙事必要时写清人物与时序 |
| 3 大动作 | 站起/走动/转身/拿取，写清动机、路径与接触关系 | 叙事需要则保留；仅在实际执行不稳时错峰、拆镜或简化非承重动作 |

**镜头类型 → 焦点分配**：对话正反打=说的人层 2、听的人层 1（反应先于对方台词结束）；群像=主角层 2、背景层 1 且动作简单。

## ③ 修复规则

| 失败 | 加锁 |
|---|---|
| 角色站位含糊/左右跳 | 五要素逐项补齐，缺项视为未装配 |
| 视线反向（没看对话对象） | 「双眼锁定 X，全程不移开，除非明确写移开」 |
| 手-道具物理在多人时崩坏 | 接触简化或移出画外；拿取动作给单人镜头 |
| 对话者嘴唇乱动 | 明确当前可见说话人及发声区间，其他人保留呼吸与反应但不代动说话口型；OS 内心独白、VO 画外音按剧本保留，不使用「无画外音」覆盖已有声音 |
| 同框角色描述雷同（一张脸演两个） | 回 asset-library 身份区分门，锚定描述禁词级雷同 |
| **左右颠倒/镜像站位**（吸收 deepwhite 俯视调度图） | **按风险触发**：两人普通对话不强制俯视图；多人移动、越轴风险、复杂道具互动或空间谜题（≥2 人且同框有位置关系且存在上述风险）**必须附俯视调度图**：画布俯视示意——谁在左/右、谁近门/窗、道具在哪个象限、机位在哪、人物朝向箭头；用文字+字符图或描述均可（「俯视：B 贴窗左，A 站门右，桌在中央偏左，机位在门侧」）。**命中风险场景却无俯视图=未装配** |
