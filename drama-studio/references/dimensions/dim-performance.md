# 维度卡 · 表演（dim-performance）

> Contract 结构：①契约要素 ②选择表 ③修复规则 ④时间轴翻译层。与 storyboard-craft 第 1/3/9 节（微节拍/表情语气/表情三轴）配套，本卡是表演总纲。

## ① 契约要素（焦点/承重角色按镜头职责取用）

六项是表演诊断维度，不是每镜必填六格。焦点或承重角色先写目标与本镜可见变化，再按失败风险选战术、节拍、手上活、身体余波或 eye life；只有**承重台词**或复杂承重表演才按需展开较完整的前/中/后变化，普通功能镜已有角色档案可继承，只写变化项。非焦点角色只写**位置、朝向、必要的持续行为与禁区**，不为背景群演逐人补目标、战术和节拍，避免指令过载。

1. **目标（Objective）**：本镜这个角色想让什么发生、避免什么，目标可落在剧本已有的人、物、任务或环境条件上。写成可行动的动词，不把情绪状态当动作，也不为套「对手」关系改写既定人物关系。
2. **战术（Tactic）**：此刻如何追目标。直接说、绕开说、沉默、行动或等待都由人物、场景和已发生刺激决定；战术是否变化也跟随本镜结果，不按身份或题材套固定话术。
3. **节拍变化**：目标达成/战术失败/新信息/权力翻转可形成节拍，变化需在停顿、姿态、语速、视线或动作结果中可读。`2-4 个`只是一段复杂承重表演的首轮诊断参考；一拍足够或长镜需要更多变化时按戏与模型能力处理，不凑数。
4. **business 手上活**：当谈话缺乏关系压力、停顿落点或身体在场感时，可给角色一件与处境有关的事（数钱/擦杯/修东西），并让某次停手成为重音。已有有效调度时不为填模板硬加手上活。
5. **身体余波**：只有事件、人物状态或已有表演证据支持时，才写喘息、出汗、吞咽、停顿或短暂空白；日常低压镜可以没有。不得为显得承重而虚构伤势、秘密、关系或强制情绪代价，**也禁微笑鼓掌欢呼当万能反应**。
6. **eye life**：起稿主动继承正文中有叙事作用的看向、避开、追随与再对视，保留视线对象和回应落点；不能等到假感出现才设计承重眼神。技术性眨眼、扫视、视线先于转头等控制只在本镜确需时补充。视线对象继承剧本与调度中的人物、物件或画外目标；技术澄清只能补身份/方位绑定，不能把角色改成看镜头。微表情可从**眉弓 / 眼睑 / 瞳孔 / 嘴部 / 下颌**中选择承重部位，不要求五部位全写。

**表演档案 master profile**（有跨镜表演连续性需要时建一次，之后各镜只写变化）：只记录剧本、正典或已批准设计中确立且会持续复用的节奏、动作、视线与声音特征。惯用小动作、步态、遮掩方式或在意对象只有已有证据且当前制作确需时才记录；没有就留空，不为齐档创造习惯、伤病、秘密、关系或软化对象。

**情绪库取材入口**：遇到表情同质、情绪过渡不清或已有刺激缺可见回应时，读取 [共用情绪表演库](../emotion-performance-library.md)，按触发与强度选条，再读该条可见表现与语气，结合对应补充和转换示例细化；复合感受、倾听、权衡或情绪衔接问题直接读该情绪库内对应补充与转换写法；已明确的恋爱场另读库内双人表演对应条目，保留双方回应与本场关系结果，选当前景别可见的细节，保留动作顺序、幅度、方向、对象及呼吸与对白衔接；不只取概括方向，不跳转外部原文。沿本卡翻译为少量可见变化，不整套复制面部/姿态/呼吸，不把示例微表情当作心理诊断。对白、OS 与画外对白 VO 的发声文字逐字继承已定正文，不为提示词显得专业而书面化、概括或擅自换词；发现口语失配时定位原句，回 Crew 按 dialogue-craft §1.1 修订后同步，不靠加“随口”、塞语气词或加速配音掩盖。角色语气逐句承接 Crew 已写提示，制作只补发声实现；缺少会改变人物意图的依据时回编剧，不自行改动机。

## ② 选择表

**表演强度四级**（按镜头功能选）：

| 级 | 状态 | 用法 |
|---|---|---|
| 1 克制 | 相对本镜基线变化很小，但关键选择仍可读 | 安静、动作或说话均可，按人物和刺激决定 |
| 2 日常 | 反应幅度接近日常行为 | 不要求持续小动作；已有行为足以承载就保持自然 |
| 3 外露 | 观众能清楚读到目标或关系变化 | 可通过动作、声音、停顿或空间选择呈现，不固定组合 |
| 4 峰值 | 本段相对变化达到峰值 | 可以是爆发、骤停、直接表达或压住不发；只由事件与人物证据决定 |

**地位表演**：地位是当下关系与行动结果，不是动作速度模板。根据谁掌握信息、谁先选择、谁承担后果、空间和他人如何响应来呈现；强势者可以急，弱势者也可以静，不能用「静/慢」或「忙乱/碎」代替人物证据。地位发生变化时，只写观众需要看清的那个可见结果。

**表演写成刺激-反应-意图（v1.7.3 增 · 判断方法）**：承重反应先核**刺激**（已有的话、动作、消息或环境变化），再写角色实际作出的**选择**，并让既定**意图**可从结果中读到；普通连续动作不必机械拆成三句。错位、延迟、遮掩、直说或不说都只是角色与场景证据支持时的选择，不能为了制造潜台词强加。反应中的交互对象、视线对象与关系称谓必须继承剧本，不由表演模板改写。

## ③ 修复规则（烂表演 8 条高发项）

| 失败 | 修复 |
|---|---|
| 脸谱化（眉毛表演情绪） | 删掉无依据的面部任务，回到已有刺激、目标与可见选择；环境和人物确实支持时才加手上活 |
| 等 cue（对方说话时脸是空的） | 需要承重响应时，把注意与反应落在实际刺激发生处；不要求所有背景角色持续反应 |
| 单一战术（整场一个调） | 先核结果是否真的改变；有新刺激或失败才换战术，不为制造层次硬换 |
| 手势复读台词（说「大」就张开双臂） | 手势先于想法、或与台词矛盾、或删掉 |
| 情绪跳变却无因果 | 补足缺失刺激或可见结果；若剧本事件本就允许直接表达，不强造克制、裂缝或情绪代价 |
| 威胁方式与人物/场景不符 | 由已有人物与情境决定预告、日常化或突然到来，不把任一路线设为强制答案 |
| 无叙事依据的群体同步 | 承重角色可按理解差异错开；明确集体刺激允许同步，背景人物不要求人人错峰反应 |
| 死眼（凝视不眨无扫视） | 仅补足能修复当前假感的 eye life，并保持原视线对象；不把第 6 项全部塞入 |

## ④ 时间轴翻译层（表演设计 → 视频模型提示词的下游格式 · v1.7.0 新增）

> 上游（§①②③ + storyboard-craft 情绪路径）决定**演什么**；本层决定**怎么喂给视频模型不崩**。情绪路径**不固定顺序**，只保留本镜真正发生且观众可读的节点。时间轴细拆适用于确需细拆的承重变化；普通镜不启用整套切片。核心是可见因果与动作连续，克制、外露、静止或运动都由本镜事实决定。

**切片风险诊断四件套**：
1. **时长按自然变化点切**：`2-3 秒/片`只作无项目证据时的观察起点；实际按目标模型能力、动作完成度与意义变化划分，每片保持动作连续；
2. **微动作数量按失败证据收紧**：同一小段塞入多个彼此独立的微动作、且实测出现抽搐或掉帧时，减少到一个主变化；`每片 1-2 个`是常见修复尺度，不是所有模型的硬上限；
3. **速度继承剧情**：先保持剧本、分镜与表演设定的实际速度；正常速度不得擅自改成慢动作，急变也不得因通用风险被抹掉。只有目标模型能力或本项目失败证据要求时，才调整切片、输入或动作幅度，并记录代价。
4. **身份锚与收尾按需写**：无可靠参考图或接口需要文字锁身份时，首句引用资产卡短锚；结尾状态按镜头契约选型，只有需要延展、剪辑点或克制余波时才定格，**不默认黑屏或无意义转场**。

> **能力观察边界**：单次生成出现或未出现某种问题，只能记为该项目、该 provider/adapter/version 与输入组合下的观察；未经模型卡、当前接口 schema 或重复实测支持，不得升格为所有模型的普遍能力或禁令。

> **切片服务于动作链完整（v1.7.3 增 · 判断口径）**：切片是喂模型的格式，不是把一个动作剁碎的授权——同一动作链（抬手→握杯→收回落到桌面）落在时间轴上跨片时，写成一条**连贯进行的动作**（上一片的起始姿态=下一片的延续），观众看到的是一次完整动作，不是两秒一个独立的姿势快照；切片边界跟着动作与情绪的推进点走，不为「每片都有事发生」硬塞微动作。

**三类防崩检查**（先读模型卡，实际失败后再收紧；不写成所有模型的必然规律）：

| 禁忌 | ❌ 错误写法 | ✅ 正确替换 |
|---|---|---|
| 1. 交互对象与空间绑定不清（易串角） | 只写「看向他」「走过去」，没有已有人物/物件与站位绑定 | 用资产 ID、角色称谓和既定方位明确原对象；除非剧本/分镜原本如此，不得改成看镜头 |
| 2. 抽象心理无法落画面 | 「露出一丝算计」「心里很委屈」 | 只翻译本镜已有证据支持且观众需要看见的动作、声音或结果，不凭抽象词补新秘密 |
| 3. 动作超载（已出现抽搐时） | 同一小段塞入多个独立表情与动作 | 保留承重主变化或重切片，速度仍按剧情与模型实测决定 |

**输出前自检三问**：①人物、物件与方位是否足以避免串角，同时保留了剧本中的真实交互对象？②抽象心理是否只被翻译成已有证据支持的可见行为，没有补新事实？③速度、视线和动作链是否与分镜连续，没有为了技术格式改戏？

**下游格式骨架**（只在确需时间轴细拆时使用，不补创作内容）：
- `{起止时间}`：继承 `{CHAR_ID / 当前状态 / 既定站位}`；在 `{已有刺激}` 后完成 `{本段唯一承重选择或动作延续}`；视线保持 `{剧本/分镜中的实际对象}`；速度沿用 `{既定速度}`。
- 下一片若延续同一动作，首姿态承接上一片结尾；没有新的意义变化就不另切片。

**与其他维度的关系**：切片时长与单镜时长预算（storyboard-craft 镜头数自适应）对齐；外貌前缀与 asset-library §3 角色圣经字段逐字一致；表演只按本镜风险取用动机、视线、呼吸、脸部、身体、声音或收尾等相关维度，不要求齐套。
