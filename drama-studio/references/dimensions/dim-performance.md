# 维度卡 · 表演（dim-performance）

> Contract 结构：①契约要素 ②选择表 ③修复规则 ④时间轴翻译层。与 storyboard-craft 第 1/3/9 节（微节拍/表情语气/表情三轴）配套，本卡是表演总纲。

## ① 契约要素（焦点/承重角色按镜头职责取用）

六项是表演诊断维度，不是每镜必填六格。焦点或承重角色先写目标与本镜可见变化，再按失败风险选战术、节拍、手上活、生理成本或 eye life；只有**承重台词**或复杂承重表演才按需展开较完整的前/中/后变化，普通功能镜已有角色档案可继承，只写变化项。非焦点角色只写**位置、朝向、必要的持续行为与禁区**，不为背景群演逐人补目标、战术和节拍，避免指令过载。

1. **目标（Objective）**：本镜这个角色**从对手身上要什么**，写成对准对手的动词（「逼他还钱」「让她信我不怕」）。禁状态词（「他很愤怒」）——状态演不出来，目标能演。
2. **战术（Tactic）**：此刻用什么方法追目标（施压/讨好/羞辱/哀求/挑衅/拖延）。一个战术失败就换，**一镜一个主战术**。
3. **节拍变化**：目标达成/战术失败/新信息/权力翻转可形成节拍，变化需在停顿、姿态、语速、视线或动作结果中可读。`2-4 个`只是一段复杂承重表演的首轮诊断参考；一拍足够或长镜需要更多变化时按戏与模型能力处理，不凑数。
4. **business 手上活**：当谈话缺乏关系压力、停顿落点或身体在场感时，可给角色一件与处境有关的事（数钱/擦杯/修东西），并让某次停手成为重音。已有有效调度时不为填模板硬加手上活。
5. **生理成本**：高压力事件若对身体毫无余波，可从喘息、出汗、吞咽、停顿或短暂空白中选真实可见的一项；日常低压镜不强制。**禁微笑鼓掌欢呼当万能反应**；成本应由事件触发，不在事前预演答案。
6. **eye life**：死盯或眼神漂移已造成假感时，再写眨眼、扫视、视线先于转头等控制。微表情可从**眉弓 / 眼睑 / 瞳孔 / 嘴部 / 下颌**中选择承重部位，不要求五部位全写。

**表演档案 master profile**（每主要角色建一次，之后各镜改写不重贴）：tics 必带触发器（「摸硬币=在掂量局势」）/ 命名步态 / 面具+裂缝（「However, when X，伪装崩一角」）/ 一个软化目标。

## ② 选择表

**表演强度四级**（按镜头功能选）：

| 级 | 状态 | 用法 |
|---|---|---|
| 1 克制 | 几乎不动，情绪全在眼睛里 | 特写、权力高位者 |
| 2 日常 | 自然反应，微动作不断 | 对话常态 |
| 3 外露 | 肢体参与，战术明确 | 对抗、追逐目标 |
| 4 爆发 | 全身+声音，生理反应齐发 | 高成本表演：密度作诊断参考（连用要付叙事成本），「持续压迫」或「静默余波」型段落合法，按叙事节奏判断 |

**地位表演**：强者=静止、慢、少动作、占用空间；弱者=忙乱、小动作多、语速碎。**地位反转瞬间（status break）是最贵的戏**——用在第 2 层聚焦反应。

**表演写成刺激-反应-意图（v1.7.3 增 · 判断方法）**：每个可见反应前有**刺激**（对方的话/动作/消息），反应本身是**选择**（迎上去/僵住/移开视线/用 business 遮掩），背后有**意图**（此刻想从对手身上要什么）——三段齐，表演才有戏；只写反应不写刺激与意图，动作就成了表情包循环。**反应不必准确完整**：真实的人会反应错位（该怒时先笑一下）、延迟（话落半秒后才懂）、遮掩（笑着但手指掐进掌心）——错位与延迟恰恰是潜台词的可见形态，别把每个反应都修成「标准答案反应」。

## ③ 修复规则（烂表演 8 条高发项）

| 失败 | 修复 |
|---|---|
| 脸谱化（眉毛表演情绪） | 删掉面部任务，写目标+给手上活 |
| 等 cue（对方说话时脸是空的） | 反应写在对方台词进行中开始 |
| 单一战术（整场一个调） | 标节拍，每拍一个新战术动词 |
| 手势复读台词（说「大」就张开双臂） | 手势先于想法、或与台词矛盾、或删掉 |
| 情绪无台阶（直接哭/怒） | 搭梯子：克制→裂缝→崩；情绪必须有代价 |
| 威胁预告（眯眼慢转身再动手） | 威胁日常化，暴力无预警到来 |
| 无叙事依据的群体同步 | 承重角色可按理解差异错开；明确集体刺激允许同步，背景人物不要求人人错峰反应 |
| 死眼（凝视不眨无扫视） | 回契约第 6 项全写 |

## ④ 时间轴翻译层（表演设计 → 视频模型提示词的下游格式 · v1.7.0 新增）

> 上游（§①②③ + storyboard-craft 情绪路径）决定**演什么**；本层决定**怎么喂给视频模型不崩**。情绪路径**不固定顺序**，只保留本镜真正发生且观众可读的节点。时间轴细拆适用于需要细拆的单角色情绪特写；普通镜不启用整套切片。核心理念：**克制即张力**——情绪可收缩在眼神、面部肌肉微动与呼吸里。

**切片风险诊断四件套**：
1. **时长按自然变化点切**：`2-3 秒/片`只作无项目证据时的观察起点；实际按目标模型能力、动作完成度与意义变化划分，每片保持动作连续；
2. **微动作数量按失败证据收紧**：同一小段塞入多个彼此独立的微动作、且实测出现抽搐或掉帧时，减少到一个主变化；`每片 1-2 个`是常见修复尺度，不是所有模型的硬上限；
3. **降速词优先**：动作前缀「缓缓 / 极轻微 / 慢慢」，慎用「瞬间/猛地/突然」——急变动作是当前主流视频模型的高风险场景，先读模型卡按能力选择；实际失败后再收紧。
4. **身份锚与收尾按需写**：无可靠参考图或接口需要文字锁身份时，首句引用资产卡短锚；结尾状态按镜头契约选型，只有需要延展、剪辑点或克制余波时才定格，**不默认黑屏或无意义转场**。

> **能力观察边界**：单次生成出现或未出现某种问题，只能记为该项目、该 provider/adapter/version 与输入组合下的观察；未经模型卡、当前接口 schema 或重复实测支持，不得升格为所有模型的普遍能力或禁令。

> **切片服务于动作链完整（v1.7.3 增 · 判断口径）**：切片是喂模型的格式，不是把一个动作剁碎的授权——同一动作链（抬手→握杯→收回落到桌面）落在时间轴上跨片时，写成一条**连贯进行的动作**（上一片的起始姿态=下一片的延续），观众看到的是一次完整动作，不是两秒一个独立的姿势快照；切片边界跟着动作与情绪的推进点走，不为「每片都有事发生」硬塞微动作。

**三大防崩禁忌**（当前主流模型的高风险写法——先读模型卡，实际失败后再收紧；不写成所有模型的必然规律）：

| 禁忌 | ❌ 错误写法 | ✅ 正确替换 |
|---|---|---|
| 1. 禁主角外人称与空间位移（防串角爆框） | 「看向父亲」「走到桌前」——凭空多出人/镜头强行拉远 | 交互对象全部改镜头或画面方向：「看向镜头」「视线转向画面右侧」「保持半身特写静止」 |
| 2. 禁抽象心理描写（模型渲染不了心理活动） | 「露出一丝算计」「心里很委屈」 | 全部翻译成肌肉与呼吸：「眼睑微压」「下颌紧绷」「呼吸停滞」 |
| 3. 防动作超载（已出现抽搐时） | 「瞬间闪过冷笑并立刻低头」 | 保留一个主变化，必要时用极微小局部动作 + 降速词 |

**输出前自检两问**：①提示词里出现主角以外的人称了吗？（有→改成镜头方向）②有心理活动描述吗？（有→翻译成脸部肌肉动作）

**格式示例**（15 秒失望戏的一个可行版本，不是固定顺序或配额）：
- 0-2秒：古装短剧女主角，低头垂眸，嘴角噙着含蓄淡笑不露齿，神态温柔安静。
- 2-4秒：笑意缓缓收敛，嘴角归平；双眼头部慢慢抬起，视线转向画面右侧，神情转为认真。
- 4-6秒：持续望向右方，眉头微蹙一下随即松开，双眼睁大约一成，嘴唇轻启又合上（欲言又止落在唇部动作上，不写「疑惑」二字）。
- 6-9秒：视线缓缓下沉，头部微低，笑意尽数褪去，嘴角两侧肌肉松弛下拉，肩膀微沉，吞咽一次，呼吸变浅，不流泪（「失落」翻译成上述肌肉动作，不写情绪词）。
- 9-12秒：低头轻阖双眼，平复心绪，嘴角浮现一抹藏起难过的浅淡自嘲，呼吸自然，动作极轻。
- 12-15秒：缓缓抬头，眨眼一次后目视前方，下颌微收，眼轮匝肌放松保持凝视，唇线平直，定格不动（「温柔清冷略带忧郁」由上述肌肉组合呈现，不写情绪词）。

**与其他维度的关系**：切片时长与单镜时长预算（storyboard-craft 镜头数自适应）对齐；外貌前缀与 asset-library §3 角色圣经字段逐字一致；情绪拆解（动机+眼神+呼吸+脸部+身体+声音+收尾）沿用本卡 §1 契约要素。
