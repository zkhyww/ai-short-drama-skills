# 维度卡 · 光影（dim-lighting）

> Contract 结构：①契约要素 ②选择表 ③修复规则。与 storyboard-craft 第 5 节「光影 contract」配套使用（本卡是扩展版）。

## ① 契约要素（每镜必齐 5 项）

1. **物理来源**：光从哪个具体物件来（窗/路灯/屏幕/烛火/走廊灯），禁「电影感打光」式空话。
2. **情绪动机**：这个光为什么是这个情绪——光服务场景意图，不服务好看。
3. **方向**：主光方位（左侧 45°/顶光/逆光/侧逆），跨镜不得反向。
4. **对比比**：亮暗比（2:1 柔和生活 / 4:1 紧张 / 8:1+ 悬疑压抑）。
5. **窗口预算**：一场戏里「漂亮光」镜头配额有限——关键情绪点用风格光，过渡镜头用自然光，避免全片高光疲劳。

## ② 选择表（情绪 → 光影方案）

| 情绪/场景 | 光源+色温 | 方向 | 对比 |
|---|---|---|---|
| 日常温情 | 窗光/暖灯 3200-4300K | 侧前方 | 2:1 |
| 都市冷峻 | 顶灯/屏幕光 5600-6500K | 顶或正侧 | 4:1 |
| 悬疑压迫 | 单点光源+深阴影 | 侧逆/底光 | 8:1+ |
| 对峙剑拔弩张 | 双侧交叉光（cross-key，两人各自主光） | 两侧对打 | 4:1 |
| 回忆/梦境 | 过曝柔光+光晕 | 逆 | 低对比 |
| 雨夜离别 | 路灯冷白 6500K+雨丝可见 | 顶光 | 高对比 |

**色温情绪渐变尺**：2000-2700K 怀旧/温暖 → 3200-4300K 日常温情 → 5600-6500K 冷峻都市 → 6500K+ 疏离/异化。全剧的色温走向可以本身就是一条情绪曲线（暖开局→冷中局→回暖终局）。

公式：**[光源类型] + [色温] + [光线方向] + [聚焦区域] + [情绪效果] + [整体氛围]**。

## ③ 修复规则

| 失败 | 加锁 |
|---|---|
| 画面变平光（flat front light） | 「主体在相机与更亮背景之间，相机在主体阴影侧；面部允许落入深影，轮廓光+眼神光+环境反射交代细节；无正面主光、无美颜补光」 |
| 背光变顺光 | 「整镜按逆光曝光，不按脸曝光；剪影与轮廓边缘承载画面」 |
| 跨镜光向跳反 | 连续性锁：「主光方向与上一场一致，阴影方向符合光源」 |
| 光影与情绪脱节 | 回契约第 2 项重写动机，写不出动机就换自然光 |
