# 维度卡 · 动作/打斗（dim-action）

> Contract 结构：①契约要素 ②选择表 ③修复规则。打斗深度规范另见 drama-crew 的 genre-and-fight-rules（涉打斗戏时由沈砚一并贴入）。

## ① 契约要素（按动作镜头/阶段承担的功能取用）

1. **动作链四段式**：大动作按 准备→发力→接触→收势 组织，段间状态连续（上段结束=下段起始）。四段可由同镜或不同镜头分别承担，单镜只写它负责的阶段；阶段可详略有别，按物理完成时间与观众可读性分配，不强迫复杂动作在 1–3 秒内全做完；动作节点不是剪辑切点。
2. **一镜一主导动作**：画面焦点清楚，但不让所有对手排队等主角打完。主要战斗者各有目标与路线（牵制/护人/封出口/防守转反攻），可同步行动，接触与结果须读得清。**同一条动作链的连续小动作（四段式内部）不算「多动作」**；只有独立动作争焦点或执行不稳才错峰/拆镜，不强制每镜所有人都有大动作。
3. **手与道具按叙事职责处理**：手部互动若承载交付、身份、证据或动作结果，就让关键接触与状态变化可见；先核当前模型能力、角色/道具参考和动作素材。只有接口限制或具体穿模失败成立时，才换动作参考、拆到可读步骤或交后期，不能因多人同框就自动简化或移出画外。
4. **三线一致**：视线线（看谁）/ 动线（往哪移动）/ 胸线（躯干朝哪）三线互相印证不打架。
5. **物理锁**（只勾本镜可见且不改结果的项）：重力与重量转移（脚跟接触→重心→蹬地）/ 接触反馈（按已锁结果选择轻触、位移、形变或无痕，不默认制造伤害）/ 布料与头发延迟（先身后摆）/ 液体粘滞（仅场景确有液体时）/ 粒子随风（仅命中烟尘雨雪时保持方向一致）。接触反馈服从剧本与资产锁定的伤态、破坏和终点；无伤训练、静物接触或未承担结果的镜头不补生理代价、裂纹或每镜消散。

## ② 选择表

**动作类型 → 拆解策略**：

| 类型 | 策略 |
|---|---|
| 走路/奔跑 | 脚跟触地/膝抬/对摆臂/躯干前倾/步幅变化；禁漂浮 CG 跑 |
| 拿取/传递 | 单人镜头给特写；重量进手腕与小臂 |
| 打斗对招 | 正常对招中近景侧面 / 蓄力低角度仰拍 / 攻防带角度 / 特写留给破绽点（运镜四原则） |
| 情绪性动作（摔门/砸杯） | 按情绪与结果选择准备、接触、后果的可读时长；已锁无破坏时不为力度补裂损 |
| 舞蹈/动作迁移 | 参考视频管动作节奏，角色图管身份——两参考职责不混 |

**动作密度判断**：先让观众读清目标、接触与后果，再按实际时长排片；动作链超出可读时长/模型能力时拆镜——**优先保持动作链因果连续，在准备/发力/接触/收势的自然边界切开，并继承姿态、方向和接触状态**（与 storyboard-craft §12 口径一致），不拿固定几秒机械规定招数。

## ③ 修复规则

| 失败 | 加锁 |
|---|---|
| 人物漂浮/滑步 | 「脚底有摩擦、重心随步转移、无滑步无漂浮」 |
| 武器/道具无重量 | 「小臂承载可见重量、手腕角度随质量反应、挥动有加减速」 |
| 一镜多动作打架 | 拆镜或降级：主动作层 3，其余回层 1 微动作 |
| 动作结果与已锁状态对不上 | 回查剧本/资产终点：该有的疲劳、伤态或破坏须可见；已锁无伤、无破坏或轻量训练时保持对应结果，不额外补喘息、踉跄、手抖或衣损 |
