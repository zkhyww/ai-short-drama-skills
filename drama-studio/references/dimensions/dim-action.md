# 维度卡 · 动作/打斗（dim-action）

> Contract 结构：①契约要素 ②选择表 ③修复规则。打斗深度规范另见 drama-crew 的 genre-and-fight-rules（涉打斗戏时由沈砚一并贴入）。

## ① 契约要素（每动作镜必齐 5 项）

1. **动作链四段式**：每个动作 1-3 秒，大动作拆成 准备→发力→接触→收势 四段，段间状态连续（上段结束=下段起始）。
2. **一镜一主导动作**：一个镜头只让一个动作当主角；多动作排队不并排。**同一条动作链的连续小动作（四段式内部）不算「多动作」**——它们是同一主动作的分段展开，不是排队并排。
3. **手优先**：动作镜头里手先入画、先交代——AI 视频里手最脆弱，**手-道具接触在多人同框时简化或移出画外**。
4. **三线一致**：视线线（看谁）/ 动线（往哪移动）/ 胸线（躯干朝哪）三线互相印证不打架。
5. **物理锁**（按画面内容勾选写入）：重力与重量转移（脚跟接触→重心→蹬地）/ 接触必留痕（湿接触留渍、碰撞有形变）/ 布料与头发延迟（先身后摆）/ 液体粘滞（血会挂、滴、抹、聚）/ 粒子随风（烟尘雨雪方向一致，前中后景都有）。

## ② 选择表

**动作类型 → 拆解策略**：

| 类型 | 策略 |
|---|---|
| 走路/奔跑 | 脚跟触地/膝抬/对摆臂/躯干前倾/步幅变化；禁漂浮 CG 跑 |
| 拿取/传递 | 单人镜头给特写；重量进手腕与小臂 |
| 打斗对招 | 正常对招中近景侧面 / 蓄力低角度仰拍 / 攻防带角度 / 特写留给破绽点（运镜四原则） |
| 情绪性动作（摔门/砸杯） | 蓄力段压短、接触段给足、后果段留 0.3-1.0s 余韵 |
| 舞蹈/动作迁移 | 参考视频管动作节奏，角色图管身份——两参考职责不混 |

**动作密度阈值**：4-6 秒 = 1 目标 1 接触 1 后果；动作链超出可读时长/模型能力时拆镜——**优先保持动作链因果连续，在准备/发力/接触/收势的自然边界切开，并继承姿态、方向和接触状态**（与 storyboard-craft §12 口径一致）。

## ③ 修复规则

| 失败 | 加锁 |
|---|---|
| 人物漂浮/滑步 | 「脚底有摩擦、重心随步转移、无滑步无漂浮」 |
| 武器/道具无重量 | 「小臂承载可见重量、手腕角度随质量反应、挥动有加减速」 |
| 一镜多动作打架 | 拆镜或降级：主动作层 3，其余回层 1 微动作 |
| 打完无代价 | 生理成本补写：喘息/踉跄/手抖/衣服乱——after-event 必须付账 |
