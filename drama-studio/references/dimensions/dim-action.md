# 维度卡 · 动作/打斗（dim-action）

> Contract 结构：①契约要素 ②选择表 ③修复规则。打斗深度规范另见 drama-crew 的 genre-and-fight-rules（涉打斗戏时由沈砚一并贴入）。

## ① 契约要素（按动作镜头/阶段承担的功能取用）

1. **动作链四段式**：大动作按 准备→发力/操作→接触/作用→收势/结果 组织，段间状态连续（上段结束=下段起始）。四段可由同镜或不同镜头分别承担，单镜只写它负责的阶段；阶段可详略有别，按物理完成时间与观众可读性分配，不强迫复杂动作在 1–3 秒内全做完；动作节点不是剪辑切点。竞赛、载具、精细操作、表演协作与异种互动同样保留使阶段结果成立的必要过程，不只拍前后状态。
2. **一镜一主导动作链/注意焦点**：画面焦点清楚，但不等于一镜只许一人动。战斗者、乐手、队员、谈判/仪式参与者或共同操作者可同步行动，只要共享一个可读的目标/注意链，并写清各主体、对象、路线/声部/器具、接触与回应；只有彼此独立的动作争焦点或执行不稳才错峰/拆镜，不把其他承重参与者一律降为微动作、随机点头或画外。
3. **手、工具与道具按叙事职责处理**：互动若承载交付、身份、证据、工序、控制或动作结果，就让关键接触面、占手、受力、状态变化与物件去向可见；先核当前模型能力、角色/道具参考和动作素材。只有接口限制或具体穿模失败成立时，才换动作参考、拆到可读步骤或交后期，不能因多人同框就自动简化、改成单人特写或移出画外。缺部件、未完成步骤或中断状态不能跨切自动恢复成成品。
4. **三线一致**：视线线（看谁）/ 动线（往哪移动）/ 胸线（躯干朝哪）三线互相印证不打架。
5. **物理锁**（只勾本镜可见且不改结果的项）：正常重力地面运动才用脚底接触→重心→蹬地；车辆/器具补承载、控制输入、接地/支点与惯性；牵引/托举补受力与反作用；液体介质补浮力、阻力与流动；失重补漂移、旋转与可用支点，不硬套脚跟落地。接触反馈按已锁结果选择轻触、位移、形变或无痕；布料/头发、液体、粒子只按实际介质给相称延迟和方向。无伤训练、静物接触或未承担结果的镜头不补生理代价、裂纹或每镜消散。
6. **形态、进度与跨切状态**：动物/异种的肢体、翼、尾、抓握或承重方式服从已定物种/形态与能力，不套人类手指、口型或步态；材料、器械、球/车与身体的位置、完成进度、失败状态在下一切点继承，除非画面明确完成交接、修复或状态改变。

## ② 选择表

**动作类型 → 拆解策略**：

| 类型 | 策略 |
|---|---|
| 走路/奔跑 | 脚跟触地/膝抬/对摆臂/躯干前倾/步幅变化；禁漂浮 CG 跑 |
| 拿取/传递 | 按事件职责选择单人或多人同框；关键接触、占手、重量/阻力、交接双方与落点须可读，只有真实可读性/模型失败才补特写或拆镜 |
| 打斗对招 | 正常对招中近景侧面 / 蓄力低角度仰拍 / 攻防带角度 / 特写留给破绽点（运镜四原则） |
| 情绪性动作（摔门/砸杯） | 按情绪与结果选择准备、接触、后果的可读时长；已锁无破坏时不为力度补裂损 |
| 舞蹈/演奏/同步协作 | 参考视频或乐句时间轴管节奏与队形，角色图管身份；写清各参与者的声部/器具/接触、同步点、接续或中断，不把群体缩成独演特写 |
| 体育竞赛/载具 | 锁目标与判据、器具/球/车辆身份、控制者/乘员、有效路径、接地/承载、对手响应及阶段结果；不拿欢呼蒙太奇替代已锁输赢 |
| 烹饪/工艺/维修等精细操作 | 锁同一材料/零件与工具接触面、顺序、占手、进度和前后状态；缩时时保留改变状态的承重步骤 |
| 动物/异种互动 | 按已定解剖与感知写刺激→动作→接触/承重→反馈；背景动物不展开主角流程，无拟人设定不补人类动作 |
| 水下/失重等特殊介质 | 先写介质、支点与可用推进方式，再写路径、阻力/惯性、接触和结果；不用陆地动作锁覆盖特殊环境 |

**动作密度判断**：先让观众读清目标、接触与后果，再按实际时长排片；动作链超出可读时长/模型能力时拆镜——**优先保持动作链因果连续，在准备/发力/接触/收势的自然边界切开，并继承姿态、方向和接触状态**（与 storyboard-craft §12 口径一致），不拿固定几秒机械规定招数。

## ③ 修复规则

| 失败 | 加锁 |
|---|---|
| 人物漂浮/滑步 | 「脚底有摩擦、重心随步转移、无滑步无漂浮」 |
| 武器/道具无重量 | 「小臂承载可见重量、手腕角度随质量反应、挥动有加减速」 |
| 多人/多动作争焦点 | 先按共同目标、对象、接触或节拍收成一条主动作/注意链并分清参与职责；仍有独立因果互扰或模型失败才错峰/拆镜，不全局把其他参与者降微动作 |
| 动作结果与已锁状态对不上 | 回查剧本/资产终点：该有的疲劳、伤态或破坏须可见；已锁无伤、无破坏或轻量训练时保持对应结果，不额外补喘息、踉跄、手抖或衣损 |
| 工序/材料跨切复原或凭空完成 | 回到上一切点的物件、工具、缺件与完成进度；补实际交接/操作/状态变化，不能用成品镜跳过承重过程 |
| 动物/特殊介质被套成人类陆地动作 | 按已定形态、感知、承重方式与介质重写支点/推进/接触；不发明能力或无因伤亡 |
