## 能力参数

| 项 | 参数 |
|---|---|
| 支持模式 | 文生 T2V / 图生 I2V（首帧/尾帧/双帧）/ 参考生 R2V / **指令式编辑**（改角色/物体/场景/声音，不重生成整片） |
| 时长 | **4–15s**（整秒递增）；Smart Expansion 可延至约 30s |
| 画幅 | 21:9、16:9、4:3、1:1、3:4、9:16、adaptive（参考任务） |
| 分辨率 | **768p / 原生 2K（1440p 模式，短边 1440）**；24fps 固定；本地最低 384p（256p 会失败） |
| 参考资产上限 | **Omni-Reference：9 图 + 3 视频 + 3 音频，共 ≤12 文件**（每段视频 ≤15s） |
| 首尾帧 | ✅ 支持（first_frame / last_frame / both；双帧输入时输出画幅跟随输入图） |
| 多镜头 | ✅ 单条内可含多镜头切换（贴合叙事节奏） |
| 原生音频/语音 | ✅ **原生立体声**（对话+音效+音乐同 pass；32kHz；11 种语言）；音色克隆/迁移 |
| 已知冲突 | ①首尾帧模式**不能与参考数组混用**；②图生模式拒绝 aspect_ratio（画幅跟随输入图）；③本地推理模型 19.5–61.7GB（INT8 剪枝/bf16 三档）+ Qwen3-VL-32B 文本编码器 + 双 VAE，显存门槛高；④R2V 与 T2V/I2V 用不同权重（ref2va vs fl2va） |
| 失败降级 | 显存不足用 INT8 剪枝（19.5GB）降分辨率；时长 15s+ 用 Smart Expansion；编辑局部改动用指令式编辑而非整条重生成 |
| 提示词适配 | prompt ≤7000 字符；R2V 用 `<Picture 1>` / `<Video 1>` / `<Audio 1>` 标签按连接顺序引用；**给每个参考分配明确任务**（身份/风格/运动/相机/声音），明确分配效果远好于模糊混用；时长在 24fps 下对齐 17 帧/块网格 |

## 制作侧使用要点

- **一致性最强**：Omni-Reference 一次锁定角色+风格+动作+音色，适合连载剧跨镜一致。
- 原生 2K 直出，裁切重构图余量大；24fps 与电影剪辑节奏一致，无需帧率转换。
- 对白镜：原生立体声+口型同步；可上传参考音频锁定角色音色。
- 本地部署：可离线跑（ComfyUI 原生支持），适合需要本地渲染或隐私场景。
