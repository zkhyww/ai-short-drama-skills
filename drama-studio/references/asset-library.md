# 资产库规范（丹青·美术资产师使用，按需加载）

> 解决：AI 短剧制作中「角色跨镜变脸、场景跨镜跳结构、资产无法跨项目复用」三大顽疾。
> 原则：**资产先建档、分镜只引用**——景川写提示词时不临时编外貌，只引用资产 ID。

## 1. 资产三库（JSON 建档，唯一 ID）

每个项目建三个库 + 一个索引：

| 库 | 文件 | 核心字段 |
|---|---|---|
| 人物资产库 | characters.json | char_id / 姓名 / 身份定位 / 外貌特征 / 常服与特殊服饰 / 性格标签 / 标志性表情 / 声线特征 / prompt_template / negative_prompt |
| 场景资产库 | scenes.json | scene_id / 场景名 / 空间类型 / 时间天气 / 光影基调 / 氛围色调 / 固定陈设 / 关联道具 / prompt_template |
| 道具资产库 | props.json | prop_id / 道具名 / 外观细节 / 功能属性 / 出场关键场次 / 视觉特征标签 |
| 资产索引 | asset-index.json | 全资产 ID→名称→类型→文件路径，供 reuse_asset_ids 跨项目复用 |

人物 prompt_template 模式：`年轻女性，{appearance}，{costume}，{emotion}表情，{action}`——分镜只替换变量，不改骨架。

**复用机制**：续作/补拍/新集时传入 `reuse_asset_ids`（人物 ID 列表+场景 ID 列表），直接加载已有资产，不重画不重建。

## 2. 角色三件套（每主要角色缺一不可）

定妆照 + 肖像特写 + 三视图。三者共同锁一致性，只给定妆照换景别就漂移。

**版式规范**（吸收 XiaoLuo/LIRA/aipdd-char-view）：
- **三视图**：正面全身 / 背面全身 / 侧面全身，同一姿势同一光源，中性灰底，标注身高比例参照
- **肖像特写**：头肩特写，中性微表情，正面略 3/4
- **表情十二宫格**（可选，情绪戏多的主角）：3×4 网格，每格一种情绪表情，同角度同光
- **动作十五宫格**（可选，动作戏主角）：3×5 网格，每格一个标志性动作
- **垫图版式**：单张 1:1 画布 4×4 网格 = 五官特写（2×2）+ 多角度脸型（2×2）+ 正/侧/背三视图（4×2 排布）；图生图精修时 denoise 参考窗口 0.32-0.40（高了变脸、低了修不动）

## 3. 身份区分门（防「一张脸演两个角色」）

crew 交接母稿中的「人物视觉锚定行」（v6.17.0 起随母稿人物档案节提供，v6.17.1 明确职责）承载创作侧已确立的**基础视觉事实**。丹青必须**逐字继承 crew 基础视觉事实**，不得删改、同义替换或用制作偏好覆盖；这些事实不是完整出图参数。丹青在其上补足下列生产级区分项，新增内容统一标为 **[制作设计/推断]**；若与 crew 基础视觉事实冲突，必须保留 crew 事实并调整制作设计。crew 锚定行缺失时，先提取剧本明示事实并标来源，其余仍按 [制作设计/推断] 补足，不把推断伪装成原文事实。每个主要角色的最终生产锚定描述必须通过区分门：
- **≥3 条稳定结构轴**（脸型/鼻型/下颌/眼距/眉形/体态 中选）
- 其中 **≥2 条必须在脸部**
- **同批角色描述禁止词级雷同**（两人都用「剑眉星目」= 不通过）
- **负向标注**：与同剧相近角色明确区分——「无此结构：非圆脸、非双眼皮、无虎牙」

**角色圣经字段**（锚定描述写法，吸收 shipin-fenjing）：每个 CHAR_ID 的 anchor = **首词（年龄段+性别+种族类型）+ 8-12 个视觉词 + forbidden 3-5 项**。多格/多镜引用时**逐字复制，禁同义替换**（换一个词就是换一张脸）。

**16 项资产锁**（吸收 manju-laoli，按角色层级定锁的数量）：主角 = 五官 10 项（脸型/眉/眼/鼻/嘴/下颌/肤/发/痣斑/年龄感）+ 服装 6 项（款/色/材质/配饰/鞋/状态）；配角 8 项；群众演员 3-5 项。锁项写进资产卡，提示词用 **@资产名 短锚点**引用（如 @lin_wan_v1），全项目不重置编号。

**一致性五重锁**（吸收 ai-comic-drama-production）：①定妆双保险（三件套+角色圣经双锚）②服饰锚点（每套服装独立锁）③发色瞳色锁定（最易漂的两项单独写死）④参考图链式传递（后续生成把前次确认图当新参考）⑤失败即重生成（不用坏图当参考）。

**参数固化三原则**（吸收 aimanju）：同一项目内 固定目标模型版本 / 锁定 seed（平台支持时）/ 统一提示词结构——三样不齐，跨镜必漂。

**依据标注**：crew 或剧本明示内容标 [事实:crew] / [事实:剧本]；为满足出图与角色区分而新增的结构、服饰细节和禁项标 [制作设计/推断]；确实无法确定且会改变故事事实的内容标 [未知]。不得覆盖 crew 基础视觉事实，也不得把 [未知] 或制作设计写成原文事实。

**数值-视觉双轨**：档案层可写数值（身高 168cm/年龄 28），提示词描述层必须纯视觉（「比对手高半头」），数值不进提示词；空间量词相对化（一臂距离/画面 1/2），禁 cm 级假精确。

**参考图有无 → 描述深度二分法**（吸收 Mx-Shell）：有参考图时，该元素提示词 ≤20 字简描 + 参考图占位（图是真相源，文字不抢戏）；无参考图时，强制全量物理描述（角色含外形/服装/面部/特殊标识，场景含时代/光线/布局/散落物）。

## 4. 场景资产板（每核心场景一套）

- **四机位视图**：C1 主视觉（24-35mm，建立空间）/ C2 侧面空间（35mm，墙窗家具关系）/ C3 材质细节（50mm）/ C4 功能动线（24-35mm）
- **不可变空间锚点 10 项**：房间轮廓/墙体门窗数量位置/主家具数量位置朝向/材质/主色辅色/时间天气光向/人工灯状态/磨损痕迹/层高比例/功能区划分——跨镜全锁，禁镜像、禁移动固定资产
- **90° 俯视布局图（按风险触发，与 dim-blocking 同口径）**：多人移动、越轴风险、复杂道具互动或空间谜题的核心场景才必做——正交俯视，标注 C1-C4 机位+朝向箭头+视野锥，人物动线用虚线+箭头（多角色分色）；两人静态对话不强制
- **隐藏区域补全**：参考图看不到的背面=「保守推定」，只延续已建立的轴线材质，不虚构新功能区；标注「结构待确认」
- **无参考图时**：允许自建场景资产板（先出 C1 主视觉定调，再推其余三视图），不强制用户上传

## 5. 道具资产

关键道具（剧情道具/信物/武器）：外观细节+材质+磨损状态+出场场次；多个状态（干净/破损/染血）= 分别建档。触发词注意：器械类用中性材质功能描述（「复古工业电子道具，数字读数」），避安全审核词。

## 6. 九宫格公式（批量出图/质检/选图）

3×3 contact sheet：**行=景别**（特写/中景/全景），**列=视角**（正/3-4/侧），**中心格=纯底 pose-only**。用途：一次出齐角色的景别×视角组合，供后续图生视频选首帧；质检一致性；衍生多镜素材。

## 7. 声音指纹与母音色卡（闻笙·声音导演维护）

声音拆成两层，禁止混写：

- **声音指纹**：角色怎样说话——句长、用词、语速节奏、重音习惯、停连、语调、拒绝方式与情绪底色；来自 crew 交接或制作侧按台词归纳。
- **母音色资产**：角色实际使用的声音锚——从模型自带音色或开源音色生成结果中筛出的可复用参考片段。`voice_id` 是角色的逻辑声音身份，`mother_voice_id` 才是冻结后的实际母音色资产；两者不得互相代替。

本工作流只使用 `provider_builtin | open_source` 两类来源，不建立真人克隆音色流程，也不在声音卡中设置许可证、授权或 consent 字段。

### 7.1 稀疏 YAML

未知的可选字段直接省略，不得为了填满模板堆叠缺失状态占位。母音色冻结前只写已经发生的事实：

```yaml
voice_id: char_linnuo_voice
voice_fingerprint:
  diction: 短句，少解释，压力越大越礼貌
  speech_rhythm: 先停半拍再回答，句尾常收住
  stress_habit: 重读否定词和对方姓名
  refusal_style: 不正面说不，用条件句封口
mother_voice:
  state: pending_candidates
```

冻结后补真实资产定位：

```yaml
voice_id: char_linnuo_voice
mother_voice:
  state: frozen
  mother_voice_id: mv_linnuo_001
  source_type: provider_builtin
  source_name: 模型内置音色名称或开源音色名称
  provider: 实际供应商
  model: 实际模型
  adapter: 实际接入层
  source_episode: E03
  source_shot: S03-014
  time_range: 00:02.400-00:10.100
  asset_path: 04_声音/mother_voices/mv_linnuo_001.wav
  sha256: 实际文件哈希
  generation_task_id: 实际任务 ID
  frozen_at: 2026-09-02T00:00:00+08:00
```

`source_type=open_source` 时记录实际音色名称、版本或仓库定位、资产路径与哈希；不适用的 provider/model/adapter 字段省略。`provider_builtin` 没有可复用音频输入能力时，仍保存母音色片段作听觉基准，并固定实际 preset/生成参数；若当前视频接口无法回传声音参考，则改走独立 TTS＋对口型链路，不声称已锁定模型内声音。

### 7.2 角色首次发声起筛选

1. **起点按角色，不按第一集**：每个角色从其在全剧中首次发声的镜头开始建立候选；角色到后续集才登场，就从该集开始。
2. **候选片段标准**：优先试听约 6–15 秒的干净连续表达（不是硬时长；实际上下限服从工具），至少包含一个完整意群，能听清音高中心、音色、节奏、重音、停连、气息与句尾落点。多人叠话、BGM 盖声、只剩耳语/喊叫或情绪极端到无法代表常态的片段不冻结。
3. **允许向后寻找**：首次发声没有合格片段时标 `provisional`，继续在该角色后续镜头或后续集筛选；未冻结阶段生成的对白只算预览，不得写入正式连续性资产。
4. **冻结与回填**：用户或制作侧试听确认后标 `frozen`，截取并保存母音色资产；冻结后必须把该角色此前所有临时对白按同一母音色重新生成，再进入正式剪辑与连续性账本。
5. **失效处理**：母音色文件损坏、接口不再支持、或实听持续漂移时标 `reseed_required`，重新筛选并只回生成该角色受影响对白；不得静默换声。

状态机：`pending_candidates → provisional → frozen`；只有发生资产失效时进入 `reseed_required`。

**铁律**：① `voice_id` 全剧稳定，`mother_voice_id` 冻结后整剧不换；显示名不放进 voice 字段；②普通改句以一条台词为单位重录，但首次冻结或重新选母音色时，必须回生成该角色所有使用临时/旧母音色的对白；③任意两个高频对话角色音色差异以可听辨为准，优先拉开音高中心、音色质感、节奏与口音中的至少两个维度；④旁白别名自动识别（「他」「那人」指向谁，不新增音色）。

## 8. 竖屏画幅契约（9:16 项目强制执行，吸收 manju-laoli）

- 人物纵向占画面高度 **50-70%**（特写 70%、中景 55-65%、全景 50%）
- **避开字幕安全区**（画面下 20% 不放关键表情/道具）
- **切镜角色纵向位置不跳变**——上一镜人物在什么高度，下一镜保持，防跳切感
- 横屏 16:9 项目改用三分法，本契约不适用

## 10. 抗趋同保护指令 + 签名锁定清单（v1.7.0 新增 · 防"模型把设计吃掉"）

> 解决真实失败模式：同一角色批量出图后，模型会悄悄把设计拉回"大众审美"——方脸拉圆、伤疤消失、老人减龄、旧衣变新。三重锁管"跨镜不漂"，本节管"**不被模型美型化修正**"，两层叠加。

### 10.1 趋同引力七宗 × 保护指令写法

| 趋同引力 | 表现 | 保护指令写法 |
|---|---|---|
| 美型化 | 方脸拉圆、棱角磨平 | 「保持方正脸型与下颌棱角，不柔化」 |
| 伤疤消失 | 缺口被"治愈" | 「左眉断疤必须存在，保持不对称，不修复不美化」 |
| 减龄 | 年龄向 25 岁回归 | 「保持五十岁年龄感：法令纹、眼袋、灰白鬓角」 |
| 比例标准化 | 头身比拉向 7-8 | 「严格 5 头身，躯干厚重四肢偏短」 |
| 服装精致化 | 旧衣变新、皱变挺 | 「外套肘部磨损起球，领口变形，保持旧物感」 |
| 表情甜美化 | 默认表情上扬 | 「默认表情无笑意，嘴角平直」 |
| 体型理想化 | 胖瘦向健美回归 | 写死具体体型词，并在保护指令里重复一次 |

**执行规则**：每张参考图的保护指令**至少覆盖该角色全部"非常规特征"**（缺口/年龄/体型/旧物）；表现图（氛围图、远景点缀）酌情精简，但**缺口保护不省**。写法要点：锁具体（「左眉一道纵向断疤」，不是「有伤疤」）+ 否定式护缺口（「保持不对称，不修复不美化」）。

### 10.2 签名锁定清单（每角色 2-3 条 · 措辞固定逐字复制）

- 从资产卡挑 2-3 条**最具辨识度、最易丢**的特征（位置+形态写死：左眉纵向断疤 / 深绿旧围巾绕颈两圈 / 右手无名指褪色红绳），汇成一页「签名锁定清单」挂在 characters.json 顶部；
- 每条 prompt **逐字复制**清单原文，禁同义替换、禁改写——与 §3 角色圣经字段同一纪律：换一个词就是换一张脸；
- 生图后逐张核对**签名在场**：缺签名即判废图重生成，不进分镜；
- 质检对照（严恪 QC 抽查项）：随机抽图核对签名锁定项与保护指令是否逐字在场、特征是否被模型"修正"。
