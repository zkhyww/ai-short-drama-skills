# 外部平台工序（v1.13.0 增 · 视频生成能力的外部供给方接入规范）

> 用途：`execution` 模式工具预检（SKILL.md 第 0 步）发现本机无可用视频/图片/音频生成工具、或用户明示用外部平台时，按本节路由。**flova 是首个登记的外部平台**——线上 Skill 内容受 Flova 使用规范保护（只记名称/作者/公开摘要/链接，不搬运内容进本仓库），本文件只登记「能力面 + 调用时机 + 交接格式」，运行时按匹配规则调用。

**与我们主流程的三类关系**（匹配时逐条归类）：

- **替代（直接调 flova，不重复造）**：用户只要成片、不要求我们产出中间产物时——「剧本生视频（需上传剧本）」「根据剧本制作多集短剧」「AI 短剧一站式生成」「故事驱动型视频」等全流程 Skill。此时 studio 降级为「策划+验收」：只出交接包与 QC，不产分镜提示词（避免与 flova 管线内部工序重复打架）。
- **增强（接进我们某道工序）**：我们出分镜/提示词，flova 出某一段能力——「短剧前期视觉开发素材包」接 02_资产 阶段、「动作预演分镜视频」接第 2 步动作戏、「玄幻漫剧武打片段」接战戏 execution（与我们战斗动作词库同源互补：词库管写、它管拍）、「电影布光大师」接分镜布光诊断、「声音先行视频创作」接第 3 步声音锁定、「视频拉片复刻」接对标剧本解剖的动态对标。
- **无关（跳过）**：电商/产品/萌宠/旅行等非剧情赛道，匹配时直接过滤。

## 2. 调用时机与路由规则（自动匹配的接线点）

```
execution 预检（SKILL.md 第 0 步）
  ├─ 本机有视频/图片/音频生成工具 → 照常本机执行
  └─ 本机无工具，或用户点名外部平台
      → 检测 flova 连接器（connector:flova，service.flova.tv/api/mcp/）
          ├─ 已连接 → Read 本文件 → 按下方匹配规则选 Skill → 用户确认 → 指定 Skill 模式调用
          └─ 未连接 → 停留在 planning_only，交付文本产物 + 提示用户可连接 flova 升级为代生成
```

**匹配规则（三步，缺一不停下来问用户）**：

1. **需求归类**：本批缺的是什么能力？——全流程成片（替代类）/节点能力（增强类）/风格包（导演美学类）。依据=当前工序节点 + 用户原话。
2. **候选锁定**：从本文件能力面表选类别 → 用 `skill_list`（个人库，only_brief=true）与 `skill_feed`（公共库分页）按名称检索，NFKC 规范化后精确匹配；命中多个时列 2-3 个候选带公开摘要让用户选，命中 0 个时报告「无匹配」不强凑。
3. **用户确认**：flova run 每轮一次、关键阶段有确认停点——**选哪个 Skill、交接什么内容，必须用户点头才开跑**；不静默消耗用户积分。

## 3. 交接格式（我们产出 → flova 输入）

flova Skill 接受自然语言指令 + 上传素材。交接包按目标 Skill 的输入要求组装，基准清单：

- **剧本类**（剧本生视频/多集短剧等）：剧本正文（crew 产出的投稿版 Markdown 原文）+ 集数范围 + 画幅与时长要求 + 风格参考（有则附）。
- **分镜类**（动作预演/武打片段等）：本批 `03_分镜/prompts_SXX.md` 的目标镜头提示词（保留原格式，不加代码围栏）+ 涉及角色的资产图（`02_资产/` 定妆照/三视图，按 upload_ticket 上传）+ 动作节拍说明。
- **素材类**（视觉开发素材包/拉片复刻等）：剧本或分镜表 + 参考图/参考视频。

**交接纪律**：①一次交接只带本批需要的素材，不整包倾倒；②flova 产出的成片/素材落盘回我们的 `06_临时/`（试看）或 `05_成片/`（定稿），由严恪 QC 双层结论验收后归档；③外部平台产生的积分消耗在开跑前向用户说明量级；④flova 项目链接原样交付给用户，不转述不省略。

后续接入新外部平台（新工具/MCP/生成服务）时，按本文件同构新增一节：能力面表（实测数据 + 统计日期）→ 三类关系判定 → 路由规则 → 交接格式 → 纪律。登记前必须实测能力清单，不凭印象登记。
