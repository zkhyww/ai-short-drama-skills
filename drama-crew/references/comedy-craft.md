# 情境喜剧专项

## 1. 从目标生成笑点

触发：喜剧承诺已经确定，而场景只剩俏皮话、人物突然变笨或笑点脱离主线。输入：本场目标、人物自我认知、关系/权力差、观众和人物的信息差、冻结结果。执行人文茵，结构前提需重选时先回纪遥/集纲。

1. 找出人物认真想达成的目标，及其过度自信、误判或不得不维持的体面；喜剧来自此人此刻的应对，不靠更换身份也成立的段子。
2. 先安排观众能理解的铺垫：约定、道具用途或错误预期。让人物选择使局面更难，再让同一铺垫以改变的意义回收。升级可提高暴露风险、关系代价或解决难度，不必更吵、更蠢。
3. 比较对白包袱、动作结果、听者反应三种表达，选当前最清楚的一种；反应已完成效果就不再解释笑点。
4. 检查笑点之后主线目标或关系仍前进；失效先补铺垫与人物选择，再改句尾，不按分钟补笑话。

落点：写进原集纲事件链或正文，不另列笑点配额。核验：指出铺垫、选择造成的升级及回收原文，检查是否破坏已知能力、人物尊严或正典。情境因果不存在回集纲；只是不顺口回对白。悲痛、静默或紧迫场不因“全剧喜剧”强行搞笑，用户已冻结的克制语气优先。

### 1.1 反差、误读与主观想象（条件专项）

通用反差先按 dialogue-craft §2；这里只在已定喜剧语气或允许的轻喜场命中时加载。

1. 把本人真实目标、外在言行、旁人掌握的信息分开。可用“表面维持体面、内心慌张”或“本人想低调、他人误以为在示威”等机制，但角色选择必须来自已有动机；不固定主角吐槽、配角脑补或系统毒舌角色槽。
2. 误读由实际线索加期待/偏见引起，推动下一次选择或关系变化；纠正失败必须有原因。重复时改变代价、知情或应对，不反复让所有人误解同一件事；不要求负面目标必得正面结果。
3. OS 可与表面语气形成喜剧反差，动作可接住笑点，不把动作、OS和解释台词重复三遍。俏皮话、热梗、夸张反应、破第四面墙只在年代、角色认知与已定风格允许时用，不设固定密度。
4. 确需展示人物想象时，正文明确“谁的想象”、起止及回到现实后的状态，区分想象、真实回忆与客观事件；不能用【闪回】冒充未发生的事。标记服从已选模板；模板未约定时用自然动作文字清楚说明，必要的主观画面格式在既有项目记录约定。想象中的道具、伤势、移动与能力不进入现实正典，角色不能凭空知道别人想象的内容。滤镜、画框等制作实现不固定到通用编剧方法。
5. 保留笑点依赖的铺垫、停顿与反应；字数不足先查故事功能，不插无意义互动，不一律删修饰词，不硬塞三人场。悲痛、危险和承诺兑现处先保护情绪，反差可以增加人物温度，不必转成笑话。

验证时核“线索—误读—选择—结果/回应”是否可定位；反例包括无依据脑补、听见别人的 OS、想象当现实和为笑点撤销已兑现结果。没有反差的坦诚交流与纯行动场不判失败。文字链成立不等于观众实测好笑。
