# 世界观档案（World Bible · 吸收自早期 n8n 工作流"宇宙企划书/静态设定集"思路）

> 使用场景（**唯一口径 · 本文件为世界观触发规则唯一定义处，其他文件只引用不复述**）：先核世界事实是否承重——地点与距离、时间锚、力量/职业/物理规则、势力权限、跨时空、跨季或高连续性状态会约束人物选择、证据、解法或制作连续性时启用。构造规则多、跨模块依赖强时建完整六模块；只需追踪空间/时间/设定边界时建轻量版；实际低风险且没有可继承世界资产时可免新建。题材标签、集数、快写或预览档位只影响展开与拆并，不得免除承重事实核查；上游已有世界观档案、时间线或专业边界时，任何入口都须读取并继承命中片段。立项时能确定承重风险即建，后续首次命中时补建，随批更新并按实际需要进交接块。
> 与正典账本的分工：**账本管"剧情连续性"**（人物/知情/关系/道具/伏笔/集末），**本档案管"世界本身的真实性"**（世界设定跨集不崩）。一个管戏，一个管世界。

## 1. 六模块（按承重复杂度选择完整或轻量）

| 模块 | 记什么 | 示例（玄幻） |
|---|---|---|
| ① 空间地理 | 疆域层级/主要地点/地点间距离与交通 | 青岚洲→天玄大陆→上界；宗门/秘境/禁区位置 |
| ② 时间线 | 纪元/朝代/大事件锚点/当前时间 | 玄历 1200 年，天魔劫后三百年 |
| ③ 力量规则体系 | **境界/等级/技能树/规则限制**（升级系统本体） | 炼气→筑基→金丹→元婴；功法分五行；禁术代价 |
| ④ 势力格局 | 宗门/家族/阵营/彼此关系与制衡 | 五大宗门、魔道双宗、皇朝与宗门的微妙平衡 |
| ⑤ 视觉奇观 | 题材特有的标志性画面/地理奇观/物种 | 剑冢万剑悬空、灵脉如河、渡劫雷云 |
| ⑥ 设定边界 | 硬规则/禁改项/观众会揪的错误点 | 灵气守恒、境界不可越级挑战、时间流速恒定 |

**轻量版**：只建 ①空间地理（城市/街区/地标）②时间线（年代/季节/时间锚点）⑥设定边界（职业常识/法律/物理现实）——角色与关系由正典账本管理，不在本档案重复。触发与继承边界只认本文件头部的承重风险口径，不按题材、集数或预览档位豁免。

## 1.1 世界规则怎样长成戏（不新增模块 · v6.10.0 增）

每条真正承重的世界规则，应在现有③力量规则、④势力格局或⑥设定边界中回答：

- 它改变了谁的可选路径、权限或处境？
- 它的作用范围、触发与调用条件是什么？
- 使用、违反或绕开它，实际有哪些成本与后果，哪些只是风险？项目未规定代价时可无新增损失。
- 它的例外与边界是什么，谁有资格使用？
- 观众依据什么理解它与当前解法的因果关系？可以延迟揭示，但揭示后须与已建立事实相容、可回看理解。

**承重机制采用双层口径，不新增字段**：

- **机制真实契约**：先写清「世界真实如何运行」——触发条件、能力边界、项目已规定的代价（如有）、例外与失效条件是什么。它是正典事实，不随角色误解或剧情暂未揭晓而改变。
- **剧中披露状态**：再分别判断「人物当前知道」与「观众当前知道」到哪一步。人物可误读、观众可领先或落后，但正文只能展示当前允许披露的部分；未披露不等于世界规则不存在，角色猜测也不得反写成机制真相。

两层答案仍融入现有③④⑥模块：机制层保证前后自洽，披露层决定本场能说、能看见和应暂缓的内容。写悬念时可以延迟答案，不能为了藏答案临时改规则。

承重规则以实际作用、调用条件和因果关系进入剧情；台词提过名称不自动证明解法成立，也不要求所有规则提前演示。禁止在主角陷入绝境时临时新增万能规则救场。例外及其披露须与既有事实相容，项目已规定的边界和代价必须兑现；没有新增损失不单独构成缺陷，已成立的后果也不能无因撤销。

本节不新增世界观字段，答案直接融入现有六模块。

## 2. 成长体系账本化（凡人修仙传式升级系统的落点 · 与正典账本联动）

- 主角及关键角色的成长在**正典账本「成长体系」栏**跨集追踪：
  `成长体系：主角 E01 炼气三层 → E05 筑基 → E12 金丹；装备：E03 得残剑 → E08 修复`
- **四线并行**（多维度体系，防单线无敌）：
  - 个人战力（境界/技能/功法）
  - 势力资源（宗门/势力/人脉）
  - 声望地位（名声/头衔/口碑）
  - 装备道具（神器/法宝/特殊物品）
- **升级节奏红线**：连续跃迁若没有准备、瓶颈和代价，会让成长迅速贬值；长段落里战力、资源、地位、信息或方法没有任何一维变化，才是成长停滞。具体步频按题材、体量和既有节奏裁量，不按固定集数凑升级。

## 3. 交付与更新

- **命中承重风险时建**：立项时已能确定就由主理人组织（可调纪遥或文茵）产出完整或轻量初版；后续首次命中时补建。上游已有资产只更新活动真源，不另造平行档案；立即落盘，按 SKILL.md 展示分级在下一自然节点合并通报文件名，用户要求时再展开；
- **命中变化时更新**：项目已启用或继承世界观档案，且本批确有命中模块变化时，编剧才附「世界观增量」（如新地点、新规则、权限或境界变化），由主理人合并；无变化不产空增量；
- **按启用状态交接**：项目实际启用或继承了世界观档案时，把活动真源随交接包传给制作侧，供其按命中模块建立场景资产或视觉奇观参考；未启用且没有可继承资产时不新增世界观交接物。

## 4. 与制作侧的衔接

- 制作侧丹青按需消费①④⑤⑥（空间地理/势力约束/视觉奇观/设定边界），并结合账本外观与状态行建资产；
- 制作侧景川按需消费②③④⑥（时间线/力量规则依据/势力关系/设定边界）；法术、变身、境界爆发等镜头仍按 dim-vfx 特效卡执行。只传命中片段，不把六模块全文塞给每个角色。

## 5. 质量四轴（检验层 · 六模块管"填什么"，四轴管"怎么验" · v6.8.0 新增）

> 吸收世界观美术设定法。实际启用的模块写完只算"填了"，命中的质量轴经核验才算"立了"。**诊断顺序：先查可信（地基），崩了其余白搭。** 轻量版按实际承重模块核①可信与④情绪基调；涉及差异化系统或主题表意时再核对应轴，不按题材名称减项。

| 轴 | 检验问题 | 工具 |
|---|---|---|
| ① 可信 | 观众信不信、住不住得进去（一致性+完整性） | **Watsonian 自检**：每个设定问"在这个世界内部，为什么会这样"——答得出世界内部逻辑=成立；答"因为剧情需要/因为这样好看"=破绽，必须回炉 |
| ② 独特 | 认得出、记得住（不是换皮） | **invention 四级**（下表）——对现实默认设定做了多少**有意义的替换** |
| ③ 表意 | 世界是否在替主题说话（不是中立容器） | **叙事地层**：一个物证同时供给多轴——磨损的石阶=生活痕迹（可信）+衰败主题（表意）+沧桑情绪（基调）；主题靠环境物证表达，禁台词解说 |
| ④ 情绪基调 | 被氛围感染了吗 | **spatial expression**：用形/尺度/光/密度先让人"感到"再"理解"——拥挤+潮湿+昏暗→压抑；开阔+明亮+疏朗→自由 |

**invention 四级**（由浅到深，定这个世界做到哪一级即止）：

| 级 | 改什么 | 例 |
|---|---|---|
| 命名级 | 只换名字，本质不变 | 警察叫"治安官"、货币改个名 |
| 表层级 | 外观、风俗、制度 | 独特服饰/礼仪/政体形式 |
| 系统级 | 社会运行逻辑、技术或自然体系 | 一套自洽的魔法经济/生态系统 |
| 本体级 | 物理法则本身 | 魔法改写因果、时间非线性 |

- **纪律：invention 匹配故事需要即止，不是越高越好**——现实题材停在表层级（靠完整性和情绪基调取胜）完全成立；级别越高，一致性维护成本指数上升。
- **弱轴反查**（四轴哪条弱，就回六模块查对应缺料）：可信弱→③力量规则/⑥设定边界不自洽；独特弱→invention 太浅或⑤视觉奇观无识别度；表意弱→主题没贯穿到①空间与⑤奇观；情绪弱→①空间地理没做 spatial expression。
- **交接同步**：仅在项目实际启用或继承世界观档案时，把本节已运行的四轴结论（尤其情绪基调定位与视觉母题）随活动真源交给制作侧，丹青据此确定场景资产板的氛围色调；未运行的轴不补造结论，未启用世界观档案时不新增固定交接项。
