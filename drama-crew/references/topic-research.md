# 题材深耕资料包（望舒·题材深耕专家使用，按需加载）

> **解决的问题**：`genre-and-fight-rules.md` 是覆盖通用大类的单表，遇到细分子赛道（虐渣/系统流/姐弟恋/年代商战/海外本土/主旋律讴歌…）就查无可查。本文件定义「数据库未覆盖的细分赛道」如何靠联网深搜现场生成资料包。
> **触发条件**：①纪遥判定「题材细分且现有规范未覆盖」；②用户主动要求深耕某赛道；③跨赛道组合中出现陌生赛道。除此之外**不读不用**。

## 1. 深搜要求（铁律）

- **最少 5 条、最多 8 条 WebSearch**，全部带当前年份/季度关键词，禁止凭训练记忆编造赛道数据。
- 每条结论**必须带信源与时间戳**（平台名/榜单名/报道日期）。
- 搜不到就**明写「未检索到」**，不许用通用规律糊弄——这条是失败判定项。

**搜索角度（覆盖越全越好）**：当期该赛道上榜作品 → 受众画像与人群结构 → 高频桥段/开场范式 → 收费卡点与集数惯例 → 平台政策与审核红线 → 同类赛道竞品空缺 → 近半年口碑崩盘案例（反面教材）。

## 2. 资料包 8 项结构（产出必须齐全）

| # | 项目 | 内容要求 |
|---|---|---|
| 1 | **赛道定义与边界** | 一句话定义；与相邻赛道的分界（如「虐渣」≠「复仇」，差别在施虐过程的展示比重）；典型误区 |
| 2 | **当期数据** | 热度档位（上升/平台期/衰退）、竞争密度、平均集数与单集时长、头部样本 3 部（带数据） |
| 3 | **受众画像** | 性别年龄结构、核心情绪诉求（要的是什么爽/什么虐）、弃剧雷点、付费意愿特征 |
| 4 | **桥段库** | 母题 3-5 个 / 高频桥段 8-12 条 / 开场范式 3 种 / 断章卡点惯例 / 本赛道专属爽点函数 |
| 5 | **情绪配方** | 主情绪 + 副情绪配比；情绪峰值通常落在第几集；低谷期允许长度 |
| 6 | **红线与雷区** | 平台审核禁忌、本赛道特有的价值观风险、易引发弃剧的写法 |
| 7 | **差异化切口** | 至少 3 个「别人没做/做烂了可升级」的新鲜切口，每个给一句话示例 |
| 8 | **参考样本** | 3 部可对标作品 + 各自可借鉴点与**应避开的坑** |

## 4. 交接下游

- 资料包**原文整段**交给文茵（写作用）与纪遥（选题校准用），顾临中转，不摘要化。
- 第 4 项桥段库直接并入写作素材；第 6 项红线并入季衡/素弦核查清单；第 7 项差异化切口供纪遥用于去同构。
- 资料包**只在本次项目内有效**，跨项目复用前必须重搜当期数据（时效铁律）。

## 5. 失败判定（命中即打回）

- 未做联网检索、或检索条数 <5 条
- 结论无信源无时间戳
- 用「一般来说/通常」式通用规律填补未检索到的项
- 差异化切口 <3 个，或切口与竞品重合
- 8 项结构缺项
