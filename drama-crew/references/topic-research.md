# 题材深耕资料包（望舒·题材深耕专家使用，按需加载）

> **解决的问题**：`genre-and-fight-rules.md` 是覆盖通用大类的单表，遇到细分子赛道或一个明确创作/对白/制作事实缺口时，既不能凭训练记忆补，也不能把一次小缺口扩大成整套市场调查。本文件分别定义「整赛道资料包」和「定向补项」。
> **触发条件**：①纪遥判定「题材细分且现有规范未覆盖」；②用户主动要求深耕某赛道；③跨赛道组合中出现陌生赛道；④文茵六行自检或 Studio 专业角色发现现有规则与共享案例索引不能可靠回答的明确问题。前三类走整赛道资料包，第四类只走定向补项；其余任务不读不用。

## 1. 两种检索模式与共同铁律

**A. 整赛道资料包**：目的是建立赛道全貌，执行下方 8 项结构；最少 5 条、最多 8 条搜索，覆盖互补角度。涉及热度、平台、政策、模型能力或竞争状态时带当前年份/季度关键词。

**B. 定向补项**：只回答一个已定位的问题，例如某职业流程、地域说法、年代用语、对白语用、镜头方法或模型当期能力。本地资料不能可靠回答且已有联网授权时，主动调用可达的 `agent-reach` 定向检索原帖、作者续文或完整可访问样本；不要求用户点名，也不把一个对白或镜头缺口扩成 8 项资料包。**不设固定搜索条数或样本配额**，以问题是否已被可靠材料回答为充分性标准；获得足够材料，或同类查询不再增加决策价值时停止。

**共同铁律**：

- 事实结论带可核来源与时间；平台、热度、政策、模型能力核当期来源，常青的语言、职业流程或叙事材料不强限近三月。
- 搜不到就明写「未检索到」，安全使用已知规则做原创，不猜补来源、原文或许可。
- 认证确证失效才请用户本机登录；执行失败只标未知。没有联网、安装、付费或落盘授权时维持相应模式，不自行扩权。
- 先查 Studio 单点持有的 `../../drama-studio/references/case-library/README.md`（从 Crew Skill 根定位时为 `../drama-studio/references/case-library/README.md`），按用途标签只读命中记录；获准且本地根已绑定时才读命中单条 TXT，不整包加载。公开索引不存在本地原文时不伪称已读。

**整赛道搜索角度（定向补项不强制覆盖）**：当期该赛道上榜作品 → 受众画像与人群结构 → 高频桥段/开场范式 → 收费卡点与集数惯例 → 平台政策与审核红线 → 同类赛道竞品空缺 → 口碑崩盘反面案例（反面教材）。

## 2. 整赛道资料包 8 项结构（A 模式必须齐全）

| # | 项目 | 内容要求 |
|---|---|---|
| 1 | **赛道定义与边界** | 一句话定义；与相邻赛道的分界（如「虐渣」≠「复仇」，差别在施虐过程的展示比重）；典型误区 |
| 2 | **当期数据** | 热度档位（上升/平台期/衰退）、竞争密度、平均集数与单集时长、头部样本 3 部（带数据） |
| 3 | **受众画像** | 性别年龄结构、核心情绪诉求（要的是什么爽/什么虐）、弃剧雷点、付费意愿特征 |
| 4 | **桥段库** | 母题 3-5 个 / 高频桥段 8-12 条 / 开场范式 3 种 / 断章卡点惯例 / 本赛道专属爽点函数 |
| 5 | **情绪配方** | 主情绪 + 副情绪配比；情绪峰值通常落在第几集；低谷期允许长度 |
| 6 | **红线与雷区** | 平台审核禁忌、本赛道特有的价值观风险、易引发弃剧的写法 |
| 7 | **差异化切口** | 至少 3 个「别人没做/做烂了可升级」的新鲜切口，每个给一句话示例 |
| 8 | **参考样本** | 3 部可对标作品 + 各自可借鉴点与**应避开的坑** |

## 4. 交接下游

- 每条取得的第三方原文独立保存为纯原文 TXT，只保留真实原文，不添加我方标题、出处、许可、分析或猜补尾文；来源、授权与取得状态写入对应 metadata，现有字段不足时写同一 ID 的本地来源旁档，不为此扩 schema。我方拆解/归纳另存并明确标注，成果只用稳定 ID 与 `source_locator` 回指唯一原文，需要扩读时按定位回源，不再复制一份混有我方说明的正文真源。
- 正常新增或同 ID 空值补缺统一走 `case_library.py add`，不得改动历史 `snapshot.original_case_count`；只有经批准的非空事实更正才直接编辑 canonical metadata，并复核 diff 后运行 `validate` 与 `build`。
- 新桥段、红线、差异化切口、词库或语料先作为**入库候选**，经过项目适配、与风险相称的核验并取得持久化/升格授权后，才写入正式 references；公开可读不等于可再发布原文。
- 当期数据跨项目复用前必须重核时效；常青材料只在其来源、语境或适用条件变化时复核，不机械重搜。
- 确定性事实缺口只阻塞受影响位置；没有风格参考不禁止文茵或 Studio 按现有规则原创。

## 5. 对标剧本解剖工序（拿到对标剧本/全本时执行 · v6.17.6 增）

> 资料包第 8 项给出对标作品名单后，真正拿到一部对标剧本（文本全本/部分集数）时，按本工序解剖——**把「这部为什么爆」变成可执行情报**。方法论消化自 jutian-hit-dissector（M1-M7 爆款机制/资产四分类/迁移边界），按文本剧本场景轻量化，零重型基础设施。

**五步解剖**：

1. **通读**：整本读一遍再动笔分析，不边读边下结论；记录第一反应（哪集想弃/哪段想快进——直觉数据）。
2. **量化**：动作行动词排频（抓词穷与口头禅）、OS/VO 密度（条/集）、台词开头复读（同一主语/地名起句数）、场次结构与时长配比、卡点类型分布——机械数据先行，防印象流。
3. **可抄（体例层）**：OS 承担什么功能、括号提示宽度、字幕用法、场次行格式——**体例可学**，直接反哺 submission-format 与各 craft 文件。
4. **防抄（机制层）**：拆爆款机制七问（M1 消费入口/M2 主角失衡/M3 压力系统/M4 胜负介质/M5 关系权力/M6 回报升级/M7 表达奇点）与爆点函数七拍（F1 失衡压制→F2 误导加码→F3 选择行动→F4 验证反转→F5 关系站队→F6 资源/身份/规则升级→F7 后果/新任务）——**机制可迁移，表达不可照搬**（台词、专名、连续桥段、独特道具组合、动作编排、终局表达一律不迁，与评审评分卡第 6.3 节抄袭判定同一口径）。
5. **产出入库候选**：解剖结论按词库、语料、反 AI 味样本与体例发现标注拟议去向；先做项目适配与相称核验，再由顾临按授权走升格通道，不直接写进正式 references。

**输出**：解剖报告（五步各一节 + 七问七拍逐项判定），随项目留档；体例/词库/语料层结论按升格通道沉淀回 references——解剖一次，skill 吃透一部。

## 6. 失败判定（命中即打回）

- A 模式未做联网检索、检索条数 <5 条或 >8 条；B 模式不套此数量判据
- 事实结论无可核信源；时效性结论没有日期/版本
- 用「一般来说/通常」式通用规律填补未检索到的项
- A 模式差异化切口 <3 个、与竞品重合或 8 项结构缺项
- B 模式没有回答明确问题却宣称充分，或已无新增决策价值仍无限扩搜
- 把候选材料直接写进正式词库/规则、复制未获再发布许可的原文，或用外部案例改动项目正典人物、伤病、证据、关系或结局
