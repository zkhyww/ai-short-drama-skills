# 双轨成稿与投稿排版（submission-format）

> 主责：顾临负责从已锁版内容机械派生；有 DOCX 文档工具时调用工具排版，没有时只交可核对的阅读版 Markdown 并诚实声明未生成 DOCX。文茵不在排版阶段改内容，季衡不重复终审。
> 核心边界：`完整制作母稿.md` 是**唯一内容真源**，`《剧名》_投稿阅读稿.docx` 只是**派生阅读视图**。排版不是再创作，也不是审批、备案或发行资格确认。

## 1. 何时生成

- **4A 始终生成**：完整项目终稿或直通稿进入交付时，先生成 `{项目名}_完整制作母稿.md`。
- **4B 按意图触发**：用户表达投稿、送制片人/平台编辑、对外阅读、需要 Word/DOCX，或明确要“制作版 + 投稿版”时生成投稿阅读稿；由已有语义直接路由，不新增用户弹窗。
- **分批不反复导出**：正文尚未锁版时只维护活动正文与账本；除非用户明确要阶段阅读稿，否则不为每批生成早版 DOCX。
- **专用模板优先**：接收方提供模板、字体、页边距或字段清单时，按其模板派生；通用模板只在没有专用要求时使用。

## 2. 唯一真源与版本链

1. 母稿头部记录：`project_id`、`script_rev`、`review_state`、目标成片时长、主画幅与用途。
2. 导出前对母稿正文计算 SHA-256。把 `source_script_rev` 与 `source_sha256` 写入 DOCX 自定义文档属性；工具不支持自定义属性时，在母稿交付记录中登记并明确告知，不能静默省略。
3. 投稿稿只改展示，不改字义。收到“顺便把这句也改了”的反馈时，先回母稿修改，`script_rev +1`，重跑受影响的青梧局部复核、素弦/季衡门禁，再重新导出。
4. `drama-studio` 只消费母稿；不得把 DOCX 反向当作剧本输入，不得让两份文件各自继续修改。

## 3. 两种视图的字段映射

| 内容 | 完整制作母稿 | 投稿阅读稿 |
|---|---|---|
| 剧名、一句话卖点、梗概、主要人物 | 保留 | 保留 |
| 集号、场号、内/外、地点、日/夜、出场人物 | 保留原字段 | 合并成易读场次行 |
| 场景五字段 | 保留，供制作读取 | 去掉字段标签，把必要环境与人物状态化成自然动作说明 |
| 动作、必要表情、可见道具 | 保留 | 保留，去掉纯机器指令口吻 |
| 对白、必要的承重台词表演提示 | 保留 | 保留；提示简洁置于人物名后或台词前 |
| 动作节拍、镜头建议、情绪强度数字、时长预算 | 保留 | 删除制作专用标签；若动作本身影响剧情，只保留自然动作正文 |
| `romance_axis`、质检节奏、review_state、账本增量、source_locator | 保留在母稿/交接头 | 正文删除 |
| 返修表、红线、评分、AI 痕迹、合规工作底稿 | 独立报告保留，不混进正文 | 删除 |
| 提示词、模型名、生成参数、AI 出图/配音指令 | 制作需要时保留在相应内部位置 | 删除 |
| 许可证号、批准文件编号、节目编号、审批结果 | 只有收到正式上游输入才可原样附入 | **不得生成、推断或预填**；收到正式字段且接收模板要求时才原样加入 |

**转换底线**：去标签不等于删戏。任何会改变事件、证据、知情边界、关系、人物选择、因果或季终悬念的删除，都不是排版，必须退回内容流程。

## 4. 通用投稿阅读稿结构

没有接收方专用模板时，按以下顺序：

1. 封面：剧名；可选副标题；作者/团队、联系方式、日期仅在用户实际提供时填写，未知字段省略，不写占位符。
2. 一句话卖点与故事梗概。
3. 主要人物：姓名 + 年龄段/身份 + 核心欲望 + 与主线直接相关的矛盾，控制为阅读性介绍，不搬运完整内部人物账本。
4. 正文：每集标题、场次行、动作与对白，按 **§4a 标准剧本排版**执行。

### §4a 标准剧本排版（v6.16.0 增 · 国内影视通用格式）

正文部分采用国内影视行业标准格式（与家法正文格式同源），这是**排版基准**：4B 产出时必须把母稿正文机械转换为本格式，接收方给专用模板时仍优先其模板。

**格式要素（缺一即排版返修）**：

| 要素 | 格式 | 示例 |
|---|---|---|
| 集标题 | `# 第 X 集`（只写集号） | `# 第一集` |
| 场次行 | `**场{集}-{场} {日/夜} {内/外} {地点}**` 加粗 | `**场1-1 夜 内 盛氏集团顶层宴会厅**` |
| 人物行 | `**人物：{名} {名} {名}**` 加粗，**空格分隔**，不用顿号/逗号 | `**人物：苏晚 苏曼 众高管**` |
| 动作行 | 以 `∆` 开头，一行一个可见动作 | `∆水晶灯下庆功宴觥筹交错。` |
| 台词行 | `角色名：（情绪）台词`，括号内 ≤5 字情绪/动作提示 | `苏曼：（低声）是我弄丢的。` |
| 闪回 | `（画面闪回：∆……）` | — |
| 转场 | 场末按需：`（切至）` / `（淡出）`，非每场必写 | — |

**排版纪律**：
- 行间不留空行——场次行、人物行、动作行、台词行一律紧排；集与集之间空行分隔。
- 重要动作不塞进台词括号，单独出 `∆` 行；括号只放 ≤5 字的情绪或动作提示。
- 场号按 `{集}-{场}` 连续递增，全稿不重不漏。
- 删除母稿中的 `【场景设定】`、`【动作节拍】`、`Beat`、情绪强度分值等内部标签（转换底线见 §3）；场景设定段的必要环境信息并入该场开头的 `∆` 动作行。
- 不为齐版改台词、不为凑格式加戏；内容性差异一律回母稿（§2 底线）。

**场次转换示例**（母稿 → 投稿阅读稿）：

```text
# 第一集
**场1-1 夜 内 盛氏集团顶层宴会厅**
**人物：苏晚 苏曼 众高管 侍应生**
∆水晶灯下庆功宴觥筹交错，身着保洁工装的苏晚推着清洁车贴墙而行，低头擦拭地毯酒渍。
∆苏曼端着红酒迎面撞上清洁车，酒液泼了苏晚满身。
苏曼：（讥笑）哟，这不是苏家大小姐吗？怎么，沦落到给人端盘子了？
苏晚：盛氏的保洁，也是一份工作。
苏曼：（凑近，压低声音）那你就好好擦。这地板，你们苏家当年跪着也没保住。
∆苏晚直起身，不看苏曼，继续擦拭。宴会厅大屏亮起，全场高管肃立鼓掌。
```

## 5. 通用 DOCX 排版（可选成品 · Markdown 排版稿为默认载体）

4B 默认交付 **Markdown 排版稿**（`《剧名》_投稿阅读稿.md`，按 §4a 格式纯文本排版，好检索好版本管理）；用户或接收方明确要 Word 成品时，才在此之上产出 DOCX，以下保守默认重点是耐读与可批注：

| 项目 | 通用默认 |
|---|---|
| 纸张 | A4 纵向 |
| 页边距 | 上下左右约 2.5 cm |
| 正文字体 | 中文宋体或等效易读字体，12 pt；英文/数字使用兼容字体 |
| 剧名 | 居中、加粗，20–22 pt |
| 集标题 | 黑体或等效无衬线字体，16 pt |
| 场次行/人物行 | 加粗，12 pt（§4a 格式） |
| 动作行 | 12 pt，`∆` 保留；台词行人物名加粗、台词常规 |
| 行距 | 1.35–1.5 倍；场次行前保留适度段前距 |
| 页码 | 页脚居中；封面可不显示页码 |
| 分页 | 每集前插入分页符，不用连续空行顶到下一页 |

不要为了“像正式稿”虚构版权声明、机构抬头、审批章、编号或项目联系人。没有专用模板时，也不声称上述通用样式必然满足某个平台的收稿要求。

## 6. 导出前核对

- 母稿 `script_rev` 与 SHA-256 已记录；
- 剧名、人物名、集数、场号与母稿一致；
- 正文符合 §4a 标准剧本排版：场次行/人物行加粗齐全、人物行空格分隔、动作行 `∆` 开头、台词括号 ≤5 字、场号连续、行间紧排；
- 每集另起一页（DOCX），集场没有漏排或重排；
- 内部审核字段、Beat/预算、账本提示、AI 制作标签已移除；
- 动作去标签后仍保留剧情事实；
- 没有自行添加审批编号、备案结论、版权主体或联系方式；
- Markdown 排版稿未生成 DOCX 时，明确说明默认载体为 Markdown，未伪装为 DOCX。
- 已生成 DOCX 时，必须逐页渲染为可视页面并逐页检查：无缺字、重叠、溢出、异常空白、孤行、错误分页或场次断裂；人物名、动作与对白层级清楚。任何排版修复后都重新渲染，不能只读正文或 XML 就宣布完成；宿主确实无法渲染时，交付时明确标注“未完成视觉 QA”。

任一内容性差异都要回母稿处理；只允许在本步骤直接修复字体、分页、缩进、页码、标题层级等展示问题。

## 7. 产物必要性判定表（题材 × 体量 → 必产 / 可并入 / 可免 · v6.14.0 增）

> 解决「哪些产物必须有、哪些可以并入、哪些可以免」的自由裁量不可比问题（实测 18 集轻量项目 11 文件 vs 60 集项目 22-29 文件，两套结构都对但无规则可查）。**判定先于产出**：主理人在第 0 步确认行落定题材/集数后，按本表判定产物清单，随第 3 步起执行并在交接单头部记一行判定结果（如 `产物档位：轻量（18 集·现实情感·可免：世界观/时长证据/查重独立文件）`）。

| 产物 | 必产条件（不满足则可免/并入） | 依据 |
|---|---|---|
| 市场简报 / 选题候选主题卡 | 所有项目必产 | 流程起点，不可省 |
| 候选结构查重 | 默认并入候选主题卡「查重结论」行；仅补充检索时拆独立 `02A` 文件 | SKILL.md 第 2.5 步留痕口径 |
| 世界观档案 | 按 world-bible.md 头部唯一口径：特殊题材必建；其他题材 ≥30 集**且**命中复杂度建轻量版；短篇现实题材可免 | world-bible.md（唯一口径） |
| 人物档案/圣经 | 所有项目必产（体量缩放：主角十二件套，配角五件套；<15 集可并为一份） | character-bible.md |
| 独立梗概 + 独立粗纲 | ≥30 集拆两文件；<30 集可并入选题报告后的「故事方案」段 | 交付文件数随体量收缩 |
| 逐集集纲 | 所有项目必产 | 创作承重结构 |
| 分批正文 | 所有项目必产；批粒度按 canon-ledger §5（10-20 集/批自适应；短篇可单文件） | canon-ledger.md |
| 正典账本 | 集数 ≥10 必产；<10 集随四件套顺带产出存档 | canon-ledger.md 头部 |
| 账本增量独立文件 | 集数 ≥10 的续写批必产 `{项目名}_增量_E{起}-E{止}.md`；<10 集可并入交付记录 | canon-ledger.md §2 |
| 连续性核查报告 | 质检批/用户要求/跨会话恢复时按节奏产出；全稿终审模式中途不产 | 质检节奏表 |
| 合规报告 / 终审评分报告 | 标准交付必产（与质检模式绑定）；直通交付不伪造 | 第 3.8/3.9 步 |
| 活动时长证据（逐集秒数表） | IAP/混合 或 漫剧载体（动作点折算时长）必产；IAA 真人短篇可并入集纲秒数列；短篇试写可免 | commercial-craft §5 |
| 标准制作交接单 | 进制作链必产；只交母稿不进制作时并入母稿交付记录 | 第 4A 步 |
| 完整制作母稿 | 4A 始终生成 | 本文件 §1 |
| 投稿阅读稿 | 4B 按意图触发，非默认产物 | 本文件 §1 |

**档位速查**：①**全量档**（60 集+/漫剧/IAP）——上表全部命中项必产，13 类齐备；②**标准档**（30-40 集常规题材）——世界观按口径、梗概粗纲可并、其余全产；③**轻量档**（<30 集现实题材/短篇）——可免：世界观档案、独立梗概粗纲、时长证据独立文件、账本增量独立文件（并入交付记录）；**不可免**：简报、主题卡、人物档、集纲、正文、账本（≥10 集）、合规、终审、母稿。**轻量≠缺核心产物**：减的是重复性/条件性产物，不是核查与真源纪律。
