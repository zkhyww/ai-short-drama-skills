# 爆款拆解方法论（吸收自 jutian-hit-dissector，按需加载）

> 只吸收「创作方法」层：CORE 判定、爆款机制速查、原创迁移矩阵。不吸收其工程基建（多模态深读/证据链/脚本验证器/项目目录体系——那是拆解真实成片的活，与我们的创作流程无关）。
> **使用时机**：选题决策（纪遥）、换题材（调整规则）、用户对标某爆款要求「像它但不抄它」时。其他场景不读不贴。

## 1. CORE 四核心判定法（选题独创性检验）

给候选选题做「删除测试」——**如果删掉它，故事会退化成普通同类，那它就是 CORE**。四层各问一句：

| 层 | 问题 | 判定说明 |
|---|---|---|
| 受众与情绪核心 | 观众靠近谁、在乎什么，期待获得何种体验与兑现？ | 可为解气、心动、好奇、温暖、紧张、遗憾等；不把所有承诺翻译成受辱后的补偿 |
| 戏剧核心 | 谁在何种压力下必须做什么选择？ | 压力可来自人物、关系、制度、环境、任务或自身限制，不预设反派 |
| 商业核心 | 什么循环持续制造钩子与回报？ | 循环须服务本项目已确认的主要情绪回报与兑现方式 |
| **奇点核心** | **删除后是否退化成普通同类？** | 指出本项目不可替代的机制、关系、视角或表达组织，不用具体作品桥段代答 |

**用法**：纪遥的候选方向每个必须过一遍四核心，奇点核心说不出 = 换方向。已选方向在选题报告中单独写一行「CORE 一句话」。

**引擎分类（K1–K7，选 1 主 + 至多 1 副）**：K1 外部胜负 / K2 身份地位 / K3 关系权力 / K4 信息真相 / K5 人物转变 / K6 规则系统 / K7 生存资源任务。写清主副引擎，防止中期引擎漂移（换了引擎观众会迷惑）。

## 2. 爆款机制速查（M1–M8，压缩版）

写作时按项目需要取用；机制是诊断工具箱，不要求逐项齐全，缺少某项不自动补戏：

| 维度 | 检查什么 | 短剧落地 |
|---|---|---|
| M1 消费入口 | 前 3 秒观众凭什么留下？ | 第一屏必须有理解锚 + 有效事件 |
| M2 主角失衡 | 主角当前在乎什么、缺什么或受什么限制？ | 已有稳定状态、任务、关系或好奇也能开场；不强制先受压或受辱 |
| M3 压力系统 | 什么持续形成阻力、选择或代价？ | 来源可以是对手、关系、制度、环境、任务或自身限制；长段落确已失去作用时才回查变化 |
| M4 胜负介质 | 用什么判定输赢（可见）？ | 胜负必须手机上看得懂的动作/事件 |
| M5 关系权力 | 谁在关系里掌握权力、如何转移？ | 关系长期静止且不再制造选择或代价时回查，不按每集次数凑偏移 |
| M6 回报变体 | 同一承诺能否以不同进展或结果兑现？ | 回报可加深、转向、完成或安静落地；不限定为更大打脸或更强烈度 |
| M7 表达奇点 | 本剧独有的、别人没有的机制？ | 对应 CORE 奇点核心，写进选题 |
| **M8 双赛道叠加** | 是否存在第二个赛道能叠加新的爽点源？ | 主赛道定世界观与基调，副赛道只供新冲突源；须过「不违和/受众统一/主次分明」三通过线（见 topic-selection 第 5 节⑥） |

## 3. 爆点函数速查（F1–F7）

单集/单场的情绪动作单元，写集纲卡点时对照：

| 函数 | 内容 | 例 |
|---|---|---|
| F1 失衡/压制 | 给主角加压 | 泼水羞辱 |
| F2 误导/加码 | 让观众以为更糟 | 被诬陷偷机密 |
| F3 选择/行动 | 主角主动出招 | 当众反杀证据链 |
| F4 验证/反转 | 真相揭晓 | 白板解题被认出笔迹 |
| F5 关系/站队 | 拉拢或站队 | 男主查出真相选择守护 |
| F6 资源/身份/规则升级 | 地位跃迁 | 董事会摘工牌自曝 |
| F7 后果/新任务 | 胜利留下新问题 | 揭露后引出更大黑手 |

> F 函数是识别回报与卡点的工具箱，不要求每集至少命中一项；连续使用同一函数只有在结构与效果也重复、已经造成疲劳时才预警。

## 4. 原创迁移矩阵（T1/T2/T3 —— 换题材/对标时的保原创方法）

用户要「像某爆款但不抄」，或换题材重做时，先判迁移深度，再改方向：

| 级别 | 定义 | 必须改动（六项中至少四项，第 5、6 项必改） |
|---|---|---|
| T1 同题材不同故事 | 保留核心命题与情绪回报，重写人物旧债/关系/压力/事件链/终局 | 1 主角身份与旧债 2 核心关系 3 压力源 4 胜负介质 **5 具体事件链 6 终局证明** |
| T2 相邻题材等价替换 | 保留选择压力与动作语法，建立新职业/规则的真实流程与失败代价 | 同上六项 |
| T3 跨题材内核迁移 | 删掉原题材外壳后核心仍成立才触发 | 同上六项，且必须换外壳 |

**红线（防抄袭）**：不得复用独特台词、专名、连续场口顺序、独特道具组合、可识别动作编排、终局表达。只借鉴「机制」不搬「表达」。
**可吸收层**：可以学习具象情绪载体怎样进入行动、反差怎样改变理解、回报怎样续接下一步，以及声音/画面怎样落住情绪；不得迁入案例的具体道具剧情、地域/性别/CP 默认、原句金句、字数配额或传播数字。
**判定**：迁移后如果只是「改名换皮」→ 相似性闸不通过，打回重做。

### 4.1 清洁室桥段复用法（对标拆解后的保原创落地）

**适用**：对标某爆款剧的**具体桥段/名场面**时，禁止直接仿写。桥段级复用必须走清洁室七槽位替换，**每次至少替换 3 个槽位**（含最关键的冲突来源与胜负规则），禁止只换人名和地名。

| 槽位 | 说明 | 示例（对标「女主被假闺蜜陷害」桥段） |
|---|---|---|
| ① 人物身份 | 主角/反派的职业、阶层、社会身份 | 豪门千金 → 破产创二代 |
| ② 关系结构 | 人物间的关系类型（闺蜜/师徒/兄弟/宿敌） | 闺蜜 → 合伙人兼前任 |
| ③ 冲突来源 | 矛盾的根源（利益/误会/复仇/资源） | 争家产 → 抢公司控制权与专利 |
| ④ 胜负规则 | 赢的方式与判定标准 | 家产继承权 → 新品发布会竞标 |
| ⑤ 关键道具 | 承载冲突的物件 | 遗嘱 → 核心技术专利书 |
| ⑥ 场景环境 | 事件发生的空间 | 豪宅书房 → 公司会议室/发布会 |
| ⑦ 结果代价 | 胜负的代价与后果 | 被逐出家门 → 团队解散+行业封杀 |

**执行流程**：
1. 拆解对标桥段 → 列出七个槽位的原值。
2. 至少替换 3 个槽位（**冲突来源、胜负规则两个槽位必换其一以上**；若只换 3 个，其余 4 个槽位也要避开「独特表达」——独特台词/专名/连续场口顺序不得复用）。
3. 替换后跑**相似性闸**：原桥段与新桥段并排，问三个问题——①换个观众能认出是同一桥段吗？②核心情绪回报是否保留（这是允许保留的）？③删掉原剧外壳后新桥段是否成立？
4. 任一项不通过 → 回到步骤 2 继续替换，直至通过。

### 4.2 赛道胜负介质锁（吸收自 7.8.6 赛道胜负介质矩阵 · 防一套发动机套所有题材）

**适用**：定赛道/选题材时，明确**本项目的目标与障碍 / 解法成立条件 / 观众期待的回报**。下表提供常见参考，不是题材武器白名单；不要求每部剧有败者，终局也可以共同完成、退出竞争或接受事实。

**回报判断**：回报须对上前文已经建立的具体关切，并以行动、关系、理解或结果让观众看见兑现；旁白或角色宣布“赢了”不能替代兑现。已确认利落反击的项目不被审核擅改成长久忍让，治愈或关系项目也不为制造爽感强塞羞辱。

| 赛道 | 常见解法参考 | 设对抗线时的失败原因参考 | 常见回报参考 |
|---|---|---|---|
| 都市逆袭/马甲 | 隐藏实力/资源降维 | 信息差（不知道对手是谁） | 身份落差打脸 |
| 家庭亲情/治愈 | 情感联结/爱 | 利己主义（失去家人信任） | 被守护/被看见的泪 |
| 甜宠 | 心动细节/真诚 | 套路与算计（被真诚打败） | 双箭头暧昧拉扯 |
| 悬疑推理 | 证据链/逻辑 | 留下破绽 | 真相揭晓的智力快感 |
| 古装权谋 | 布局/人心 | 贪与独（众叛亲离） | 博弈翻盘 |
| 职场/现实 | 专业能力/原则 | 违规越线（被规则反噬） | 专业硬刚/小人物翻身 |
| 玄幻/重生 | 实力层级/先知信息 | 傲慢（低估主角成长） | 碾压与预判打脸 |
| 乡土/烟火 | 人情/实干 | 投机取巧 | 朴实力量被认可 |

**防污染检查（纪遥选题必过，季衡终审复核）**：
1. **类型融合**：玄幻战力与查案逻辑、黑暗复仇与治愈、爽感与社会观照都可以共存；先明确每种类型分别承担什么回报，并让世界规则、能力边界、证据链和因果判定保持一致。
2. **污染模式**（有证据时返修）：①本项目的证据或能力规则被临时光环替代；②人物关键行为失去可理解依据，只剩题材口号；③解法推翻前文规则或核心承诺。没有新增损失、非典型解法或对手未落败本身不命中。
3. 选定主副类型后，正文冲突可以在不同胜负介质之间切换或共同作用；切换时同时核已建立的世界、能力或证据规则与核心受众承诺，违反任一项才判漂移。

**与 T1/T2/T3 的关系**：整剧级迁移用矩阵（T1/T2/T3），单桥段级复用用清洁室七槽位；两者同时启用时，矩阵优先，桥段替换在矩阵框架内执行。
