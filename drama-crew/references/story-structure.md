# 主线副线编织与全局节奏（按需加载 · 结构与呼吸感规范）

> v6.6.0 新增。吸收 7 源蒸馏：Fiveable 编剧课（副线三职能/编织四法/跨切交汇）/ StudyRaid（B-story 管主题/编织时序/砍线测试）/ The Write Practice（多线管理三原则）/ 夜雨聆风甜宠分段法（80 集情感五阶段）/ 头条动情戏 22 细节（身体出卖内心/反差动情）/ 中国作家库呼吸式节奏公式（四板循环）/ 凡人修仙传拆解（延迟满足/归零换图/草蛇灰线）。
> **故事引擎先行（v6.8.3 增）**：骨架排布之前先问——这部剧靠什么**持续产生下一场戏**？一个可持续的故事引擎 = 一组会轮换变化的变量：人物位置、已知信息、权力对比、信任关系、可用资源、未付代价、可用方法。检查某段「写不动了」时先查变量：七个变量全静止，不是桥段不够多，是引擎熄火了——先转动一个变量，再谈排节拍。
> **分工**：纪遥在选题层定「明线/情感线/暗线」三线框架与多季意向，文茵在集纲阶段按本文件编织落地；writing-craft §13 双轨节奏管**场/集内**微观松紧，本文件 §2 管**集间/幕间**宏观呼吸——两层互补不替代。
> **用法**：文茵排集纲与写情感戏前必读 §0/§1/§2/§3/§4；纪遥做多季规划读 §5/§6；季衡终稿窗读 §6。

## 0. 故事发动机承重判断（判断口径，不新增交付物 · v6.10.0 增）

现有「位置 / 信息 / 权力 / 信任 / 资源 / 代价 / 方法」七变量说明什么会动；以下六问判断故事为什么能持续动：

1. **主角可重复行动**：主角能够反复采取什么行动推进故事，而不是每集等待新任务、新线索或别人救援？
2. **对手正常赢法**：如果主角不介入，对手将怎样凭既有资源、规则和关系自然获胜？
3. **推进代价**：每次前进会失去、暴露或欠下什么；这笔代价会怎样改变下一轮选择？
4. **主胜负介质**：双方真正争夺的是哪一种资格、关系、资源、规则、位置或真相？胜负怎样被观众看见？
5. **当前范围承诺**：观众追完本季/本轮，哪些由主角欲望和开篇钩子提出的问题必须得到回答？
6. **终局证明**：最后用什么可见行动、真实代价和对手失败，证明这一范围确实结束，而不只是角色宣布「结束了」？

**中后段换挡**：当故事开始重复时，不只换地点、反派姓名或更大数值；应让压力来源、主角策略、不可逆代价中的两项发生性质变化。旧方法失效，才会逼出新故事。

以上答案只需体现在既有梗概、粗纲和集纲中，不另建表格，不要求角色逐条复述，不新增关卡。K1–K7 仍负责判断引擎类型，本节只判断引擎是否承重。

## 1. 副线编织法（副线 ≤ 2 条，对齐 writing-craft「副线 ≤ 1」上限的深化）

> writing-craft 规定主线唯一、副线 ≤1；本节规定**这唯一副线怎么织才不像补丁**。≥60 集长剧可开第二条（C 线），但 C 线只许零星几场。

- **副线三职能（立项门槛，一条不占 = 不立项）**：
  1. **主题呼应**——副线冲突镜像主线赌注（主角复仇，副线是别人被复仇反噬）
  2. **角色补充**——展现主线给不了的主角侧面（铁血总裁在副线里笨拙地对妹妹好）
  3. **伏笔铺垫**——副线事件为主线高潮递刀（观众先在副线认识的人，第 40 集成了关键证人）
- **B 线职能定位**：A 线管外部目标（赢/复仇/活命），B 线管**内心与关系**（情感线默认挂 B 线）——A 线负责「爽」，B 线负责「甜」与「人味」，两线在最炸的一场并轨。
- **编织四法**：
  1. **回访诊断**——每 2-3 集回访是常见节奏参考，不是固定排期；只在副线长时间消失、观众已无可识别锚点，或回归时需要重新解释时判遗忘风险。回访节点服从主线因果与悬念
  2. **因果勾连**——副线事件必须给主线推 0.5 步（副线里得罪的人，两集后挡了主线财路），纯平行不相干 = 砍
  3. **桥接角色**——一个同时活在两条线里的人（主角的助理同时卷进副线），切换时观众不迷路
  4. **悬念切线**——主线钩子拉满处切去副线（观众带着「那边怎么样了」的焦灼看副线，回访时回报翻倍）
- **砍线测试（自检）**：把这条线整段抽掉，主线剧情与高潮**毫发无损** = 断头线，砍；抽掉后高潮崩了 = 合格。
- **时序铁律**：第一幕引入（晚引 = 观众不认）→ 第二幕加码 → 高潮并线（副线必须影响主线终局）→ 收官前收束或按 §6 季终规则留白。开了不收 = 断头线（季衡「主线因果闭环」维扣分项）。

## 1.5 单元剧结构（长篇拆单元时按需 · v6.11.0 增，v6.11.1 收口）

> 单元剧 = 若干具有阶段性体验的案件、任务、地点、来访者或关系块，共同推动一条系列弧。单元多长、全剧有几个，由题材、时长和故事发动机决定；本节只管「单元自身成立」与「完成后全剧不能回到原样」，不规定集数和队形。

- **单元自身体验**：单元应提出一个当前问题或局面，让人物采取行动并遭遇变化，最后把结果落到人物或世界里。结果可以是问题被解决、代价兑现、关系改变、规则暴露或新条件成立；反转和反派惩处都是可选形态，不是所有题材的固定拍数。
- **焊回系列弧（至少有一条实质因果即可）**：可让单元改变主角资源或选择、推进核心关系或人物弧、揭开世界规则、留下会在后文起作用的人/物/信息，或改变长期对手与主线压力。下面是工具箱，不是配额：
  1. **关键资产进入主线**——本单元获得、失去或改变的物件/证据/权限，影响后续选择；
  2. **主线人物在单元中被改写**——重要配角、关系或旧债因本单元发生不可忽略的变化；
  3. **单元结果成为后续条件**——当时的人、话、决定或代价在后文重新生效；
  4. **长期压力留痕**——幕后对手、制度、世界规则或主题问题通过单元继续作用，不要求每次具象出场。
- **单元间衔接按意义选择**：上个单元的结果可以直接成为下个单元的入口，也可以经过必要的呼吸段再换题；只要观众仍知道主角现在为何行动、失去了什么、下一步要什么，就不必机械使用「起承转不合」。
- **单元节奏与角色容量**：相邻单元宜在冲突方式、情绪质地或关系重心上形成变化；新角色数量以观众能否迅速辨认其欲望、功能和关系为准，不设统一上限。
- **主线在场判断**：A 级悬念不必按固定集距露面，但每个单元结束后，观众应能感到核心承诺、人物弧、世界状态或长期代价至少有一项被推进。整段抽掉后这些都不变，才是合并或删除信号。

## 2. 呼吸感节奏（四板循环 · 集间宏观松紧）

> 核心原理：情绪操控必须张弛有度——**无宁静铺垫的灾难显得廉价，无温情衬托的杀伐显得枯燥**。全程紧绷 = 观众神经疲劳弃剧；全程平缓 = 无聊弃剧。

- **四板循环（呼吸公式）**：
  | 板 | 状态 | 干什么 | 写法 |
  |---|---|---|---|
  | 蓄力板（吸） | 慢 | 铺垫氛围/埋伏笔/积累情绪 | 场景细节、人物日常、慢对话——所有慢描写必须服务后面的爆点，禁无关废话 |
  | 爆发板（屏） | 快 | 释放张力/冲突集中引爆 | 短句、密集动作、快切——快而不乱，逻辑清晰 |
  | 缓冲板（呼） | 平 | 沉淀共情/喘息/回味 | 高潮后 1 场温馨日常或情绪复盘（大战后一起吃顿饭）——不新增冲突 |
  | 二次蓄力 | 循环 | 回到蓄力板开下一轮 | 长篇全程 5 轮以上 |
- **呼吸诊断**：连续爆发、连续平缓或固定快慢循环都不按集数自动判失败；只有长期同强度已经造成观感疲劳、信息停滞或情绪跳崖时才回查，按当前题材与体量补缓冲、压力或节奏变化。
- **强度梯度（禁跳崖）**：情绪起伏必须逐级——日常 → 小摩擦 → 对峙 → 决裂 → 大战；**禁从闲聊直接跳生死大战**（观众情绪跟不上 = 割裂）。低谷→高潮之间至少 1 场过渡场。
- **集纲落地**：集纲每行加「呼吸」标注列（蓄/爆/缓），按四板循环排布；与双轨节奏列（情节松紧×情感轻重）并存——双轨管场内，呼吸管集间。
- **收放对比法（高级）**：放线（高潮后插入温馨平淡日常）→ 收线（宁静铺垫后突然撕碎美好）——「毁灭性冲击力」的全部燃料来自前面的宁静。
- **缓冲段的隐性价值（判断口径）**：缓冲板不新增冲突，但**不是零事件**——它靠隐性变化产生价值：信任加深了一格、秘密的距离近了一步、某个执念悄悄松了。写缓冲场时找这个「不动声色的位移」，找不到的缓冲场才是真正的水。

## 3. 情感线五阶段（男女主情感线推进表 · 按总集数比例参数化）

> **适用条件（v6.12.0 收口）**：本表适用于**选题明确含男女主恋爱主/副线**的题材（甜宠/言情/都市情感等——此类题材情感线即 A 线）。其他题材不强套恋爱线：亲情、友情、师徒、团队羁绊、人物内在弧线都是合法 B 线，只要求 B 线满足第 1 节副线三职能门槛；悬疑/动作/恐怖/家庭等无恋爱结构的项目**不注入本节五阶段**，也无「互通心意时间位」检查。原表为 80 集实测，按下表比例换算到任意集数。

| 阶段 | 进度位 | 内容 | 观众感受 |
|---|---|---|---|
| ① 相遇绑定 | 0–25% | 暧昧与误会交织；被利益/危机/契约**绑定**在一起，被迫互相帮助；互相了解 | 「有点意思」 |
| ② 互相欣赏 | 25–50% | 通过主线事件看到对方的品格与能力，好感萌生；身体突破性接触（救/扶/拉）；有人开始自我否认感情 | 「磕到了」 |
| ③ 嫉妒与考验 | 50–75% | 吃醋生无名火；误会升级、外界阻力加大；但**关键时刻总为对方出手** | 「他们怎么还不在一起」 |
| ④ 心意确认 | 75–90% | 明确了自己的心意、愿为对方牺牲，**但没说出口**或被误会压制 | 「急死了，我要等他们在一起」 |
| ⑤ 表白收官 | 最后 10% | 表白/互通心意/在一起 | 「圆满，值了」 |

**六条铁律**：
1. **互通心意不早于收官前 10%**——大结局前出现 100% 互明心意的场景 = 提前泄洪（「伪胜利」可用：在一起了但误会没解还埋雷）。
2. **禁纯约会集**——不单独用一集写与主线无关的甜约会（收官最后 10% 内除外）；所有甜都要挂在主线事件上。
3. **关系推进诊断**——每集 1-2 个小推进是常见节奏参考，不要求逐集凑数；只要关系状态、理解、信任或阻力在合适节点发生变化即可。一个拎鞋、一碗红糖水、一次解围都可以是推进；集末「情绪卡点」（内心独白/眼神变化）按本集承载力使用，不靠强反转堆情感。
4. **因为了解而爱**——初遇后必须有 2-3 次互动/帮助/看到品格的过程才生情；**禁「看到成功/帅就爱上」**（感情铺垫是因果连贯的硬要求）。
5. **情感线为谈恋爱服务的方式 = 制造环环相扣的麻烦**——他们不能在一起（但每集都给好嗑的东西）；每次误会解开都增强理解与欣赏，再进下一个。
6. **贯穿符号可选**——一件道具/一句话随情感阶段变形（花苞→盛放；同一句话首尾不同含义），视觉化情感递进，避免直白台词。

## 4. 动情戏写法（身体出卖内心 · 顶配细节库）

> 台词在演，身体在招供——动情戏的高级感全在**小动作与眼神**，不在情话堆砌。配套：character-bible §5 每角色预埋 1 个专属小动作。

- **心动小动作**（嘴上故作平静，动作出卖内心）：低头、咬唇、搓衣角、手指反复摩挲、耳尖发红、突然整理根本不乱的袖口、递东西时指尖刻意避开接触又舍不得收回
- **眼神三层**：普通对视=看见轮廓 → 动情=**世界静音**（周遭人声全部消失）→ 深爱=**眼底发光、彻底失神**（目光多停半秒才移开/看完背影久久无法回神）
- **反差动情（顶级苏感）**：越高冷/沉稳/克制的人，动心后的**破例**越值钱——情绪从不外露的人指尖颤抖、声音放轻；从不送礼的人笨拙地带了早餐；规矩最多的人为对方破了规矩。**破例 = 爱的证据**，写动情戏先翻人物小传找他的「从不」。
- **破防瞬间**：强撑的人破防前有征兆——声音变平、动作变慢、过度礼貌（越客气越危险）；破防落点用**生理信号**（喉结滚动/呼吸一滞/眼眶红了却笑），禁旁白宣布「她崩溃了」。
- **密度与克制**：动情戏贵精不贵多；情绪顶点数量服从本集承载力，连续顶点互相稀释或没有铺垫时才回查。该克制时克制（深情的最高级是不说），攒到真正的顶点再引爆。

## 5. 凡人式成长曲线（长篇/玄幻/系统流的升级纪律）

> 用户原则：**世界观够大就可以一直写，升级不用太快**；每 1-3 集完成一个精彩小故事可作长篇节奏参考，不是固定周期。吸收《凡人修仙传》三层纪律：

- **延迟满足**：一次升级跨多集铺垫（找材料/炼丹/闭关/打逆风局），突破瞬间集中爆发——积累越久，突破越炸；禁每集升一级（通货膨胀 = 爽点报废）。
- **升级体系透明**：境界/等级有明确标准、瓶颈与通过率——读者紧张感来自「这次能不能过」，不靠反派作恶，系统自带危机感。金手指**只给放大器不给战力**（把时间变资源，不给代打），成长曲线三段：闷声发育 → 资源升级 → 悬念揭晓。
- **归零式换图**：换地图不是换场景，是**重新排队**——本季天花板到了下一季地板（化神进了灵界也得从底层熬起），靠新地图的规则差异重启张力，靠人脉/智慧/旧底牌赢回地位。
- **升级的多维化（判断口径）**：「升级」不只有敌人更强一维——**位置**（进入更大的舞台）、**信息**（知道了一个改变格局的秘密）、**权力**（得到/失去调动资源的能力）、**信任**（同盟建立或破裂）、**资源**（金手指进账或被夺）、**代价**（上次胜利的账单到了）、**方法**（旧招失效逼出新路）——任一维变化都是真升级。连续几集都在「换更强的敌人」= 单维升级，换两三个维度轮着动，升级感立刻不疲劳。
- **草蛇灰线**：前季/前段的看似闲笔（道具/路人/一句话），数季后回收成关键转折——每个多季项目挂一张「长线伏笔表」（埋设集/预计回收季/回收方式），青梧伏笔超期检查据此执行。
- **小故事节奏**：1-3 集完成一个小故事是常见参考，不按固定集数自动判失败；小故事应有阶段体验并让大主线至少发生一项实质变化（信息/关系/资源/代价/选择）——大主线是暗河，小故事是浪花，浪花不断流，暗河不干涸。

## 6. 季终悬念与多季铺垫（最后一集的双任务）

> 每部剧最后一集 = **收本季 + 开下季**双任务同时完成。世界观够大 → 可以一直写；收官即开篇。季数不设上限（万妖图录传已连载 11 季仍在涨），但必须守 §6.1 三道防线。

- **双任务铁律**：
  1. **本季主线必须收束**——本季大冲突给出结果（赢/输/惨胜都可，烂尾不可）；本季副线与人物关系全部交代（收束或明写留白到续季）。**留悬念 ≠ 本季的事不办完**——收的是事，留的是新事。
  2. **续季悬念锚必须埋下**——最后一集末尾让观众带着 1 个大问号离场（三源任选）：
     - **新地图**：主角踏进更大的世界/收到更大舞台的邀请（凡人式「欢迎道友飞升」——全剧最后一句是欢迎词；万妖式 S11「执棋境」揭开世界被外力锁死 → S12「小世界之外的天地」）
     - **新对手**：本季大 boss 之上的影子露出一角（幕后者/更高级势力注意到了主角；万妖 S12「蛰伏万年的执棋势力登场」）
     - **新代价**：胜利的账单晚到——主角赢了今季，却发现赢了这件事本身引来了更大的麻烦（身份暴露/大势力盯上/挚友反目种子）
- **悬念锚三禁**：禁纯预告式旁白（「下一季他们将面对……」）；禁与本季主线无关的硬贴片；禁把本季已收束的冲突重新翻出来当悬念（那是烂尾不是铺垫）。
- **多季一致性**：季与季之间按 character-bible §7 四行追踪表核人物连续性（性格不漂移/关系不重启/弧光接续）；每季立项时在世界观档案里补「本季地图与天花板」一节——本季主角起点=上季终点，本季天花板=下季地板。
- **长线布局**：季终悬念锚在**本季前段就要埋**（至少 1 处前季伏笔指向它——草蛇灰线，不许终集凭空掏）；纪遥选题报告对多季项目标注「第一季收束点 + 续季悬念锚」两行。

## 6.1 N 季连载模式（万妖图录传基准 · 长线运营天花板）

> 案例：《万妖图录传》（红果 AI 漫剧，2026）——5 个月 11 季累计播放 60 亿+，一月两季节奏；S11 上线首日热度 1.25 亿，连续四季破亿（红果首部）；S12 预约量 520 万。它证明了 N 季连载的可行性与回报天花板，也用血泪暴露了三条长线红线（见三道防线）。

- **连载节奏**：一月两季、单季 90-164 集、单集约 2 分钟——季与季之间不留长空窗；预约量经济（S9 380 万 → S12 520 万）靠「收官即开新季」的连载惯性滚动，**季终悬念锚就是预约转化的引擎**。
- **世界观逐季升维（真相洋葱）**：每季揭一层世界真相——S11 揭「世界被外力锁死」，S12 开「小世界之外的天地」。N 季项目在世界观档案预埋「真相洋葱」（3-5 层，立项时写好但只给目录不给谜底），每季开局揭一层、收官引出下一层——**世界观够写的前提是真相分了层**。
- **伏笔收割季**：十几季的伏笔在关键季集中回收（万妖 S12「埋藏十几季的诸多伏笔即将集中爆发」）——长线伏笔表按季管理，每 3-5 季设计一次「伏笔收割季」，集中回收的快感密度远超逐集小回收。
- **N 季三道防线（每季收官后跑「季间体检」，三条全过才开下一季）**：
  1. **形象不漂移**——万妖 S11 姜月初建模不如 S10、甚至闪现男性面孔，观众反弹迫使 S12 延期两周回炉重做（520 万预约差点崩盘）。对策：character-bible §7 永不漂移特质 + 制作侧资产锚定表，**每季开工前复核形象锚定**——AI 生成项目此坑致命，角色脸一垮全盘皆输。
  2. **战力不崩坏**——万妖 11 季后战力体系崩坏，被迫靠「伪画界」世界观兜底。对策：凡人式升级纪律（§5）+ 成长体系账本第七栏，跨季必须审计战力天花板与通过率，禁为单季爽点临时拔高——今天的超模就是明天的崩坏。
  3. **支线不失控**——万妖后期支线铺陈过多、节奏拖沓。对策：副线砍线测试（§1），每季开新支线前先收旧支线，**全剧同时活跃支线 ≤2**。
