# 创作方法路由

本文件只导航现有流程，不增设阶段、角色、确认关或评分。顾临在每次派单时执行；具体创作和核查仍归原成员。已有稿按问题直达，快写沿用主流程例外。

专项文件是本包 reference，可按问题直接引用，不要求另装外部 Skill，也不表示原仓库全部模块已安装。

## 1. 选择与派单

先读当前任务范围、用户已确认承诺与材料版本，再按 §2 选阶段、按 §3 选实际问题。已批准写法优先于参考方法；题材名或作者国籍只帮助检索，不决定必须用什么。需深入作者方法或案例分析时，按 [screenwriting-library.md](screenwriting-library.md) 先读取本地选中章节并核版本/散列，外部资料不得代替本表出关。每个问题选一个主方法，只有不同缺口确实需要时才加补充方法；不把所有参考一次注入。

把下列短块填入原角色任务模板，不另造方法报告：

```text
【本次方法】阶段/范围｜要解决的问题｜主方法文件与章节｜为何适用/排除条件
【执行依据】当前真源修订与原文定位；命中方法原文（新成员实际注入）
【落点与验证】写入现有哪份产物/哪场；审核者核什么具体变化；失败回哪一层
```

回传在已有交付说明中列实际落点与未解决项即可。方法“选中/已读”不等于“已使用/有效”，须在交付原文指出因果、行动、回应或结构变化；审核者检查文本，不给遵循方法本身加分。没有问题不强造修复。参考不可达时说明未读，按可达通用方法原创；承重创作、对白或制作事实缺口按 topic-research 交望舒定向补项，选题市场事实缺口才回风聆；阻塞范围限于依赖它的部分。

## 2. 阶段导航与出关证据

表中出关是现有流程的验收条件，不替代用户方向决定、青梧核查、素弦合规或季衡评分。

| 当前任务/输入 | 执行人及方法原文 | 交付落点 | 本阶段可验依据 | 失败返回 |
|---|---|---|---|---|
| 接稿或恢复：用户要求、现有文件 | 顾临：[startup-guide.md](startup-guide.md) §1/§3；[canon-ledger.md](canon-ledger.md) §4 | 已有接稿/进度入口 | 确认与建议分开，真源和已审范围可读；本次范围明确 | 来源矛盾先查原文；只有无法判定的关键冲突问用户 |
| 未冻结结构的片段探索：人物/生活片段/情绪画面，用户允许探索 | 文茵：[theme-design.md](theme-design.md) §1「片段探索任务」；按需含蓄戏或喜剧法 | 原范围内候选片段文件，标未定稿；接稿记录写下一动作 | 片段有可感知行动/回应，标明试探与既定事实；正式扩写前回原确认及结构验证 | 片段空泛回文茵；需改用户承诺回原方向决定，不自动变E01 |
| 选题：事实简报与受众承诺 | 风聆核源；纪遥：[topic-selection.md](topic-selection.md) §5；[title-naming.md](title-naming.md)；[theme-design.md](theme-design.md) §1（主题/形式确有问题时） | 原候选主题卡与选题结论 | 承诺有兑现方向，事实与创意假设分开，名称与内容相符 | 市场事实缺口回风聆，创作专业事实回望舒定向补项，概念不成立回纪遥；方向仍按原确认关 |
| 梗概/人物/世界：已选方向 | 文茵：[character-bible.md](character-bible.md) §1–4；[world-bible.md](world-bible.md) §1.1（按该文件触发）；[theme-design.md](theme-design.md) §1–2（按需） | 现有梗概、人物档及已启用世界档 | 选择由欲望/阻力推动，规则能在事件中使用并产生后果 | 缺动机/规则回文茵；承诺冲突回纪遥或用户明确决定 |
| 粗纲/集纲/多季：活动梗概和前态 | 文茵：[story-structure.md](story-structure.md) §0/§1/§2/§4；长篇加 §5/§6；[writing-craft.md](writing-craft.md) §2/§9/§15 | 既有粗纲/集纲单元格 | 开场与目标、有效行动、实际变化、当集回报、结尾承接形成事件链；跨季保留相关成长成果 | 事件链失效回集纲；根本发动机失效回梗概/纪遥，不用台词救结构 |
| 正文：本批集纲、前文和正典 | 文茵：[writing-craft.md](writing-craft.md) §7/§12/§18；[dialogue-craft.md](dialogue-craft.md) §1/§2/§5/§7；AI 制作正文加 §9.3 与 [commercial-craft.md](commercial-craft.md) §5；按 §3 选专项 | 本次正文与既有增量 | 场内目标、阻力、策略及结果可见可听；人物能行动也能回应；不照抄方法标签 | 表达回正文/3.7；改变前态或结果的修复回剧情责任层 |
| 改稿/3.7：当前稿及修改边界 | 文茵：[dialogue-craft.md](dialogue-craft.md) §9；青梧：[canon-ledger.md](canon-ledger.md) §2/§3 | 完整改动范围正文、原变更表、必要增量 | 前后依赖仍成立，动作/发声能共存；估时证据分层，受影响资料已处理 | 纯表达回3.7；承重事实回文茵相应剧情层；青梧只查只并 |
| 3.8/3.9 审核：当前待审真源与已核范围 | 素弦合规后季衡：[review-scorecard.md](review-scorecard.md) §3/§8/§9；青梧沿原范围核连续性 | 原合规/终审报告 | 举证实际文本、修订和覆盖范围，未核不当通过；既有分档/返修上限不变 | 依缺陷回表达、正文、集纲或选题；到原上限仍阻塞则上报 |
| 4A/4B 交付：当前修订及适用审核 | 顾临：[submission-format.md](submission-format.md) §1/§2/§6/§7 | 唯一标准正文与必要配套资料/交接 | 版本一致、用途匹配、正文无内部复核元文本；阅读与制作共用正文 | 内容在唯一正文修订并重核影响，明确要求的格式导出再重生成；文字合格不等于成片合格 |

## 3. 题材与场景问题导航

先按 [genre-and-fight-rules.md](genre-and-fight-rules.md)「题材契约五问」同时确认必须提供的体验与不可破坏的边界。下表是条件路由，不是每场清单。

| 实际问题 | 主方法与应用 | 有效证据/失败责任 |
|---|---|---|
| 情境说是喜剧，却只有旁插笑话 | [comedy-craft.md](comedy-craft.md) §1 | 人物目标引发误判/升级/回收；前提缺失回集纲，表达问题回文茵 |
| 人物位置、道具或跨场动作接不上 | [writing-craft.md](writing-craft.md) §12「空间、道具与跨场接续」与 §18；涉及知情再读 [canon-ledger.md](canon-ledger.md) | 原正文能追踪位置变化、道具去向、出入口与时间关系；只补已有事件所需依据，改动行动/结果时回编剧剧情层；不产机位、景别或剪辑方案 |
| 场首空间难读，或集尾弱/下集不接 | [writing-craft.md](writing-craft.md) §18；[commercial-craft.md](commercial-craft.md) §7.2 | 场首自然一两句可建立当前局面；相邻尾首原文能指出未决问题及有效推进；空间表达回正文，切点牵涉剧情结果回相邻集结构，不新增危机补数 |
| 场首像资料表，重复故事日或道具清单 | [writing-craft.md](writing-craft.md) §18；[submission-format.md](submission-format.md) §3/§4a | 先查后文重复，独有承重信息自然融入唯一正文动作段，再同步影响资料；不得只给字段加∆，不改事实或提前披露 |
| AI 剧本偏薄、微表演没写或时长有疑点 | [commercial-craft.md](commercial-craft.md) §5；[dialogue-craft.md](dialogue-craft.md) §9.3 | 环境、行动与有因果的听答反应写进原正文；缺戏回编剧，镜头表达回 Studio；默认文本自检，仅未消除的疑点局部升级，不逐集试演 |
| 安静戏成了说明书或没有关系变化 | [quiet-drama-craft.md](quiet-drama-craft.md) §1 | 可感知的行为/回应/理解变化；无承重变化回场景，非强加噪声 |
| 人物喊主题、形式不服务故事 | [theme-design.md](theme-design.md) §1–2 | 对立选择及后果支持主题，形式改变信息体验；回梗概或实际场景 |
| 场地只是背景、道具只是装饰、障碍撑不起干预，或公共群戏散乱 | [writing-craft.md](writing-craft.md) §7「场地、道具与公共程序」 | 环境改变可行策略，道具改变用途或知情；公共程序使目标碰撞，不逐场强套 |
| 人物对立只剩好坏标签、盟友只会赞同，或施压对白未触及实际选择 | [character-bible.md](character-bible.md) §4「价值压力」 | 具体代价逼出选择，质疑有其自身利益和关系依据；回人物或场景层 |
| 明确长剧试播/提案或戏曲任务 | [screenwriting-library.md](screenwriting-library.md) §3 | 只取命中专项，返回既有纪遥/文茵/望舒职责；普通短剧不触发 |
| 世界观名词堆积、观众不懂当前秩序/资源用途，或兑现缺少规则依据 | [world-bible.md](world-bible.md) §1.1；[dialogue-craft.md](dialogue-craft.md) §9.2 | 仅凭正文定位规则作用、人物选择和可感知结果，区分合法延迟与理解缺口；简称不合并功能。已有事实补呈现，新增规则按授权回创作层，青梧核因果，季衡核观看理解 |
| 本季/当前完整单元缺成长回报，或维护冒充新获得 | [world-bible.md](world-bible.md) §2；[story-structure.md](story-structure.md) §5/§6 | 以实际承诺核当前所得、可用性与后续影响；后季计划不能代偿，代价不机械清零。无成长承诺不强加升级；新增事实先核权限与取得条件 |
| 取证推断越过依据，或行动变化只存在于说明文字 | [writing-craft.md](writing-craft.md) §7「凭什么」「信息差三角」 | 获取路径由线索/人物处境支持，必要前态与变化可感知；保留合理延迟披露，回正文或对应前置场 |
| 长动作拖延、能力升级抹掉旧成果 | [genre-and-fight-rules.md](genre-and-fight-rules.md)「动作戏判断」；[story-structure.md](story-structure.md) §5/§6 | 目标/位置/策略/关系实际换挡，相关旧能力与人物仍有因果作用；回文茵结构层 |
| 特殊场面只有氛围或结果，过程/协作/权限/物件进度/叙事层状态不清 | [genre-and-fight-rules.md](genre-and-fight-rules.md)「跨题材场面入口」，仅取实际命中的机制行 | 正文有可见可听的过程、回应与前后状态；歌舞/综艺的实力、失误或换位先有表演依据，再有评审结论，清唱条件和指定词曲状态传到 Studio。交接按 prompt-assembly §1 装配并查实际产物；缺失证据回文茵，声音/舞步实现回制作，不靠反应蒙太奇补故事。普通场面不为齐类目加戏 |
| 动作与长对白抢同一身体/时间 | [dialogue-craft.md](dialogue-craft.md) §9.2–9.4 | 占手、气息、负荷和对手行动共同成立；改结果前退剧情层 |
| 尾钩变强却撤销了已兑现结果 | [writing-craft.md](writing-craft.md) §2；[canon-ledger.md](canon-ledger.md) §3 | 新期待由已有后果生长，既有安全/成果未被无因抹掉；回文茵及青梧 |
| 局部改稿、同声跨视点、版本恢复 | [canon-ledger.md](canon-ledger.md) §1–4；[submission-format.md](submission-format.md) §2 | 边界、事件时间、角色/观众知情、衍生资料可追溯；按错源归责 |

## 4. 来源与使用边界

参考 [screenwriting-skills 固定版本](https://github.com/jtydhr88/screenwriting-skills/tree/a152b8c055be36cbb741ed2d13a8dd4a84c26902) 的 `sw-workflow` 阶段导航和恢复思路；本包采用自己的角色与已有真源体系。专项文件说明各自来源。外部方法按问题取用，不采用固定节拍卡数、国别模板或效果保证；本文是原创操作归纳，不分发原书/原 Skill 长段文字。外部许可与引文版权不因可公开读取而消失。
