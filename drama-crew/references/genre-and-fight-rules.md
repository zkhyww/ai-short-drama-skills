# 题材与打斗规范

> 使用场景：**下发选题分析师、编剧任务前，或向制作侧景川交接动作/类型场面时**，先 Read 本文件，按当前场实际承担的功能与事件贴对应原文。
> 题材名只帮助定位，不替代场面判断：标题没有“打斗/巨物”等词，只要实际发生追逐、攻防、异常显现、证据观察或其他承重场面仍须命中；未发生的功能不因题材标签强贴。

## 题材专属规范

**不是「什么题材都能写」：主流赛道都能跑，所有题材先过下方契约五问；命中本表已有赛道时，再给选题分析师与编剧附对应专属规则行。表外题材不硬套近似行。**

| 题材 | 专属规范（创作时强制） |
|---|---|
| 都市/现代 | 商战职场细节自洽；身份与结果有可理解的事实依据，旁白按实际功能使用；器物与项目时代、人物使用条件相容 |
| 古装宫斗/权谋 | 锁定朝代基调后，用语、器物、礼制必须同朝代，防时代错位；核心胜负靠信息差、资源与名分博弈，偶然事件可以引入新局面，不能直接替人物完成胜负 |
| 玄幻/战神/武侠/志怪 | 动作按下方「动作戏判断」执行；法术、变身与异常状态按「魔法、变身与规则效果」交代实际作用及边界，规则权威仍在 world-bible §1.1。力量层级用行动前后状态与相称反馈呈现；参数台词可用于挑衅、评估、误导或战术沟通，不能代替结果 |
| 悬疑/刑侦/证据场 | 信息管理：锁「谁知道什么」；需要观众/人物观察的线索须有可感载体、实际观察者与当下允许推到的结论，误导仍基于真实证据。线索回收与揭示时机服从承诺；巧合可引入线索或相遇，不能直接解决案件，真相与动机须有可回看痕迹 |
| 恐怖/惊悚/志怪场 | 先给可辨认的日常锚，再让声音、影子、痕迹、物件、空间或人物感知发生具体异常，并写出实际回应及显露/保留到什么程度。**显形与留白按恐惧来源选择**：局部适合制造未知，完整显形适合兑现威胁或改变策略；跳吓应有因果并留下结果，不能只靠音量。机制一经建立应前后一致（同 world-bible §1.1），幻觉或不可靠视角不能一笔撤销真实代价 |
| 年代/历史 | 时代用语与政策合规；涉及真实历史人物/事件需先提醒用户确认授权与边界 |
| 甜宠/闪婚/其他关系场 | 先明确人物在乎什么及互动依据，用实际的提议、照顾、拒绝、选择或行动与接收者的回应推进关系/感受；续写或改写不得凭空制造过去的阻挠、亏欠、冲突或关系史。误会、嫉妒与外界阻力只在有心理、知情依据时使用，不强造创伤或固定男女队形 |
| 喜剧/荒诞 | 写清角色当下目标、具体误解/错配/规则碰撞、当事人的实际反应与笑点落点；“发生搞笑误会”“气氛滑稽”不是事件。笑点可来自行动、语言、节奏、身份或处境，不要求每场插梗 |
| 追逐/灾难/逃生 | 让威胁的来向与变化、人物可用路线/出口/障碍及关键选择进入因果，交代行动造成的空间或状态结果；不靠“场面惊险宏大”代替追逐和应对，也不为规模强造伤亡与破坏 |
| 表演/比赛/非战斗奇观 | 写清任务、规则/接续条件或胜负判据，参与者实际做了什么、可观察的变化/难点及协作者、观众或对手的反应与结果；“表演精彩”“全场震撼”只可概括已发生的内容，不能替代内容本身 |
| 通用底线（所有题材） | 不涉违法、色情、血腥暴力渲染、赌博美化；分镜杜绝肢体畸形/扭曲、画面闪烁卡顿等生成质量问题 |

## 题材契约五问（表内表外题材通用 · v6.10.0 增）

题材表只提供提醒，不代表穷尽全部赛道。确定题材后，用五问明确本项目的创作承诺与解法条件，不把题材名称当武器白名单：

1. **情绪承诺**：观众进入这个题材，主要想持续得到什么感受？
2. **胜负介质**：本项目的目标、障碍与回报是什么，解法如何成立？可共同完成或退出竞争，不强制双方输赢。
3. **专业真实**：哪些职业流程、社会规则、礼制或物理边界一错就会出戏？
4. **特有失败**：人物在这个题材里最怕以什么方式失败？
5. **背叛承诺的捷径**：什么解法会违背本项目已建立的规则、能力边界或核心期待？非典型解法按因果核验，不按题材标签直接否决。

答案融入既有选题、梗概和正文，不新增题材表或交付物；表外题材不得硬套最相近的一行。

## 动作戏判断（按实际场面功能与规模缩放 · v6.10.0 重写）

动作戏的核心不是动作数量，而是目标、空间、策略与结果：

1. **目标与任务**：人物可能争夺人、物、出口、时间、位置、公开结果，也可能训练、展示、护送、逃离或完成其他动作任务；目标决定什么过程必须看清。
2. **相对位置与路线**：入口、出口、距离、方向、障碍、危险源和可利用物怎样约束移动与接触；人物不能在无地理关系的空场里互殴。
3. **压力、回应与策略**：体力、武器、人数、地形、信息或心理准备形成压力；对方怎样响应，旧办法失效时怎样换距离、目标、武器、合作方式或节奏。多人可以同时夹击、掩护、牵制或撤离，不必排队轮流出手。
4. **承重接触与位移**：真正改变局面的格挡、命中、失手、夺取、阻拦、落点或位置变化写出主体、对象及结果；场景中的掩体、台阶、门窗、器物或地形要实际参与因果。
5. **结束状态**：交代动作后人物、道具、空间、能力、暴露程度或下一任务的真实状态；训练、表演、试探和安静过渡可不造成受伤、耗竭、环境破坏或反转，但已经批准的主要过程与结果不能缩成「一番交手获胜」。

「起手→交锋→接触/回应→结果」是短动作场的参考形态，不是所有动作戏必须复制的固定拍数；15 秒只可作为短场预算示例，不作统一上限。力量规模与反馈服从已锁能力、媒介和项目风格，不要求每次升级到伤害、代价或环境破坏。招牌动作可以维持人物识别，但应随目标和处境变化使用，不能机械复读。血腥表达继续遵守现有克制边界。

### 魔法、变身与规则效果（动作/机制场命中时）

正文只交代会影响本场结果、路线、知情或连续性的实际机制：谁/什么是**来源与目标**，产生什么效果及相关限制，路径或作用区域是否承重；区分实体本身与其放出的光、烟、风、能量或其他派生效果；写清人物、材料、武器与空间在调用前后的真实状态，以及咒语/手势/触发与观众、人物何时得知规则。无需给所有能力强加法力消耗、光束、精确米数或统一特效形态；制作侧不得为了表现方便发明原文和 world-bible 没有的能力、修复或逆转。机制真实、成本、例外与能力所有权仍引用 `world-bible.md` §1.1 的既有模块，本节不复制另一套世界规则。

### 跨题材场面入口（条件示例，不增每场字段）

上表各行是场面发平或交接容易丢信息时的入口，不是新 Schema。原有六类功能继续按实际事件命中：悬疑看线索—观察者—可推结论/揭示边界；恐怖/志怪看日常锚—实际异常—回应—显露/保留；关系看提议/行动—接收者回应；喜剧看目标—具体错配—反应/落点；追逐/灾难看威胁路径—路线—空间/状态结果；表演或非战斗奇观看挑战/判据—实际变化—协作或对抗回应。

下列机制可与悬疑、关系、喜剧、动作、魔法等叠加，只在当前场真实承担时展开；正文写观众能看见/听见的事件、必要过程、回应、状态和披露边界。排版沿用 submission-format.md §4a 已选模板及其必要景别提示，不把完整摄影调度、逐秒剪辑、Panel 或制作工单塞进正文：

| 场面机制 | Crew 正文须使什么成立 |
|---|---|
| 歌舞、演奏、戏曲 | 谁演/唱什么、凭什么表现赢得或失去认可：把承重乐句、稳定接唱、动作控制、协作/失误等本场实际证据写成可见可听的过程，再写他人回应与结果，不以“全场震惊”代替实力。明确清唱/伴奏/设备播放条件、进入接续或中断；舞蹈竞争写谁从哪里经怎样的有效行动取得位置、他人如何让位/回应，不能只宣布“夺回 C 位”。指定词曲与原创待定分开，缺音轨只标时长待锁，不用字数证明歌曲已容纳；无对白不等于无表演声音。普通后台对白、无声热身不展开声乐流程；精确节拍、机位与声画工单归 Studio |
| 体育竞赛、载具 | 目标、规则或胜负判据，有效动作、对手回应、位置/接触及阶段结果 |
| 烹饪、工艺、维修等精细操作 | 原材料/工具、改变状态的操作、失败或完成进度及物件去向；缩时也保留使结果成立的真实过程 |
| 潜入、伪装 | 目标、通行条件、遮挡/视线/感知、谁知道什么及暴露或脱身结果 |
| 多方谈判、庭审、仪式 | 发言/行动主体、对象、权限/程序、证据或物件变化、他人回应与结果；自然简短集会不强套完整程序 |
| 动物、异种互动 | 物种/体型与已定能力、行动目标、可感知刺激、人兽/异种互动及结果；没有拟人设定不补人类行为 |
| 水下、失重等特殊环境 | 环境对移动、感知、交流或资源的实际约束，人物应对及状态后果 |
| 闪回、梦境、平行时空 | 当前叙事层、进入/退出、人物或观众允许知道什么，以及返回后继承的真实状态 |

正文已经凭行动、对白、声音和结果完成承诺时不重复填这些名称；指定专业事实仍按原定向核查，世界规则仍归 `world-bible.md` §1.1，不在此复制；优先引用 writing-craft §7/§12/§18 及现有题材方法，不另建子系统。

## 战斗动作词库（防词穷弹药库 · v6.17.5 增）

> 用法：写到动作戏发现只会反复用同一批动词时，对照本库取词。与「动作戏判断」五问配合——五问管方向，词库管弹药。本库是取词参考不是用词配额，优先服从动作设计。

**分层取词**（按力量级别/兵器类型/空间层次）：

- **环境反馈链只是可感反馈之一（按场面选择）**：力量等级不靠形容词堆；继承已确认的能力、媒介与场面结果，按本场真实需要写「行动→相称可感反馈/状态结果」。反馈可落在对手回应、人物位移、物件/空间变化、声音或感知；伤害、环境破坏与消耗只在本场创作确需且授权范围允许时设计，不为套用词库自动添加。原创剧本尚未冻结时，Crew 可在授权范围内合理创造后果；已锁事实不得改写，制作侧不得擅增。
- **近身兵器**：刀（劈/撩/抹/格）、剑（刺/挑/削/绞）、枪棍（扎/拦/扫/点）、拳掌（崩/切/掖/靠）、暗器（掷/弹/洒）。
- **空间层次**：垂直（腾/坠/踏壁/借柱借梁）、水平（掠/横穿/贴地翻滚/撞穿阻隔）、窄域（贴身换手/以短破长/借墙借角）。
- **受击与消耗**：受击写「具体部位+失衡方向+生理反应」——踉跄半步、闷哼、护住肋侧、退时带翻凳；不写「受到重创」「吃痛不已」类概括。

**反词穷纪律**：
- 先查行动目标、策略变化、空间利用、对手反馈与结果是否重复；设计成立后才处理措辞，同一强力动词频率只能帮助定位，不能单独扣分；
- 力量可视化从本场已定行动与相称可感反馈/状态结果中选择；形容词可辅助，但不能用自动添加伤害、破坏或消耗代替动作设计；
- 批次交付前可排频定位高重复段，但不得只换同义词冒充动作修复；终审端 #16 仍须给实际设计重复或观感疲劳证据。

## 粘贴要点

- 给选题分析师：**所有题材先贴「题材契约五问」**；目标题材命中专属规范表时再贴对应行；涉动作戏时再贴「动作戏判断」全文。
- 给编剧：**所有题材先贴「题材契约五问」**；命中专属规范表或跨题材场面机制时再贴对应行；正文涉动作戏时再贴「动作戏判断」全文与「战斗动作词库」。
- 给制作侧景川：按本批实际场面功能贴命中行；涉动作/机制场时贴「动作戏判断」及必要的「魔法、变身与规则效果」。制作侧从故事事实选择镜头、表演、声音与特效方法，不把参考形态改成固定拍数，也不补写胜负、能力、病因、历史关系或揭示时机。
