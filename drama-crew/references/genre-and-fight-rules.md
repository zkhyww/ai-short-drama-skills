# 题材与打斗规范

> 使用场景：**下发选题分析师、编剧任务前，或向制作侧景川交接动作戏时**，先 Read 本文件，按目标题材与是否有动作戏，把对应原文粘贴进现有模板。
> 不涉及动作戏的题材无需粘贴打斗规范；不涉及的特殊题材行无需粘贴。

## 题材专属规范

**不是「什么题材都能写」：主流赛道都能跑，所有题材先过下方契约五问；命中本表已有赛道时，再给选题分析师与编剧附对应专属规则行。表外题材不硬套近似行。**

| 题材 | 专属规范（创作时强制） |
|---|---|
| 都市/现代 | 商战职场细节自洽；身份落差用可拍事件呈现，禁止旁白解释；现代器物时间线不错位（智能机时代不得出现过时道具） |
| 古装宫斗/权谋 | 锁定朝代基调后，用语、器物、礼制必须同朝代，防时代错位；斗法靠信息差与名分博弈，不靠偶然事件 |
| 玄幻/战神/武侠 | 打斗按下方「打斗规范」执行；力量层级用视觉结果呈现，禁止台词报数值（「三成功力」类）；境界/规则首集立规矩并全程自洽 |
| 悬疑/刑侦 | 信息管理：每集锁「谁知道什么」；线索必须闭环回收；禁止巧合破案；真凶动机在前半程埋下可回看痕迹 |
| 恐怖/惊悚 | 氛围工具箱：恐惧可从熟悉事物逐渐异常、迫近的直接威胁、未知规则或人物主观感受进入；**显形与留白按恐惧来源选择**——声音/影子/痕迹/局部适合制造未知，完整显形适合兑现威胁或改变策略。跳吓可以使用，但应有因果铺垫并留下后果，不能只靠突然音量重复刺激。伪安全可按需要经历预兆、短暂平静与颠覆，也可直接破裂，不固定三阶；五感异常与视觉奇观按场面目的取舍。真相是否完整揭示由结局承诺决定，但机制一经建立应前后一致（同 world-bible §1.1）；若采用幻觉、记忆偏差或不可靠视角，须前置线索且不能一笔撤销人物已经付出的真实代价。 |
| 年代/历史 | 时代用语与政策合规；涉及真实历史人物/事件需先提醒用户确认授权与边界 |
| 甜宠/闪婚 | 误会必须有来源与代价；禁止为甜而甜的降智操作 |
| 通用底线（所有题材） | 不涉违法、色情、血腥暴力渲染、赌博美化；分镜杜绝肢体畸形/扭曲、画面闪烁卡顿等生成质量问题 |

## 题材契约五问（表内表外题材通用 · v6.10.0 增）

题材表只提供提醒，不代表穷尽全部赛道。确定题材后，用五问锁住它真正独有的创作逻辑：

1. **情绪承诺**：观众进入这个题材，主要想持续得到什么感受？
2. **胜负介质**：这个题材靠什么决定输赢，而不是统一靠打脸或身份碾压？
3. **专业真实**：哪些职业流程、社会规则、礼制或物理边界一错就会出戏？
4. **特有失败**：人物在这个题材里最怕以什么方式失败？
5. **背叛题材的捷径**：哪种方便写法会直接破坏题材快感，例如悬疑靠巧合、权谋靠对手降智、治愈靠突然说教？

答案融入既有选题、梗概和正文，不新增题材表或交付物；表外题材不得硬套最相近的一行。

## 动作戏判断（按题材与场面规模缩放 · v6.10.0 重写）

动作戏的核心不是动作数量，而是目标、空间、策略与结果：

1. **争什么**：双方必须争夺具体的人、物、出口、时间、位置或公开结果；没有目标的交锋只是动作展示。
2. **空间怎样参与**：先让入口、出口、障碍、危险源和可利用物进入动作因果，人物不能在无地理关系的空场里互殴。
3. **优势从哪里来**：体力、武器、人数、地形、信息或心理准备决定开局优势；力量感用动作前后状态和环境反馈表达，不靠台词报数值。
4. **策略怎样改变**：试探后发现旧办法无效，才换距离、目标、武器、合作方式或攻击节奏；每轮交锋应改变位置、资源或认知，避免装饰性来回。
5. **结果留下什么**：动作结束必须改变持有物、关系、暴露程度、行动能力或下一目标，不能打完恢复原状。

「起手→交锋→受击→结果」是短动作场的参考形态，不是所有动作戏必须复制的固定拍数；15 秒只可作为短场预算示例，不作统一上限。招牌动作可以维持人物识别，但应随目标和处境变化使用，不能机械复读。血腥表达继续遵守现有克制边界。

## 粘贴要点

- 给选题分析师：**所有题材先贴「题材契约五问」**；目标题材命中专属规范表时再贴对应行；涉动作戏时再贴「动作戏判断」全文。
- 给编剧：**所有题材先贴「题材契约五问」**；命中专属规范表时再贴对应行；正文涉动作戏时再贴「动作戏判断」全文。
- 给制作侧景川：涉动作戏时贴「动作戏判断」全文，S 段切分参考「起手-交锋-受击-结果」形态（参考非固定拍数）。
