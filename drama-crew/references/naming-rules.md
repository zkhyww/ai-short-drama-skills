# 角色命名规范（时代、家庭与辨认成本优先）

> 使用场景：**定名、改名、或编剧校验定名时**先 Read 本文件，把「命名边界 + 候选生成与复核 + 执行确认」原文粘贴进下发模板。
> 不需要命名的环节（如纯分镜续写且无新角色出场）无需读取。

**问题背景**：名字需要适合故事的时代、地域、家庭关系和人物使用情境，并让同场人物易于辨认。常见字、叠字、少见姓或朴素姓名本身都不是缺陷；没有作品证据时，不凭印象声称某个字或名字“高频”。
**触发**：所有主要角色（主角/对手/助力者/重要配角）定名时使用本规范。选题分析师第一次定名；编剧与制作侧景川全程沿用已定名，不得擅改。

## 1. 命名边界（有证据才重定）

1. **实际辨认困难**：只在同一作品、同一关系网或同一场景中，姓名的读音、字形、称呼或人物功能确实让读者难以区分时调整；同音、近音或相同用字不脱离使用情境判错。
2. **可识别仿制**：已知具体作品时，若姓名连同人物身份、关系或独特表达构成可识别仿制，必须重做；只共享常见字、常见姓或读音，不足以证明仿制。
3. **用户与项目禁用**：用户明确禁用、已锁定的知识产权边界、家族辈分或其他项目事实优先执行。已由用户或上游确认的定名不得擅改；发现证据后提出候选并等确认。

## 2. 候选生成与复核（按项目需要取用）

1. **姓氏有来源**：常见姓、少见姓都可用于主角或配角；先服从时代、地域、民族、家庭关系与真实来源。现实中少见的姓不因陌生被禁，也不因稀有自动加分。
2. **音义参考**（可选，选真实可读的字，不造字）：

   | 音义方向 | 用字示例 | 使用条件 |
   |---|---|---|
   | 山水草木 | 岫、汀、荻、蘅、屿、川 | 项目确实需要相应意象，且读音、字形与时代背景合适 |
   | 明暗刚柔 | 曜、朔、峥、桓、润、珩 | 含义或反差确实参与人物、关系或传播设计 |
   | 日常朴素 | 柱、全、喜、根、芳、明 | 符合家庭取名习惯与人物年代，不把朴素自动当土气 |

3. **组合规则**：
   - 单字或双字名服从时代、家庭命名习惯、读音与辨认成本，不从稀有字库随机拼装；
   - 名字可以有含义，也可以只是家庭自然取名；不得强迫名字预告角色命运、性格或反差；
   - 同音、近音、同声母或同韵尾只在实际听读混淆时调整；家族辈分、同名剧情或现实设定需要保留时，可用姓氏、称谓、关系和场面调度维持辨认；
   - 不按阶层、主配角、正反派固定姓名气质，不强制二字名与三字名混用，也不为“跨剧随机”改掉自然、已成立的名字。
4. **命名交付格式**：选题报告给 2-3 套候选，并说明时代/地域/家庭关系/辨认成本；只有名字含义确实参与人物或情节时才补充说明，不要求每个名字自带卖点。

### 候选复核

逐套核对：①时代、地域、民族与家庭来源是否成立；②同场称呼、读音和字形是否造成实际辨认困难；③是否触碰用户禁用或构成对已知作品的可识别仿制；④生僻字、谐音或称谓是否增加目标载体的理解成本。项目若确实需要姓名含义、人物反差、关系呼应或传播性，再把它们作为候选取舍依据；不满足这些加分项不自动重定。

## 3. 定名纪律

候选复核给出事实依据，不凭“熟脸感”“网感”“土气”或未经验证的词频打回。用户或上游确认后，编剧只沿用定名；需要调整时回到候选与确认流程，不在正文中自行换名。

## 4. 执行确认

定名后名称全链路锁定（选题→梗概→集纲→剧本→分镜锚定表），如需改名按 SKILL.md「调整规则」表走「替换角色名」行：统一替换并同步账本（补一条「改名记录」：旧名→新名+生效集），不得只改一处。
