# 剧名命名规范（有网感 · 不直白不土 · 能传播）

> 使用场景：**选题定案与梗概交付时**必读——每个候选主题必须配 2-3 个剧名候选，选题确认关展示给用户选；定名后全链路锁定（标题/封面/交接块一致）。
> 本文件管**剧名**；角色名见 `naming-rules.md`（两者是不同维度，不要混用）。

**问题背景**：剧名常见毛病——直接用题材词（《食堂逆袭记》）、陈词滥调（《总裁的契约甜妻》）、长句堆砌、无记忆点，又直白又土。剧名承担四个功能：**封面标题 / 搜索关键词 / 传播钩子 / 题材+情绪+差异化浓缩**。好剧名让观众 1 秒决定点不点。

## 1. 网感剧名类型库（母型，按题材/情绪选，不照抄案例）

| 类型 | 结构 | 示例（示意，非照搬） | 适合 |
|---|---|---|---|
| **身份反差式** | 最低微身份 × 最高反差身份/能力 | 《保洁阿姨是隐形大佬》 | 逆袭/马甲/爽感主线 |
| **情绪宣言式** | 情绪词/意象 + 氛围 | 《在暴雪时分》《小巷人家》 | 情感/治愈/生活流 |
| **数字悬念式** | 数字/时间 + 悬念 | 《第 100 次告白》 | 甜宠/悬疑/强钩子 |
| **极致承诺式** | 强预期管理（重生/归来/三年后） | 《三年后，她惊艳全场》 | 重生/复仇/回归线 |
| **双关梗式** | 一词多义/玩梗/反常识 | 谐音双关、旧梗翻新 | 轻喜/反差/话题剧 |
| **地域烟火式** | 地名/场所 + 人情 | 县城/食堂/老街 + 叙事感 | 现实向/乡土/群像 |

## 2. 剧名五检（定名后逐条过，挂一条不过就重拟）

1. **一眼懂题材**：看完剧名 1 秒内知道这是什么类型的剧——看不懂=失败。
2. **三秒有钩子**：剧名本身带情绪或悬念（反差/宣言/数字/承诺），不只是"描述"。
3. **顺口可传播**：≤12 字（竖屏封面一行放得下）、读起来顺、适合做切片标题/二创梗。
4. **不撞名**：搜索查重（平台同名剧 ≥2 部即换），避免大热剧碰瓷式蹭名。
5. **承诺可兑现**：剧名承诺什么，正片必须兑现什么（《三年后惊艳全场》就必须真的惊艳）——标题党翻车是口碑杀手。

## 3. 直白土判据（命中任一条 = 打回重拟）

- 直接用题材/职业词平铺（《食堂创业记》《乡村医生》）
- 「XX传 / XX记 / XX之XX」滥用到无信息量
- 长句堆砌（>12 字，像一句话剧情简介）
- 陈词滥调（《总裁的XX》《XX夫人》《豪门XX》）
- 无记忆点（看完记不住，混在一堆剧里找不着）
- 与角色名混淆（剧名 ≠ 主角名，除非主角名本身即品牌）

## 4. 命名流程（落在选题确认关）

1. **纪遥选题报告**：每个候选主题卡附 **2-3 个剧名候选**（按类型库出，标注类型 + 网感说明）；
2. **顾临选题确认关**：候选主题卡展示时一并展示剧名候选，用户可定主题、也可单独换剧名；
3. **定名锁定**：选定后标题全链路一致（成稿文件名/封面文案/交接块），改动走统一替换。

## 5. 交付格式

`《剧名》（类型：身份反差式 ｜ 网感：保洁与资本双面，一句话钩子 ｜ 字数：9）`——候选 2-3 个并排，方便用户挑。
