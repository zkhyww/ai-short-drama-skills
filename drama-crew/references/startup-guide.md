## 1. 启动时怎么回应

主理人先读本次请求、可达的项目配置与已有材料，识别用户现在要做什么，再选择展示方式。功能卡是给使用者看的导航，不是要求逐项选择的问卷，也不进入剧本正文、成员专业提示词或视频投喂正文。

| 当前情况 | 首次回应 |
|---|---|
| Crew 新项目首次启动，未要求跳过 | 按顺序展示：开场说明两团分工，并明确告知可说“跳过引导”直接做、说“展开全部功能”随时补看 → §2 完整功能导航（三组均展示，每项说明用途与产物，标明本次推荐项）→ §3 自动填好的本次配置 → 一个最小下一步。不能只给流程箭头或让用户自行打开说明书 |
| Studio 新制作任务 | 简述本次范围、目标配置和必要缺项后直接推进；只有用户要求展开时展示完整导航，不强制长配置表 |
| 同项目续写、制作、返修或跨会话恢复 | 读取已有配置、版本与当前进度，只显示本次配置和变化；已展示或已跳过的完整导航不重复。可用已有项目记录判断，不因缺少“引导已读”字段重做初始化 |
| 用户说“跳过引导”“直接开始，别介绍功能” | 省略完整导航与长配置表，回显一行本次范围、继承设置和必要建议，然后进入匹配环节；缺项按下段处理 |
| 用户说“展开全部功能”“再看配置引导” | 展示 §2 与当前 §3，不重置项目，不重启选题，不自动执行新功能 |
| 只问某功能是什么/如何使用 | 直接解释命中功能，不启动创作、制作或配置问卷 |

信息足够时，展示完就推进当前任务，不为确认已经明确的内容再加一道“是否继续”。只有缺项会改变当前产物、核心事实、重大风格或授权边界时，才合并问最少的问题；能从可达材料读到的先读，不让用户重填。无题材的新手，下一步只请其说“帮我选题”或描述一句想法；已选制作但无稿则请其提供目标稿件。不在这个下一步附加题材、风格、受众等偏好问卷，这些可随用户补充再识别。

“跳过引导”但没有任何任务目标或可承接项目时，只问一句“这次想写什么，或要处理哪份现有稿件？”；若只选了制作团，则问要处理的剧本/镜头/资产。不能自行编造项目。已有目标但尚缺实际稿件时先要该稿件，能做的规划照常推进。

跳过的是教学，不是事实核查、既有质检节奏、方向与新增主要资产确认、IP/付费/对外发布授权；不等于“直通未审稿”“无需质检”或“预算不限”。只有用户明确改变这些选项时，才按各自原有规则处理。已有合法授权继续继承，不重复索取。跳过偏好默认只作用于当前项目/会话；用户明确要求以后也这样才使用宿主已有偏好机制，不新增全局配置或 hook。

## 2. 完整功能导航

Studio 首次开场默认简述本次范围与已有配置，要求展开时才展示完整目录；Crew 的引导方式仍按 Crew 主入口。分工说明：“创作团负责故事和剧本，制作团负责把已有剧本变成资产、镜头、声音与制作方案。你用日常语言描述任务即可，我会推荐本次需要的功能。熟悉后可说‘跳过引导，……’直接开始；随时说‘展开全部功能’补看。”以下是能力目录，不代表全部同时启动；未安装的另一团或不可用的工具标为“待就绪”。

### 创作团 drama-crew

| 功能 | 能帮你做什么、交付什么 | 什么时候用 |
|---|---|---|
| 市场与开放选题 | 查询当期赛道，给市场依据、候选主题与比较理由 | 没有方向或明确要市场研判；有稿不重跑市场 |
| 故事规划 | 一句话卖点、梗概、粗纲、全季/逐集集纲与连载钩子 | 从零规划或调整结构，按单集时长和总容量选结构 |
| 人物小传 | 按全季功能规划阵容、核心人物完整小传、关系与声音指纹 | 建人物、加角色或续作；不固定八人、不因只写首集删后续人物 |
| 世界观与连续性 | 整理世界规则、时间线、力量/职业边界、知情与道具状态 | 事实承重或已有档案时继承，轻项目按风险缩放 |
| 爽感、情感与节奏 | 设计单集回报、反转、四类钩子、情感拉扯与呼吸段，落进集纲和正文 | 所有题材；60–90 秒短集当集有爽点或实质反转，恋爱专项按项目启用 |
| 正文、改写与续写 | 从想法试写、按集纲写正文、接续旧稿或按要求修改 | 根据已有材料直达所需环节，支持快写而不强建全团队 |
| 台词桌读精修 | 整理自然听答、人物声部、潜台词与表演节奏，交完整修订稿及变更表 | 台词平、硬、同腔或进入交付前；只润色时不改剧情事实 |
| 连续性、合规与质量审核 | 定位因果、空转、重复兑现、知情与合规问题，给证据和责任层返修 | 按项目质检节奏或用户要求；诊断不擅自改稿 |
| 商业评估 | 区分内容判断、测算假设与真实数据，检查变现条件 | 只有明确要求投前测算/量化评估才启用模型，不预测必爆 |
| 标准剧本交付与按需导出 | 一份活动正文；设定/集纲按真实用途拆并，审核原文可分区保存 | 阅读制作共用；工作历史不冒充真源，目录按需创建，临时文件先核依赖与授权 |

### 制作团 drama-studio

| 功能 | 能帮你做什么、交付什么 | 什么时候用 |
|---|---|---|
| 角色、场景与道具资产 | 本集实际出镜角色逐人独立参考 + 本集共享的按集参考总表；清晰场景/道具 Panel 可直接履责；群演外观与场景反打按缺口补图，已有材料复用 | N 个角色对应 N 份参考；既有板可跨集/Clip 复用，新文件只补真实缺口，单独资产请求不启动视频流程；总表请求按 Studio asset-library §4 的自适应综合图板执行，含人物构图实际绑定对应人物图 |
| 分镜与导演设计 | 主动判断观众看什么，设计景别、运镜、光影、站位、表演与剪辑关系 | 把剧本转成镜头，交分镜总表与逐 Clip 提示词 |
| 动作、特效与复杂互动 | 设计打斗轨迹、力量反馈、巨物尺度、玄幻效果和多人/道具关系 | 按作品与模型条件读取对应维度、案例或可达专项，不因复杂预先削平看点 |
| 视频提示词装配 | 所有时长统一中文八段式；对白保留项目语言 | 自然语言说明目标即可，不必记模板名；每 Clip 只交一种正文 |
| 参考绑定与防穿帮 | 默认独立角色参考 + 按集参考总表（实际关键道具、按需精选关键构图、空场景区），核对空间、占手、光影、状态与披露边界 | 有图按真实文件/Panel 绑定；已有分图/旧表可复用，无图只规划，静态参考不冒充首帧或连续运动 |
| 声音、口型与配乐 | 声音指纹、母音色计划/资产、对白时码、声场、拟音与配乐方案 | 普通声画内联，人物音色默认用户匹配；仅明确委托声音处理时启用专项，计划不冒充试听成功 |
| 实际图片/视频生成 | 在已授权范围内调用已接入工具，记录任务、结果、尝试与成本 | 工具、登录、配额与预算就绪后；默认只交规划 |
| 剪辑、混音与字幕 | 时间线、镜头拼接、音轨衔接、混音、字幕与成片交接 | 有素材并需要成片时，按实际工具执行；发布还需相应授权 |
| 制作 QC 与局部返修 | 分开检查技术可用与语义合格，定位资产/动作/声音及方法适配责任项 | 检查当前真实产物；方法失败可退原角色替换/回落/细化，没用专项但职责完成不扣分 |
| 可视图册与可选离线看板 | 从既有索引/复用说明展示本批工作、实际图片、版本/Panel/用途、缺项与下一动作；图片词和视频词分别复制纯原文 | 多资产/多提示词集中交付或明确要求时；按 Studio file-management §2 导出只读快照，不强制简单任务、不生图、不改来源采用状态 |
| 续作与跨任务恢复 | 继承角色、资产 ID、版本锁、镜头进度与已通过结论 | 做下一集、换任务或返修时，只使受影响内容失效 |

### 两团共享

| 功能 | 能帮你做什么 | 使用边界 |
|---|---|---|
| 统一案例索引 | 按当前创作问题从 canonical metadata（已绑定时）或公共 metadata（未绑定时）发现候选，只读命中单条 | 标签不证明适配；先核输入/完整性/模型/来源状态，获准且 TXT 可达才声称读过原文，不整库注入 |
| 缺口定向补搜 | 本地不足时，在已有授权内查原帖、作者续文与相关案例 | 按需使用可达的 agent-reach；需要登录或评论未读全时主动说明，不能把半截内容当完整 |
| 版本与资料边界 | 保留原始要求、来源定位、当前版本、作者索引和可达状态 | 绑定失效只停案例消费，非依赖规划继续；公开包只含允许发布的 metadata，私有正文/媒体/配置不上传 |

仅装 Crew 时，创作与本包引导照常可用；未安装 Studio 的共享案例入口标待就绪，不因此阻塞不依赖案例的原创。仅装 Studio 时，可以接自带剧本制作，不要求先安装 Crew；自带稿审核状态按实际记录。

## 3. 本次配置卡（主理人自动填）

按已有信息填写相关行；不适用行可以合并省略。每个值带状态和来源，不把下面的空表直接丢给用户填写。

- 已确认：用户原话、已批准项目设置或明确目标稿的事实，注明来源。
- 识别建议：由任务推得的功能、默认值与规划假设；可纠正，不冒充硬设定。
- 待确认：缺失且会影响当前交付，说明具体问题。
- 待就绪：工具、登录、素材、额度或授权尚未具备；与用户是否确认方案分开记录。

| 配置项 | 说明 |
|---|---|
| 本次目标与范围 | 选题/写稿/精修/审核/资产/分镜/提示词/生成/成片；具体集段或对象 |
| 已有材料与缺口 | 目标稿、交接包、人物/世界观、资产、参考；区分目标输入与仅供借鉴的样本 |
| 内容与事实锁 | 题材、主要情绪回报、关系浓度、恋爱轴、不能改变的事实与揭示时机 |
| 品牌用途（仅品牌叙事） | 目标受众、商业目的、观众可感的结尾回报、品牌角色、排除的商业内容；已有约定直接继承，按 commercial-craft §8 分支处理 |
| 语言与呈现 | 剧本/对白/最终 Prompt 的目标语言与口音，真人/3D/其他媒介，成片画幅；参考图画幅另记 |
| 时长与结构 | 单集目标时长与单次 Clip 时长分开记录；总集数只在涉及整季时填写 |
| 模型与渠道 | 生图与视频分开继承已选模型/版本、provider/adapter 及各自分辨率/画幅；未定项写兼容建议，不以脚本默认覆盖。没有视频任务就不要求选视频模型 |
| 本次启用功能 | 写明功能、选择理由、预计交付物，主理人协调，本职角色完成专业设计 |
| 暂不启用 | 与本次无关或尚缺条件的功能及原因，不将“不需要”误写为“系统不支持” |
| 质检与执行边界 | 继承审核状态和节奏；规划/执行、预算上限、剩余额度与授权范围按实际记录 |
| 输出与下一步 | 已有项目目录、当前版本与下一动作；纯问答不强建目录或配置文件 |

创作持续项目的恢复入口按 Crew `canon-ledger.md` §4，沿已有接稿/进度记录定位当前阶段、真源修订、已审范围和下一动作，不另抄正文/正典；Studio 单独安装仍按本包现有标准正文、资产与分镜记录恢复，不依赖 Crew 文件。

配置说明留在项目已有接稿记录、交接头或当前答复中，不再另建一套参数台账。派单只把命中配置及其状态/来源传入现有模板，专业角色不重新盘问用户；“识别建议”不能写进“已确认硬设定”栏。

## 4. 自动识别和默认值

判断顺序：本次明确要求 → 已批准的项目设置 → 明确作为目标的剧本/交接材料 → 相容的默认建议。相互冲突且会影响当前工作时说明冲突；参考作品、示例提示词和文件名只帮助借鉴，不能覆盖目标锁。

- 任何单次 Clip 时长统一采用中文八段式；时长只决定容量、时间轴与接口适配，不再触发另一套模板。一集总时长不等于一次调用长度。
- 只给一个 30 秒视频、英文参考提示词或某模型案例，不推定目标时长、语言、模型、媒介或新增剧情事实；目标不明且会影响当前产物时再问。
- 本次明确要求优先于已批准项目设置；视频未给值按 Studio `references/prompt-assembly.md` §1 的单次 Clip 时长与 720p 默认规划；生图配置另按 Studio external-platforms 继承并核对，不套视频参数。显式参数不兼容时报告差异，不静默换模型、缩时或拆分；单集时长不等于单次生成时长。
- Studio 以本集实际出镜故事角色为准逐人准备独立参考：N 个角色对应 N 份参考，默认一人一张综合板，配角也计入；纯画外声不编造外观，纯背景群演按 Studio asset-library §1 使用场景描述/已有 Panel，装束、差异或复用外观有缺口时补多人参考板，不固定人数和张数；承担实际互动、回应或结果职责的未具名角色仍计独立角色参考。身份、外观与状态匹配的既有综合板/分图跨集、跨 Clip 复用，新角色或真实变化只补所需新板、同 ID 变体或清晰度缺项，因此参考数不等于每集新文件数；纯角色资产请求也适用默认综合板，“一张”只限数量，明确肖像等其他图种才切换，按 Studio asset-library §2 执行。视频任务由景川从本集分镜选出批准构图，再让丹青按需组装按集参考总表；清晰场景/道具 Panel 可直接履责，各 Clip 只绑相关区域，旧分图/按 Clip 表继续复用，明确参考总表请求须交一张综合视觉图板；其他纯资产任务不要求该表。服装、媒介与画幅服从项目锁，不自动 3D/9:16；设定板、网格和参考帧不覆盖实际首帧或证明连续运动。
- 英文目标项目输出英文 Prompt 与英文对白，英语口音未指定时建议自然美式；中文目标匹配中文条件。无翻译授权不改已锁对白。与用户沟通的引导语言可以沿用用户语言。
- 从零整季规划未给集数、平台或质检方式时，Crew 原有 30 集/红果/全稿终审只作透明默认建议；明确英文出海等不相容目标时不硬套红果。只改台词、只试写一场或只做资产不套整季默认。
- 既有 `carrier`、`romance_axis` 与审核状态按来源继承；未讨论恋爱轴不能推成关闭。无恋爱线仍保留题材适合的人情与情感表达。
- 制作默认 `planning_only`。用户要实际生成时，把执行意图与执行就绪分开：必要输入、工具、账号和预算满足后才提交；无需用户逐镜选择方法，也不因自动识别而自动购买、充值或发布。本机 MiniMax H3 按输入材料选画布：无参考图→11 文生；明确首帧→20；首尾帧→21；锁人物/服装/场景或其他参考职责→30。不把 11 当默认，不按脚本文件名选号；30 号按本镜职责选图，不固定三张配方，详见 Studio `h3-comfy-mode-routing.md`。

## 5. 使用者可以直接这样说

- “启动创作团，带我了解有哪些功能。”——显示完整导航，帮你确定下一步。
- “跳过引导，按现有集纲写 E03。”——继承项目设置，直接进入续写所需环节。
- “跳过引导，只润色这段对白，不改事实。”——只做当前表达修改及相称核查。
- “这份英文剧本，用 Seedance 2.5 单次生成 30 秒，先只出提示词。”——使用中文八段标题，保留原英文对白与口音，仍停在规划；仅明确要求其他提示词语言时等义调整。
- “展开全部功能，我想看看后面还能做什么。”——重新显示导航，不改当前项目配置。
