# Production-learning neutral cases

These are rule-consumption and boundary checks. They do not claim a fresh-context experiment, successful media generation, model fidelity, retention, or business outcomes. Reuse the same inputs when checking source and staged installed packages; preserve each package's existing screenplay and prompt format.

| Case | Neutral input | Expected action | Must not happen |
|---|---|---|---|
| Long unspecified Clip | One 22-second Dreamina Clip; model and resolution omitted. | Resolve seedance2.5 and 720p for this individual request. | Treat 22 seconds as the episode duration, use the short model, silently split or shorten. |
| Explicit override control | One 12-second Clip explicitly using Seedance2.5 and 1080p. | Retain both explicit compatible values. | Replace them with defaults or treat an explicit example as obsolete. |
| Boundary and incompatibility | One 15-second request with no model; one 16-second request with explicit Seedance2.0; one unspecified 31-second request. | Use fast VIP only for the first; report incompatibility for the other two. | Silently switch explicit model, accept unsupported duration or create extra paid calls. |
| Brand-service brief | A 60-second service-brand story, one location, no SKU display or investor solicitation. | In the existing brief preserve audience, business purpose, ending payoff, brand role and exclusions. | Force IAA/IAP, paid-wall design, new product claims or unmeasured audience results. |
| Direct assembly | These accepted clips only: trim, concatenate, retain native audio; no subtitles or extra review. | Keep the agreed selections; normalize/export; record selected source/in/out/order in the existing timeline; disclose semantic rereview was not performed. | Add captions/music, paid generation or external semantic review; claim skipped review passed; force a new report set. |
| Connected appearance revision | Revise the final appearance and emotional state; preceding selected take remains available. | Inspect affected actual upstream/downstream selection and cut states; update only dependent material. | Fix only the new tail, use a plan as proof of continuity, or rerender all accepted footage. |
| Ghosted reference | Extracted source has double contours, while another required angle is merely low resolution. | Diagnose separately, test representative required views, redraw only unresolved gaps preserving structure and large lettering. | Batch-upscale first or claim reconstruction recovered unknown factual detail. |
| Empty architectural reference | Reuse an accepted empty store-space reference for a scene whose script has adults browsing in the background. | Keep architectural topology; add motivated live activity and correct reflections; use existing independent identities. | Clear the live scene merely because the reference is empty, invent new walls, or mandate new keyframes. |
| Actual audio differs | A generated sentence finishes later than its prompt window. | Use measured selected audio and clip time, preserve language/meaning and compatible action, adjust affected edits. | Cut off the sentence to obey the prompt, count English letters as Chinese syllables, or use ASR/static frames as full performance QC. |
| Claimed price drift | Server-reported charge materially differs from the scoped estimate; account also has concurrent usage. | Preserve actual request and provider charge, distinguish balance, stop dependent batch pending explanation. | Attribute all balance movement to one job, promise a discount or silently resubmit. |

Automated checks in `tests/test_production_learning_contracts.py` test owner/consumer reachability. The existing production-tool suite separately tests executable model routing and real local ffmpeg assembly. A human or model consumption exercise must report its actual context and scope; these cases alone are not experimental results.
