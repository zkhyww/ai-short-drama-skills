# 三部长篇返修与剧本质量门禁设计

## 目标

依据三部 60 集行为测试暴露的真实失败，修正 `drama-crew` 的执行合同，并用修正后的规则返修《闭库名单》《静帧许可》《她们的工时账》。完整项目必须分别交付制作视图与投稿视图；时长、格式、动作和对白质量均以可复核证据裁决，不再用字数达标或主控自评分代替验收。

## 已证实的根因

1. `350–500` 被执行成逐集硬下限，返修时为了过门槛补入“记录、授权、复核、封存”等同义程序对白。
2. 时长报告使用“净台词÷固定语速 + 每动作固定秒数 + 每集固定秒数”，把规则性估算误写成接近成片时长的结论；没有代表集真人桌读或逐动作时值证据。
3. 终审对白硬度门集中看承重场，少数重点集返修后即可抬高全剧评分，普通中段与非承重场的大量静态宣读未被覆盖。
4. “精确重复为零”被误当成“没有模板化”，没有识别语义功能相同、只替换名词的程序对白和动作句。
5. 双轨成稿已有文字合同，但投稿视图缺少确定性导出门禁，导致内部字段、动作节拍箭头、情绪数字、空集纲、错误 `VO` 和非法枚举仍能进入成品。
6. 台词统计器没有严格区分真正发声、人物标签、括号动作和书写动作，造成字数及发声时长虚高。

## 设计

### 1. 制作视图与投稿视图强制分开

完整项目锁版时输出两个不同文件：

- `{项目名}_完整制作母稿.md`：唯一内容真源，供 `drama-studio` 使用。保留 `script_rev`、`review_state`、`romance_axis`、场景设定、动作节拍、情绪和时长预算等制作信息。
- `《剧名》_标准投稿阅读稿.md`：由同一锁版母稿机械派生，供编辑、平台或制片人阅读。按“封面→卖点→梗概→主要人物→粗纲→非空逐集集纲→正文”排列，只保留标准场次、人物、`∆` 动作、对白及合法 `OS/VO`。

DOCX 仅是投稿阅读稿的可选包装载体：接收方明确需要 Word/DOCX 时再生成，不用 DOCX 替代内容级双视图。投稿稿不是第二内容真源，内容变化必须回母稿升版、复核后重新派生。

### 2. 时长预算改为证据链

`350–500` 仅作为 90–120 秒真人短剧的常见对白诊断区间，不再是必须补足的逐集下限。低于区间时，只检查是否由有效动作、停顿、反应、环境变化或无对白表演承担时长；不得为了达标增加同义解释和程序话术。高于区间时检查语速与信息拥堵，也不只因数字自动删戏。

逐集时长估算分列记录：实际发声字符、语速区间、发声秒数、逐项动作/停顿估时、转场估时、总估时和证据状态。禁止用“每条动作统一 4 秒”或“每集固定补 12 秒”作为最终验收。每部 60 集稿至少对代表集做真人桌读/试演计时，覆盖开篇、中段静态集、高潮和季终；其余集只能标为估算。

### 3. 对白与动作双层抽查

终审不只检查承重场，还要抽取普通中段、低冲突和报告类场景。对白检查同时识别：

- 连续程序化问答、轮流宣读正确观点、角色同腔；
- 同义替换后的语义模板，而不只看逐字重复；
- 为达到字数下限增加、删除后不改变选择、关系、证据或结果的填充台词；
- 连续对白期间缺少可见反应、空间变化或现实后果。

动作不设机械行数配额。长对白段只在场面压力、关系或空间状态长期不变时命中；有效的凝视、停顿和静止可以成立，但必须产生新的压力或含义。重复动作句需要结合时间、地点和账本状态检查，防止《闭库名单》式跨 20 集时间戳停滞。

### 4. 投稿稿确定性预检

新增轻量 Markdown 预检工具，负责可机械判断的项目：

- 集数、场号、必需章节及逐集集纲是否完整、非空；
- 投稿稿是否残留内部字段、`【动作节拍】`、`Beat`、箭头链、情绪数字、模型参数；
- `romance_axis` 在母稿中是否仅为 `on|off`，并确保投稿稿不携带该字段；
- 人物行是否重复姓名；台词人物名后的括号是否混入明显可见动作；
- `OS/VO`、对白行与动作行分别统计，书写、回放等动作不得误算成发声；
- 连续对白无动作、跨集重复动作/时间句和异常高频制度词只报诊断，不自动改稿；
- 输出纯发声时长区间，不把动作固定折秒后冒充成片时长。

工具不判断审美，也不自动改写。它只负责阻止确定性错误进入“已审定”和投稿交付状态；语义、人物声音和动作是否成立仍由文茵、青梧与季衡裁决。

### 5. 评分与放行边界

格式预检失败、逐集集纲为空、非法状态枚举、连续性硬冲突、对白硬度门失败或时长证据冒充实测时，不能给出 `review_state=reviewed`，总分不得达到 90。主控自评分只能作为过程记录，最终放行必须附具体位置证据和预检结果。

返修采用唯一母稿：先改正文与相关集纲，再同步账本，重新派生标准投稿稿。禁止分别手改制作稿与投稿稿。

### 6. 三部剧的定向返修范围

- 《闭库名单》：全稿清除投稿视图制作残留；修复 E21–E40 时间停滞；重点重写 E51、E56、E58 及语义同类场；减少画外记录依赖；拆解长对白块并补有效反应与空间压力。
- 《静帧许可》：补强动作稀薄场和长段静态对白；统一角色/回放/直播提示格式；修正 E59 `VO` 状态；清理人物行重复；按人物利益重写概念宣讲，并重新验证 120 分钟目标。
- 《她们的工时账》：补齐 60 集逐集集纲；统一 `romance_axis=off`；修正电话等画外音；重点返修 E12、E25、E26、E36、E37、E51、E53 及语义同类制度说明场，保留现有生活感。

三部均不推翻题材、主要人物关系、第一季收束和续季悬念，只修已证实的格式、时长、动作、对白及连续性问题。

## 验收

1. 新的合同测试先证明旧规则会错误放行，再证明新规则能拦截；既有回归保持通过。
2. 预检工具用合成样例验证有效稿通过、内部字段/空集纲/非法枚举/重复人物/误计发声等失败稿被准确指出。
3. 三部返修后的制作母稿和标准投稿阅读稿成对存在，来源版本一致，投稿稿确定性错误为零。
4. 已知问题位置闭环，普通中段样本不再出现大段程序化宣读；任何保留的长对白均有明确人物目的、阻力和表演变化。
5. 每部提供代表集真人桌读/试演计时记录；没有实测覆盖的集只标“估算”，不宣布精确成片总时长。
6. `drama-crew` validator、合同测试、Markdown 围栏、本地引用及 Git diff 检查通过；README、CHANGELOG 和安装副本同步。

## 非目标

- 不建立自动改稿器或完整自然语言评分引擎。
- 不为动作、OS、句长或制度词设置新的机械配额。
- 不改变三部剧已经锁定的题材方向、主要结构与第一季悬念。
- 不生成未经用户或接收方要求的 DOCX、审批编号或发布标识。
